## 구조

새 모듈 `scripts/presentation/moco_fx.gd` (`MocoFX`, 씬마다 `ToonGunFX` 아래 하나).

- **타격 버스트**: 모든 버스트를 노드 하나의 `ImmediateMesh` 에 매 프레임 다시 그린다. 타격마다 노드·재질·텍스처를 만들지 않고 정적 캐시도 없다 (반복 로드에서 예전 피격 섬광이 쌓던 `spark` 캐시가 0 으로 멈춤). 꼭짓점 색은 HEX → `srgb_to_linear()` 한 번만 변환해 넣고, 공용 재질(`MocoFX.vc_material()`, unshaded · blend_mix · depth_draw_never · **깊이 검사 유지** · 그림자 없음)은 흰색(세 채널 1)만 HDR 1.3 으로 살짝 띄운다. 조명 노드 없음.
- **진입점**: 모든 적·보스가 이미 부르던 `HitSpark.spawn` 이 `MocoFX.on` 이면 `MocoFX.hit` 으로 분기 (`heavy` 인자 추가). `Enemy._hit_spark` 는 `_hurt` 와 같은 강타 분류(`dmg ≥ 4` 또는 slash/phantom/missile/parry)를 넘긴다. 보스(맘모스·용광로·거미·워든)는 `source` 로 분류.
- **피해 숫자**: `Enemy._hit_spark`(= 실제 `take_hit` 에서 피해 확정 직후, 경직 2배 반영 값) 와 보스 4종의 피해 확정 자리에서 `MocoFX.report` 한 번. 두 번째 `take_hit` 호출 없음. 소품(`Enemy.prop`, 가스통)은 숫자 없음.

## 효과별 적용값

| 효과 | 적용 | 문서 대비 |
|---|---|---|
| 일반 타격 | 6각 비대칭 별(흰, 한 꼭짓점 1.7배) + 짙은 마젠타 뒷면 쐐기 + 마젠타 쐐기 3 + 민트 마름모 3~4. 지름 = 대상 폭 × 0.75~0.9 (폭은 0.8~2.2m 로 자름). 심지 70ms · 큰 면 150ms · 220ms 소멸 | 크기 하한 0.6 → **0.75** (0.6 은 화면에서 너무 작음) |
| 강타 | 8각 별 + 노란 주가시 1~2 + 쐐기 4 + 마젠타·노랑 파편 4~6. 지름 × 1.2~1.6. 70 / 160 / 300ms | 그대로 |
| 배치 | 판정점(몸 안쪽)을 공격이 온 쪽 표면으로 폭×0.4 옮기고 카메라 쪽 0.25m 당김 (보스는 `fx_point` 가 이미 겉면이라 안 옮김) | PULL 0.7 → **0.25** (문서 0.10~0.25 상한. 0.18 은 몸에 가려짐) |
| 긴 가시 방향 | 공격이 온 쪽(표면 밖)으로 | 문서는 "타격 방향을 따라" — 진행 방향은 적 몸 속이라 깊이 검사에 가려져 안 보여서 반대로 뒤집음 |
| 연사 | 같은 적 45ms 안 재발생 무시(예전 규칙), 동시 버스트 상한 24 (넘으면 오래된 것부터) | 그대로 |
| 검 궤적 | 기존 호 메시 그대로, 셰이더 mo.co 분기: 흰 앞날(바깥 테두리·머리 쪽) · 마젠타 몸체 · 짙은 마젠타 꼬리, 꼬리로 갈수록 폭·알파 함께 감소. 두께/반지름 일반 0.16 · 강타 0.24, 보이는 호 일반 약 128° · 강타 150°. 일반 약 120ms · 강타(내려찍기·회전 베기) 약 180ms | 판정 범위·타이밍 불변. 콤보 초승달(`FX.crescent`)도 같은 색 |
| 베기 바닥 원·충격파 | 붉은색(Pal.BLADE) → 마젠타 | 붉은색은 적 위험 예고(DANGER) 몫 |
| 피해 숫자 | **2026-10-04 땅굴크루식으로 교체 → [damage-log.md](damage-log.md)** (예전: 흰 28px Label, 550ms, 대상당 최대 2, 화면 16) | 강타는 노란 큰 숫자 |
| 상태 | `Enemy.stagger` 로 **실제 경직에 새로 들어갈 때만** 민트 34px `STUN!` 700ms (이미 경직 중이면 안 뜸). `CRIT!` 은 실제 치명타 판정이 없어 표시하지 않음 | 그대로 |
| 훈련장 | 자체 `Label3D` 숫자는 `--vfx=old` 일 때만. 기본은 일반 전투와 같은 숫자 (두 번 안 뜸) | |
| 보호막 | blend_mix: 면 alpha 약 0.06 + 테두리(fresnel) 최대 약 0.5 + 큰 육각 셀 테두리선(구 둘레 6칸, 앞쪽 넓은 면에선 거의 안 보이게). 전개 250ms(기존). 피격 시(1회 소모 규칙 그대로) 맞은 방향 면만 SOFT 로 100ms 강조 후 깨짐 (`Shield.pop(dir)`) | |
| 드론 연결 | `DroneFX.Link`: 노즐 → 플레이어 몸체, 매 프레임 양 끝 갱신. 점선 0.18/0.12m 가 플레이어 쪽으로 흐름, SOFT 마름모 펄스 3, 폭 0.06m. 수명은 기존 호출값(보호막 350ms · 회수 250ms) | 폭 0.045 → **0.06** (망원 카메라에서 1~2px 라 범위 상한으로) |
| 볼텍스 | `DroneFX.Vortex`: 실제 반지름(8m) 바닥 `Main.gy + 0.05`(꼭짓점마다 샘플)에 끊어진 호 3개(각 95°, 두께 = 반지름 × 0.02) + 조여드는 안쪽 호 3 + 중심으로 빨려 드는 삼각 파편 7. 0.75초 + 0.12초 페이드. 16m 를 채우지 않음 | 판정(끌어당김·피해·경직)은 PartnerDrone 그대로 |

## 남은 것 · 판단 보류

- 벽에 가려진 대상의 숫자는 숨기지 않았다(전투 피드백 우선). 필요하면 앵커 가림 검사 추가.
- 넓은 화면 비율·다수 적(10+) 실전 화면에서 숫자 겹침은 상한으로만 막음 — 실제 플레이 화면으로 추가 확인 권장.
- 광선검 자체 색(붉은 `Pal.BLADE`)은 그대로다. 위험 예고 붉은색과의 구분이 필요하면 다음 단계에서 검토.
- 플레이어 피격 표시, 적 위험 예고(DANGER #FF5268) 재색칠은 이번 범위 밖.
