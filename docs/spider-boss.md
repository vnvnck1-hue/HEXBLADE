# 거미 보스 SHIPWRIGHT · SHAFT 07 설계

본편과 분리된 전용 테스트 씬(`scenes/spider.tscn`, `spider_boss.cmd`). 본편 이식은 사용자가 요청할 때 한다.
코드는 모두 `scripts/spider/` 에 있고, 기존 코드는 `player.gd` 의 감속 배율 훅(`slow_mul`, 3줄)과 로비 목록 한 줄만 바꿨다.

참고: 사용자 3면도·측면도(`output/spider-boss-20261001/spider-boss-three-views.png`), 영화 *반지의 제왕* 의 쉴롭(어둠 속 매복 · 위에서 내려옴),
*바이오하자드* 의 거대 거미(벽·천장을 오가는 출몰). "보일 듯 말 듯 → 갑자기 가까이" 의 리듬을 패턴 구조로 옮겼다.

## 움직임 — 살아 있는 거미처럼

- **3관절 다리 IK**: 발허리를 면 법선 쪽으로 세우고 고관절→발목을 2관절로 푼다. 무릎이 몸보다 높이 솟는 거미 실루엣.
- **걸음**: 발은 디딘 자리에 박혀 있고, 쉬는 자리와 멀어지면 내딛는다. 대각선 두 다리가 한 조(다른 조가 딛는 중이면 기다림), 너무 늘어나면 급히 딛는다. 빠를수록 짧고 빠른 걸음 · 높은 발 들기, 착지점은 속도만큼 앞을 내다본다.
- **면 따라 걷기**: 딛는 자리를 `stage.project()` 로 가장 가까운 면(바닥·벽·기둥·구멍 바닥)에 붙이므로, 벽에 다가가면 앞발부터 벽을 짚고 몸이 L 자로 돌아 올라간다. 벽은 머리부터 타고 내려온다.
- **몸**: 발이 닿을 때 눌리는 출렁임 스프링 · 가속 반대로 젖혀지는 기울기 · 늦게 따라오는 뒤 몸통 · 숨.
- **머리**: 플레이어를 보되 툭툭 끊어 돌리는 단속 운동. 탐조등이 볼류메트릭 안개를 가른다.
- **끊어 달리기**: 배회 중에는 확 달렸다 뚝 멈추기를 되풀이. 새끼 거미도 같은 리듬.
- **위협 자세**: 앞다리 둘을 높이 들고 공구 팔을 벌린다 (등장 · 다리 찌르기 · 2페이즈 전환).
- **죽음**: 벽에서 떨어져 다리를 몸 아래로 오므리며 경련 → 눈이 꺼지고 폭발.

## 전장

- 54×46m 홀 + 48m 벽(높이 갈수록 어둠). 카메라 쪽 남벽은 낮은 난간과 한 단 낮은 통로(절개면).
- 바닥 굴 4(북 2 · 동 · 서) · 배관 구멍 4(북 2 · 동 · 서, 9~19m 높이). 속은 겹겹의 어둠 막이라 보스가 들어가면 사라지고, 눈빛만 켜질 수 있다.
- 기둥 7개는 190m 높이로 어둠 속에 사라지며, 9m 마다 신호등(2페이즈에 붉게)이 있어 높이감을 준다.
- 기둥 셰이더: 카메라 곁을 지나가는 부분과 플레이어를 가리는 부분만 점묘로 지운다(그림자는 따로 그려 구멍이 나지 않음).

## 카메라 (`spider_camera.gd`)

기본 쿼터뷰보다 낮은 각도. 좌우 시차 회전 · 보이는 보스 쪽으로 시선 당김 + 거리만큼 물러남 · 숨었을 때 천천히 둘러봄 ·
튀어나온 순간 그 자리로 시선이 끌렸다 돌아옴 · 높은 곳/천장 낙하 때 올려다보기 · 남쪽 끝은 시선을 받쳐 바깥 어둠을 덜 비춤.

## 패턴

| 패턴 | 흐름 | 대응 |
|---|---|---|
| 거미줄 포격 | 정면 벽에 붙어 머리를 아래로 → 입이 하얗게 달아오름 → 포물선 덩이 3~5개 × 3~4회 | 떨어지는 자리 표식을 피한다. 판 위는 0.5배 속도, 직격은 감김(대시로 끊음) |
| 매복 돌격 | 구멍으로 숨음 → 가짜 눈빛 · 벽 부스러기 → 진짜 구멍 눈빛 0.6~0.85초 → 굴이면 직선 돌진, 배관이면 도약 내려찍기 | 눈빛을 보고 거리 확보. 내려찍기 뒤 1.8초 약점(×2) |
| 기둥 사이 배회 | 기둥 뒤 → 기둥 뒤로 끊어 달림 · 가끔 한 발 → 기습 → 다리 찌르기 3~5회 | 붉은 원 예고를 대시로 피한다 |
| 산란 | 뒤 몸통을 들고 해치를 엶 → 새끼 4~6 던짐 + 바닥 굴에서 몰려나옴 | 해치가 열린 동안 ×1.6 |
| 천장 낙하 | 기둥을 타고 어둠으로 → 위에서 실이 내려오고 그림자가 따라옴 → 멈칫 → 낙하, 충격 + 원형탄 + 거미줄 판 | 그림자가 멈추면 바로 벗어난다. 착지 뒤 2초 약점 |
| 기관포 소사 | 바닥에서 조준선 → 옆걸음질하며 부채꼴 소사 | 기둥 뒤로 숨는다 (탄은 기둥에 막힘) |
| 거미줄 그물 (2P) | 플레이어 둘레 고리 + 한가운데 | 고리가 닫히기 전에 빠져나간다 |
| 질주 (2P) | 지그재그 돌진 3회 + 거미줄 자국 → 다리 찌르기 | |

체력 1300, 50% 에서 2페이즈(비상등 · 빨라짐 · 숨으며 시작). 숨었거나 9m 넘게 높이 있으면 맞지 않는다.
판정 몸통은 보스 아래 바닥(벽에 붙으면 벽 밑동)에 있다.
