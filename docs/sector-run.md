# 헥스 섹터 런 (MVP)

젠레스 존 제로 「제로 공동 · 로스트 보이드」식 포탈 경로 선택 구조. 로비(`scenes/lobby.tscn`)의 **메인 게임** 메뉴로 시작한다. 방 씬은 `scenes/run.tscn`. 게임 중 Esc 로 로비에 돌아가면 런은 중단된다.

## 흐름

```
출발 → 단계 1~6 (단계마다 방 2~3개, 포탈로 다음 방 선택) → 보스
섹터 1 도시 외곽 → MAMMOTH (boss.tscn)
섹터 2 제철소   → VULCAN  (forge.tscn)  → RUN COMPLETE
```

- 방을 정리하면 방 위쪽(화면 안쪽)에 **육각 포탈**이 솟아오른다. 포탈 위 표식이 다음 방 종류와 보상을 알려 준다. 포탈 순서(왼쪽 → 오른쪽)는 지도의 위 → 아래 순서와 같다.
- 포탈 발판에 올라서면 고르지 않은 포탈은 닫히고, 육각 터널 워프로 다음 방에 들어간다.
- 화면 밖에 있는 열린 포탈은 화면 가장자리의 화살표로 표시된다.
- 방은 통로 없는 단일 방이다(기존 방 8종에서 무작위). 워프 뒤 1.1초가 지나면 전투가 시작된다.
- 체력은 런 내내 이어진다. 방을 정리해도 회복되지 않는다(기존 방 탐색 모드의 "+1" 규칙은 쓰지 않음). 회복은 **정비** 칸(+3)과 섹터 전환(+2)뿐이다.
- 체력이 0이 되면 RUN FAILED, 두 보스를 다 잡으면 RUN COMPLETE. R 을 누르면 새 런, 런 중 F5 도 새 런이다.

| 칸 | 내용 |
|---|---|
| 전투 | 적 소탕, 코인 +(20 + 단계×5) |
| 정예 | 난이도 +2, 코인 +(50 + 단계×10) |
| 정비 | 가운데 수리 발판을 밟으면 장갑 +3. 포탈은 바로 열린다 |
| 보스 | 섹터의 끝 |

지도 생성 규칙(`sector_graph.gd`): 1단계는 전투만 나온다. 3~5단계 중 적어도 한 칸은 정예이고, 보스 앞 단계에는 정비가 적어도 하나 있다. 연결선은 서로 교차하지 않는다. 난이도는 `1 + (단계-1)×0.75 + 섹터×2` 에 정예 +2 를 더해 1~6 으로 자른다.

## 조작 추가

| 입력 | 동작 |
|---|---|
| Tab | 섹터 지도 전체 화면 켜기/끄기 (첫 섹터 시작 때 자동으로 열림) |
| 오른쪽 위 미니맵 | 런 중에는 방 미니맵 대신 섹터 지도 축소판 |

## 파일

| 파일 | 역할 |
|---|---|
| `scripts/run_state.gd` | 오토로드 `Run`: 섹터 지도·현재 칸·지나온 길·체력/코인/점수, 포탈 워프 전환(화면 셰이더), 보스 결과(다음 섹터 / 완주), 패배, Tab·R·F5 |
| `scripts/sector_graph.gd` | 섹터 그래프 생성, 헥스 좌표 |
| `scripts/sector_map_view.gd` | 섹터 지도 그리기 (전체 화면 + 미니맵 공용 `paint()`) |
| `scripts/run_main.gd` | `RunMain` (Main 상속): 단일 방, 칸 종류별 진행, 포탈 배치, 정비 발판, 화면 밖 포탈 표시, 자동 플레이 |
| `scripts/portal.gd` | `SectorPortal`: 육각 틀·소용돌이 막·발판·표식, 솟아오름/닫힘, 입장 판정 |
| `scenes/run.tscn` | 런 방 씬 |
| `scripts/map.gd` | `generate_single()`, `open_spots()` 추가 (기존 생성은 그대로) |

보스 씬(`boss_main.gd`, `forge_main.gd`)은 고치지 않았다. `Run` 이 현재 씬의 `Main.state` 를 보고 승패를 처리하고, 보스전 시작 때 체력을 넘겨준다. B 키 등으로 런 밖 씬으로 나가면 런은 중단된다.

## 검증 실행

```
Godot --path . --fixed-fps 60 -- --bot --godmode --seed=2 --seconds=150        # 런 완주 (보스전만 무적)
Godot --path . --fixed-fps 60 -- --bot --seed=5 --pick=1 --seconds=20 --capture=res://_capture/run --every=15   # 칸마다 _capture/run/s<섹터>_<순번>/ 에 저장
--showmap   # 시작할 때 섹터 지도를 연 채로
--pick=N    # 자동 플레이가 고를 포탈 순번 (없으면 무작위)
```
