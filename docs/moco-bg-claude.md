### 캐시 · 계약

- `material_for(src, role)` 역할 키는 유한 4개 (`bl_body` · `bl_world` · `bl_moco_wall` · `bl_moco_service`) — 원본 재질 메타에 붙으므로 같은 원본을 벽·설비가 나눠 써도 따로 칠하고 정적 캐시가 늘지 않는다. 역할은 노드 메타(`claude_bg` = w01/half/jamb/blocks_*, `claude_service`)로 정한다. 크기 4.5m 규칙으로 벽을 고르지 않는다. 배경 시험 씬(`ClaudeBgMain._inst`)도 같은 `claude_bg` 메타를 붙인다.
- 벽·설비도 월드 계약 유지: `out_rough 0.5`, `rim 0`, `spec_k 0` (ToonOutline 월드 분류).
- 점광원(`LIGHT_IS_DIRECTIONAL` 아닌 분기) 은 그대로. 레이저 암전 → 복귀 확인.
- 상수를 바꿔 튜닝할 때는 이미 만든 재질에 반영되지 않는다 — 다시 실행할 것.

## 3단계 — 배경 톤 더 낮춤 · 플레이어 조명 풀 (부드러운 어둠)

요청: 캐릭터 시인성을 위해 배경 톤을 더 낮추고, 시야 밖에 부드러운 어둠을 깔되 플레이어 주변은 조명으로 밝게.

**조명 풀** (`BrawlLook.POOL` 셰이더 조각 · `track_pool` · `update_pool`, 기본 켜짐, **`--pool=off`** 로 끔, `--bgtone=old` 면 함께 꺼짐):

- 배경 재질(통로 바닥 `FLOOR` · 벽/설비/역할 없는 월드 BODY 재질 · 설비 바닥 `service_floor.gdshader`)만 매 프레임 플레이어 위치(`pool_pos`)를 받는다. 플레이어에서 XZ 거리(앞뒤는 화면에서 짧아 보여 ×1.25)가 `POOL_R0` 3.5m 까지는 그대로, `POOL_R1` 10.5m 에서 해·환경광이 `POOL_DARK` 0.2 배가 되도록 부드럽게(smoothstep 두 번) 줄어든다.
- 해의 빛은 `light()` 의 방향광 분기에서, 환경광은 `AO`(`AO_LIGHT_AFFECT` 0) 로 줄인다 → 바닥 표식 데칼도 같이 어두워진다. **점광원(레이저·폭발·총구)과 발광(설비 상태등·네온 데칼)은 줄이지 않아** 어둠 속에서 빛이 살아난다. 설비 바닥은 기본 조명 셰이더라 바탕색에 같은 비율을 곱한다.
- 캐릭터(플레이어·적) 재질은 등록하지 않아 어둠 속에서도 원래 밝기 → 멀리 있는 적이 어두운 바닥 위에서 또렷하다.
- 재질 목록은 id → WeakRef (원본 재질 메타에 붙은 유한한 재질이라 늘지 않고, 사라진 것은 지움). 씬을 나갈 때 `pool_on` 0 으로 되돌려 보스전 등 다른 씬에 어둠이 새지 않는다.
