# 플레이어 상태 HUD 프리셋

좌상단에 세로로 쌓여 있던 플레이어 정보(ARMOR · DODGE · BOOST · AMMO · LASER · 에너지 · MISSILE)를
장르와 스타일에 맞게 다시 배치한 프리셋 4종과 기존 배치(비교용)를 둔다.
게임 중 **H** 로 다음 프리셋, **Shift+H** 로 이전 프리셋. 실행 인자 `-- --hud=striker|corners|cockpit|tactical|legacy` 로 골라 시작할 수 있다.
고른 프리셋은 씬을 다시 불러도(재시작 · 다음 방 · 보스전) 유지된다.

- 코드: `scripts/presentation/hud_presets.gd` (그리기 전용, Player 값을 읽기만 한다) · 연결: `scripts/hud.gd` (`_apply_preset`, `_place_icons`, H 키)
- 테스트: `tests/hud_preset_check.gd`
- STRIKER는 아래의 차분한 HUD를 기본으로 사용한다. 다른 프리셋은 기존 상단 배치를 유지한다. 화면 가운데 문구와 조준·락온 표식은 기존 동작을 사용한다.

### 2026-10-04 적용: 차분한 상단 HUD와 적 체력바

사용자 채택 시안의 남색 패널·크림색 글자·녹색 장갑·주황 부스터·코랄 적 체력바를 실제 HUD에 적용했다.
좌상단은 메카 초상과 장갑 5칸/수치, BOOST 또는 HOT, 에너지 3칸이며 상단 중앙은 방 진행·현재 방 적 수와 WAVE/LOCK 표시다.
우상단 프레임은 실제 발견한 방·적·플레이어를 표시하는 미니맵, 점수와 콤보를 담는다.
일반 적 HP바는 실제 HP와 피격 잔상을 읽어 화면 공간에 그리며 기존 3D바는 숨긴다. 보스와 소품은 기존 HP 표시를 유지한다.
보스가 있으면 좌상단·중앙 카드를 아래로 내려 보스 전용 체력바를 피한다. 지도 없는 보스 씬은 방 진행·빈 지도를 표시하지 않고 점수와 콤보만 간단히 표시한다.

**사용자 최신 지정 보존 범위:** 우측 하단 원형 스킬 버튼·정보·키 배지의 위치·디자인·내용·리소스를 그대로 유지한다.
드론 UI는 이 범위에서 제외한다는 후속 지시로, 아래 TRIAD 카드를 좌하단에 적용했다.
적 체력바는 스킬과 현재 드론 카드 영역 위에 그리지 않는다. 같은 상태/배경에서 원형 스킬 영역의 적용 전후 픽셀 SHA256을 비교해 사용 가능·재충전 상태 각각 일치를 확인한다.

- 구현: `scripts/presentation/calm_hud.gd`, 기존 HUD·미니맵 연결은 `scripts/hud.gd`와 `hud_presets.gd`.
- 초상: 내장 imagegen으로 채택 시안을 참조해 만든 `assets/ui/calm_hud/mecha_bust.png`(원본 알파 유지, 임포트 최대 512px·밉맵).
- 비교: `-- --hud-art=classic`은 상단과 일반 적 체력바를 이전 디자인으로 표시하며 우측 하단은 그대로다. H/Shift+H 프리셋 전환도 유지한다.
- 검증: `tests/hud_preset_check.gd`의 실제 창 4크기 배치, 리소스 로드·알파·프리셋 복귀·중복 HP바 검사.
- 시안 원본·실제 생성 프롬프트·적용 전 스냅샷·보호 영역 해시·실제 화면·검증 로그: `output/calm-ingame-ui-20261004/`.

### 2026-10-04 후속 적용: 좌하단 TRIAD 초상 카드

사용자 후속 지시에 따라 드론 정보도 채택 시안의 큰 초상·남색 카드·민트 게이지와 키 배지로 적용했다.
기본 STRIKER에서는 좌하단에 배치하고, 원형 스킬 묶음은 변경하지 않는다. 다른 프리셋과 `--hud-art=classic`에서는 이전 드론 패널을 사용한다.

- `scripts/drone/drone_hud.gd`: TRIAD 이름·현재 상태, 실제 SUPPORT 0~100과 50 표시선, 청소/직접 청소 횟수.
- Q DOCK/UNDOCK, X SHIELD/VORTEX는 실제 합체 상태에 따라 바뀐다. Q는 합체 최소 게이지10, X는 스킬 비용50 기준으로 키 배지가 밝아진다. Z CLEAN은 직접 청소 안내, 실제 청소 중이면 밑줄 표시.
- Space 유지 이동으로 주변 청소·짧게 회피 안내를 카드 안에 유지한다. HUD는 게임 값을 읽기만 하며 입력·스킬 비용·기능을 변경하지 않는다.
- 현재 TRIAD 모델의 세 원형 모듈을 참조한 내장 imagegen 초상 `assets/ui/calm_hud/triad_portrait.png`(+ `.import`, 투명 알파·최대512px·밉맵).
- `DroneHud.panel_rect`는 창 높이에 맞춰 카드를 배치하며, `CalmHud`의 적 HP바 보호 영역도 그 위치를 사용한다.
- `tests/hud_preset_check.gd`: 실제 창4크기에서 좌하단 위치·상단/스킬 비겹침, 초상 로드/알파, 다른 프리셋의 기존 패널 복귀.
- 기준/최종 렌더·합체·지원 준비·직접 청소 화면·스킬 픽셀 비교·실제 프롬프트/검증 로그: `output/drone-support-ui-20261004/`.

### 2026-10-04 적용: 장비 그림 원형 버튼

기본 STRIKER의 오른쪽 아래를 사용자 첨부 시안에 맞춰 변경했다. 큰 붉은 광선검(LMB),
주황 총(RMB · T), 보라 부츠(SPACE), 쌍발 부스터(SHIFT), 녹색 에너지 셀(L+R), 미사일(R)을
짙은 남색 반투명 원과 얇은 연보라 테두리 안에 배치한다. 키 배지는 원 아래에 붙인다.
E 돌진은 작은 보조 버튼으로 표시한다. 코드는 `scripts/presentation/round_skill_dock.gd`.

- 탄창은 실제 `mag / MAG_SIZE`, 재장전은 원형 진행도와 RELOAD로 표시한다.
- 회피 쿨다운은 어두운 부채꼴, 부스터는 남은 게이지와 과열 HOT로 표시한다.
- 레이저 둘레 3조각은 실제 에너지, 바깥 호는 충전 단계·회복 진행도를 표시한다.
- 미사일 우상단 수량 배지는 예약탄을 포함하며 실제 발사될 때 차감한다.
- 원 그림은 클릭 영역이 아닌 조작 안내다. 기존 키 입력과 게임 동작은 그대로 사용한다.
- 창 높이에 맞춰 배율을 조정한다. 원형 스킬 첫 적용 때 드론 패널은 버튼 묶음 왼쪽에 뒀으며, 현재 기본 STRIKER는 위 후속 적용의 좌하단 드론 초상 카드를 사용한다.

그림 6장은 내장 imagegen으로 첨부를 참조해 개별 제작했고 `assets/ui/round_skills/`에 저장했다.
PNG 원본 알파를 유지하며 Godot 임포트는 최대 256px·밉맵을 사용한다.
원본 첨부, 생성 프롬프트, 실제 게임 화면과 검증 로그는 `output/round-skill-hud-20261004/`.

## 1. 현재 문제

| 문제 | 영향 |
|---|---|
| 7가지 정보가 같은 크기의 글자 + 같은 굵기의 막대로 한 줄씩 나열 | 중요도(장갑 > 회피 > 탄창 > 나머지) 구분이 없어 위급할 때 눈이 장갑을 바로 찾지 못한다 |
| 매 줄 앞에 `DODGE [Space]` 같은 글자 라벨 | 화면 폭 300px · 높이 360px 를 차지한다. 쿼터뷰라 좌상단 바닥과 적이 가려진다 |
| 조작 키 설명 줄이 화면 아래에 늘 깔림 | 버튼과 키가 떨어져 있어 "어느 게이지가 어느 키인지"를 잇지 못한다 |
| 시선 거리 | 플레이어는 화면 가운데, 조준은 커서 주변. 좌상단까지 시선이 크게 왕복해야 한다 |

## 2. 장르 · 스타일 리서치

이 게임은 **쿼터뷰 3D 트윈스틱 액션 슈터 + 로그라이트 섹터 런**, 연출은 **젠레스 존 제로(ZZZ)풍 과장 액션**,
주인공은 **메카(HEXBLADE)** 이고 배경은 네온 · 보라/청록 팔레트다.

| 참고작 | HUD 배치 | 가져올 점 |
|---|---|---|
| 젠레스 존 제로 | 좌상단 캐릭터 카드(초상 · 사선 HP 바), 우하단 원형 스킬 버튼에 키 표시 · 쿨다운 부채꼴 | 이 게임 연출의 원본. 사선 · 기울임 · 원형 버튼 문법이 그대로 어울린다 |
| Returnal · Hades | 왼쪽 아래 생존(체력 · 회피), 오른쪽 아래 무장(무기 · 탄 · 보조 자원) | 쿼터뷰에서 위쪽은 앞(진행 방향)이라 비우고, 아래 두 모서리를 쓰면 시야가 넓다 |
| Armored Core VI · Ruiner · Nex Machina | 기체 · 조준점 주변에 정보를 붙이는 디제틱(diegetic) 배치, 평소엔 옅고 변할 때만 진해진다 | 시선 이동이 가장 적다. 메카 콕핏 감성 |
| Enter the Gungeon · Hyper Light Drifter | 좌상단 유지, 글자 대신 아이콘 · 칸 | 기존 배치에 익숙한 사람에게 가장 적은 변화 |

공통 원칙: (1) 장갑은 가장 크고 가장 먼저 보이게, (2) 키는 해당 게이지 바로 옆에, (3) 찬 게이지는 옅게 · 변하는 게이지는 진하게,
(4) 헥스 · 사선 · 노란 두 눈 같은 기체 모티프를 HUD 형태에 녹인다.

## 3. 프리셋

| # | 이름 | 배치 | 성격 |
|---|---|---|---|
| 1 | **STRIKER** (기본) | 좌상단: 메카 초상 + `HEXBLADE` + 녹색 사선 장갑 5칸·수치 + 주황 부스터·에너지. 상단 중앙: 방/적·WAVE/LOCK. 우상단: 프레임 미니맵·점수·콤보. 좌하단: TRIAD 초상 카드·지원·현재 상태·Q/X/Z. 우하단: 장비 그림 원형 버튼 6종과 작은 E 돌진, 실제 탄창·미사일 수·쿨다운·충전 표시. 키는 작은 배지 | 사용자 채택 차분한 HUD + 원형 장비 HUD |
| 2 | **CORNERS** | 왼쪽 아래 판: 헥스 장갑 5칸 · 회피 마름모 · 부스터. 오른쪽 아래 판 `ARMS`: 탄창 큰 숫자 + 눈금, 에너지 · 미사일 아이콘 줄(획득 · 소모 연출 그대로) | Returnal/Hades. 위쪽 시야가 가장 넓다 |
| 3 | **COCKPIT** | 기체 둘레 호: 왼쪽 장갑 5조각, 오른쪽 부스터(쓸 때만), 발밑 회피 쿨다운(쿨다운 중에만). 조준점 둘레 호: 오른쪽 아래 탄창, 위 에너지 3조각, 왼쪽 아래 미사일 수. 좌상단에는 아주 작은 상태줄만 | AC/Ruiner 디제틱. 시선 이동 최소, 화면이 가장 깨끗하다. 큰 폭발 · 최대 레이저 순간엔 묻힐 수 있다 |
| 4 | **TACTICAL** | 좌상단 한 장짜리 판(모서리 깎음): 사선 장갑칸, 아이콘 + 막대 + 키 3줄(회피 · 부스터 · 레이저), 탄창 숫자 + 눈금, 에너지 · 미사일 아이콘 줄. 찬 게이지는 옅게 | 기존 자리 유지, 크기 약 절반 |
| 5 | LEGACY | 기존 세로 나열 | 비교용 |

모든 프리셋 공통 연출: 맞으면 장갑칸이 흔들리고 깎인 칸이 하얗게 남았다가 따라 내려간다 · 장갑 1칸이면 붉게 맥동 ·
탄 5발 이하 붉은색 · 재장전 중 눈금이 차오름 · 부스터 과열 깜빡임 · 관통 일격 남은 시간 표시 · 궁극기 슬로우 중에도 실제 시간으로 움직인다.
프리셋 1~4 에서는 버튼마다 키가 붙어 있으므로 아래 조작 안내 줄을 짧게 줄이고 8초 뒤 완전히 걷어 낸다.

## 4. 고를 때 볼 점

- 방 전투(섹터 런): 적이 사방에서 오고 위쪽이 진행 방향 → CORNERS · COCKPIT 이 시야에 유리
- 보스전(MAMMOTH · VULCAN · HALO WARDEN): 위 가운데가 보스 체력바 → STRIKER 카드는 720p 에서도 체력바와 겹치지 않게 폭을 잡았다
- 연출 통일감: STRIKER (ZZZ 문법 그대로)
- 정보를 거의 안 보는 숙련 플레이: COCKPIT

하나로 정하면 나머지 프리셋 코드를 지우고 기본값(`HudPresets.current`)만 남기면 된다.
