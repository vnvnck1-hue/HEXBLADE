# 데미지 로그 (피해 숫자)

코드 `scripts/presentation/damage_log.gd` (`DamageLog`, 화면 레이어 Control 하나가 `_draw` 로 모두 그림), 연결은 `MocoFX.report / status`.
글꼴 ARCO (`assets/fonts/ARCO.otf`, SIL OFL).

## 출발점: 땅굴크루 v7.8.1 드릴 데미지 로그

사용자 게임 `tunnel-crew-infinite-mode-v7.8.1.html` 의 `J.dmg`(생성) · `J.update` 의 `dm` 구간 · `J.drawDmg` 를 바탕으로 했다.
가져온 손맛: **크게 튀어나오는 팝 · 세로로 늘었다 돌아오는 눌림 · 위로 튀는 포물선 · 강타 기울기 · ARCO 글꼴 · 크림/노랑 색**.

1차로 원본 수치(크기 21/64, 수명 0.31초, 반투명 .55 갈색 외곽선, 169° 부채꼴 + 강한 중력)를 그대로 옮겼더니
우리 화면에서는 **잘 안 보이고 너무 빨리 사라졌다** (사용자 피드백). 원인:

- 원본은 어두운 굴 위 어둠 오버레이 위에 그려 대비가 강했지만, 우리 바닥은 중간 밝기 남보라 → 얇은 반투명 외곽선이 묻힘
- 숫자가 맞은 몸 높이에서 생겨 아래로 떨어지며 흰 피격 섬광·타격 버스트에 겹침
- 0.31초는 드릴처럼 같은 자리에 계속 숫자가 쏟아지는 게임용. 우리는 적이 움직이고 시선이 넓게 퍼짐
- 연사하면 같은 자리에 숫자가 겹쳐 "413" 같은 덩어리가 됨

## 프리셋 (J 키 / `--dmglog=stack|bounce`)

씬을 다시 불러도 유지된다 (`DamageLog.preset`, static). 숫자마다 생길 때의 프리셋을 기억하므로 바꾼 순간 이미 떠 있는 숫자는 그대로 끝난다.

| | STACK | BOUNCE (기본, 2026-10-06~) |
|---|---|---|
| 움직임 | 위쪽 36°로 약 40px 튀고 머리 위에 떠 있음, 정점 뒤 초당 22px 로만 가라앉음 | 위쪽 70° 부채꼴로 속도 470 (정점 약 70px) → 중력 1550, 감속 거의 없이 포물선으로 떨어짐 |
| 연사 | 이전 숫자를 위로 밀어 살짝 겹친 기둥 (글자 × 0.68, 대상당 6) | 쌓지 않음 — 좌우로 흩어지며 각자 떨어짐 |
| 회전 | ±0.6 rad/s 감쇠 | 날아가는 쪽으로 기울며 돎 (가로 속도 × 1.2 rad/s) |
| 수명 · 사라짐 | 0.95 / 강타 1.2초, 68% 부터 | 0.85 / 강타 1.0초, 55% 부터 (떨어지기 시작할 즈음) |

크기·외곽선·팝·색·연속 타격 열기·합산은 두 프리셋이 같다. 값은 `B_*` 상수.
캡처: `output/damage-log-20261004/sheet_bounce_chain.png` (`--dmglog=bounce`, 파일 이름 앞 `bounce_`).

## 연속 타격 열기

같은 대상을 끊김 없이(다음 타격이 **0.75초** 안에) 때릴수록 열기 h 가 0 → 1 로 오른다 (**14타**에서 최대, 끊기면 처음부터).
0.06초 합산으로 묶인 피해는 한 타로 센다. 강타는 열기가 낮아도 h 0.4(노랑)부터 칠한다.

| h 에 따라 | 0 | 1 |
|---|---|---|
| 글자 색 | 크림 `#FFFAF0` | → 연노랑 `#FFF1A0` → 노랑 `#FFC93A` → 주황 `#FF8A2A` → 붉은 분홍 `#FF3B5C` |
| 외곽선 | 짙은 남보라 `#1B0B38` | 짙은 와인 `#3D0717` |
| 후광 | 없음 | 외곽선 바깥 주황 `#FF6A1E` 옅게 (투명도 .22, 글자 × .08) |
| 크기 | ×1 | ×1.1 |
| 팝 | 1.55 (강타 1.8) | +0.12 (상한 1.9) |
| 세로 눌림 · 기울기 | 0.45 · ×1 | 0.5 · ×1.3 |
| 튀는 힘 · 수명 | ×1 · +0 | ×1.08 · +0.1초 |
| 떨림 | 없음 | 생긴 직후 0.2초 ±1.5px |

3차에서 크기 ×1.32 · 팝 +0.45 · 떨림 6px · 진한 후광 · 일반 숫자 흰 번쩍임까지 넣었으나 "연출이 너무 과하다"는 피드백으로
색 변화만 살리고 움직임 변화는 대폭 줄였다 (흰 번쩍임은 다시 강타만).

값은 `DamageLog` 의 `CHAIN_*` · `HEAT_*` 상수. 캡처 `output/damage-log-20261004/sheet_chain.png` (3 · 7 · 11 · 15 · 20타).

## 그 밖

- STUN! 같은 상태 글자는 그 대상의 숫자 기둥 위에 민트로 뜬다 (포물선 없이 감속하며 상승).
- 시간은 실제 시간 (히트스탑·슬로모션에 멈추지 않음). `--vfx=old` 면 숫자 없음.
- 원본의 드릴 과열 연출(숫자가 붉어짐)은 대응하는 자원이 없어 넣지 않았다.
