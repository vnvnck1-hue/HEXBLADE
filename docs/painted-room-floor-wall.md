# 원화 3안 · 바닥과 벽의 실제 텍스처 시험

선택 기준은 `output/painted-room-concepts-20261012/v2/03_cream_service_dock.png`. 크림 벽·연보라 바닥·보라 구조재·코랄 포인트의 핸드드로잉 원화를 실제 PNG로 제작해 별도 정비실에 적용한다.

## 실행

로비 → 테스트 씬 → **핸드페인팅 정비실 · 크림 / 연보라**. 또는 `launchers/scenes/painted_room_study.cmd`.

- B: 현재 시험 ↔ 본편 원본. 원본 메시와 재질도 함께 복원한다.
- 보정색 ↔ 조명 받기: 저채도·저명도로 보정된 표면색과 실제 광원 반응 비교.
- 가구·설비 보기 / 숨기기: 아직 이전 외형인 프랍을 숨겨 바닥·벽만 확인.
- 3안 바닥·벽 다시 보기: 파일 교체/원복 후 새 기본 시험 재질 복구.
- 1~5 시점, L 조명, 우드래그 회전, 휠 확대, F 시점 복구, Tab UI, F12 저장, Esc 로비. 기존 파일 열기/체커/원복 기능도 유지한다.

## 연결 방식

`assets/textures/painted_room/`의 `floor_room.png`, `wall_panel.png`, `wall_frame.png`는 승인 원화를 명시적 참고로 내장 image_gen이 제작한 표면 그림이다. 저장 원본과 생성 원본의 바이트는 동일하며 런타임에 색/붓질을 다시 합성하지 않는다. lossless 임포트와 미프맵을 사용한다.

`scripts/presentation/painted_room_study.gd`는 기존 정비실을 상속하고, 바닥/벽 메시만 인스턴스 전용 ArrayMesh로 복사해 UV를 새 그림에 맞춘다. 바닥 그림은 현재 8×6m 정비실의 전용 이미지이며, 모든 방에 타일링하는 범용 텍스처가 아니다. 생성 그림의 줄눈을 기존 2m 판 경계에 맞춰 UV 구간을 배정한다. 설비 데크와 판 옆면은 보라 구조재 그림을 쓴다.

벽의 물리적으로 분리된 메시 부품을 위치 연결로 찾아 얇은 실제 패널과 프레임을 분리한다. 패널 그림은 각 패널의 정면 좌표에, 프레임 그림은 로컬 면 좌표에 매핑한다. 기존 GLB/공유 메시/재질은 수정하지 않으며 B/파일 교체 때 원본 메시를 복원한다. W01 뿐 아니라 낮은 벽/엄폐물/기둥의 패널에도 적용한다.

2026-10-12 후속 사용자 요청으로 `painted_room_palette.gdshader`를 사용하는 ShaderMaterial로 변경했다. 원본 PNG를 그대로 샘플링한 뒤 선형 RGB의 휘도를 기준으로 채도를 0.18로 낮추고 밝기에 0.22를 곱한다. 이 값은 화면에 보이는 명도/채도의 비율이 아니라 셰이더 보정 계수다. 금속성0·거칠기1·반사광 없음. 보정색 확인은 unshaded, 조명 확인은 실제 광원을 받으며 두 모드 모두 낮춘 색을 유지한다. 붓질·UV·모델은 동일하다. 원본 PNG 파일은 보존하며 캐릭터/표식/UI에 전체 화면 색 보정을 적용하지 않는다. 시험 씬에 하늘 리소스가 없으므로 환경광은 실제 Main처럼 명시적인 COLOR source를 사용한다. 본편 원본 비교에도 동일한 시험 조명을 적용한다.

## 범위와 후속

바닥과 벽의 그림을 실제 엔진에서 확인하는 단계다. 가구·벽 장치·탱크·배관은 이전 모델/표면을 사용한다. 원화의 새 계단/난간/소품이나 과장된 실루엣까지 전체 장면을 재현한 결과는 아니다. 게임 본편의 랜덤 방에 새 텍스처를 연결하지 않았다. 다음은 사용자 피드백에 따른 바닥·벽 보완, 또는 가구와 설비의 같은 스타일 제작이다.

원본 제작 프롬프트와 초기 적용 기록은 `output/painted-room-applied-20261012/`, 최신 낮춘 색의 실제 화면/검증은 `output/painted-room-muted-20261012/`에 보관한다. 전용 구조/자원 격리 검사는 `tests/painted_room_check.gd`, 실제 렌더 캡처는 `_capture/painted_room_show.gd`다. 정지 메카/단순 표식 비교는 `_capture/painted_room_readability.gd`이며 전투 플레이 검증과 구분한다.
