# 광선검 6단 콤보 · 플레이어 액션 연출

코드: `scripts/sword_combo.gd` (콤보 상태·자세·판정 호출), `scripts/saber_trail.gd` (광선검 잔상 리본),
`scripts/player.gd` `combo_strike()` (한 타 판정) · `combo_shot()` (콤보 중 공중 사격), `scripts/fx.gd` `crescent()` (초승달 섬광),
`scripts/presentation/player_motion.gd` (재장전·사격·레이저·미사일 동작).
확인: 콤보 `--comboshow`, 사격·재장전·레이저·미사일 `--actshow`
(`powershell -File tools\godot.ps1 wait --fixed-fps 60 res://scenes/main.tscn -- --capture=<공백 없는 폴더> --every=1 --seconds=8 --comboshow`).

## 참고한 문법 (젠레스 존 제로 · 드래곤볼)

| 참고 | 무엇을 가져왔나 | 어디에 |
|---|---|---|
| 키 포즈 홀드 → 1~2F 폭발 → 넘쳤다 복귀 (애니풍 리미티드 애니메이션) | 준비는 ease-out 으로 감기고 멈칫, 스윙은 expo 로 첫 프레임에 거의 다 뻗고, 여운은 back | 모든 단, `PlayerMotion` 의 키 포즈 트랙 |
| 엘렌·제인의 초고속 연타 (한 입력에 여러 번 베기) | 한 단 안에 cut 을 여러 개 두고 1~2F 간격으로 이어 벤다 | 1타 삼연참, 3타 난무 |
| 주연·하루마사식 근접 ↔ 사격 전환 | 베다가 공중제비로 물러나 총을 쏘고 2F 만에 되돌아와 찌른다 | 2타 반동 사격 |

| 회전 다단히트 (코린·엘렌 회전기) | 0.33초에 5바퀴, 7번 판정, 몸은 한 틱 걸러 사라져 잔상만 보인다 | 4타 선풍 `spin` |
| 미야비의 지연 참격 (칼집에 넣은 뒤 칼자국이 터진다) | 착지 0.16초 뒤 허공에 칼자국 6개가 연달아 그어지며 범위 안 적이 베인다 | 6타 `after` |
| 다단히트의 짧은 정지 | 중간 타격은 0.014~0.035초, 마무리 타격만 0.06~0.13초 히트스탑 | `stop` |
| 회피 순간 사라짐 | 대시 첫 2프레임은 몸을 숨기고 출발 자리 잔상만 남긴다 | `player.gd` 드릴 회피 |

HoYoverse 는 내부 애니메이션 수치를 공개하지 않으므로, 프레임 수는 공개 플레이 영상에서 보이는 리듬을 60fps 기준으로 옮긴 값이다.

## cut 확장 키 (`sword_combo.gd`)
- `hits`: 스윙 동안 고르게 나눠 판정하는 횟수. 마지막 판정은 스윙 끝.
- `blink`: 준비 직전 대상 둘레로 이만큼(도) 돌아 순간이동. 벽이면 반대쪽, 그래도 막히면 제자리.
- `gun` + `shots`·`gap`: 근접 판정 대신 스윙 동안 사격. 대상이 살아 있으면 매 발 대상을 겨눈다.
- `spin`: 회전 베기. 타격마다 몸 둘레 가로 초승달, 몸은 깜빡이며 잔상, 광선검 잔상은 약하게(boost 0.3).
- `dashin`: 2F 돌진 찌르기. 잔상·무적·FOV 펀치.
- `sub`: 잔상 보간 밀도 (많이 도는 동작일수록 크게).
- `after`: 착지 뒤 지연 참격 `{n, delay, gap, dmg, radius}`.
- 회전 키(`pitch`·`uy`)는 구간이 바뀔 때 -π~π 로 감는다 (`_wrapped`). 한 바퀴 돈 뒤 다음 구간이 거꾸로 풀리지 않는다.
  선풍은 다리가 `uy × 0.4` 로 돌므로 몸 5바퀴 = 다리 2바퀴로 맞춰 끝 자세가 튀지 않는다.

## 연결 규칙
- 한 단의 타격 중 하나라도 **유효 적중**(장갑에 막히지 않은 피해)이면 성공. 사격 cut 의 탄은 연결 판정에 넣지 않는다.
  - 선입력이 있으면 캔슬 지점(여운 4~5F)에서 곧바로 다음 단.
  - 입력이 없으면 여운이 끝난 뒤 `LINK_TIME` 0.36초 동안 다음 단을 기다린다.
- 헛침: 휘두른 쪽으로 몸이 더 돌고 앞으로 쏠리는 오버스윙 자세(0.3초) + 검 봉인 `WHIFF_LOCK` 0.46초. 콤보는 1타로 돌아간다.
- 막힘(구체 크롤러 장갑): 칼이 위로 튀고 뒤로 밀리며 같은 봉인.
- 6타 뒤 0.24초 숨 고르기 (보스 `no_slash_reset` 이면 0.7초). 마무리에만 CRESCENT 글자가 뜬다.
- 대시·피격·경직·밀려남·패링·레이저·궁극기가 콤보를 즉시 끊는다. 공중에서 끊기면 부유 스프링이 높이를 받아 부드럽게 떨어진다.
- 1타는 조준 방향 70° 안의 적만 노린다. 이어지는 단은 사방에서 찾되 정면일수록 우선하고, 방금 벤 적이 살아 있으면 계속 그 적.
- 각 단의 자체 이동량(반동·찌르기)을 빼고 남은 거리만 다가가며(순간이동 뒤 cut 은 빼지 않음), 적 몸 앞(반경 + 0.8m)에서는 더 파고들지 않는다.

## 이징 · 게임필
- 준비: ease-out cubic — 빠르게 감기고 멈칫하는 긴장.
- 스윙: ease-out expo — 첫 프레임에 거의 다 뻗는 폭발. 회전 베기는 선형(일정한 초고속). 공중회전은 smoothstep, 낙하 높이는 ease-in cubic.
- 여운: ease-out back — 살짝 넘쳤다 돌아온다.
- 스윙 순간 칼은 길이 1.45~1.95배로 늘고 굵기는 얇아진다(스미어).
- 적중 시 히트스탑·흔들림. FOV 펀치는 단의 마지막 타격에만 (다단히트가 카메라를 계속 당기지 않게).

## 사격 · 재장전 · 레이저 · 미사일 (`PlayerMotion`)
기본 자세(`player.gd _animate`) 위에 오프셋을 **더한다**. 매 틱 처음 `pre()` 가 지난 오프셋을 빼고 끝에서 `post()` 가 새로 더하므로
기본 애니메이션의 lerp 가 누적되지 않는다. 콤보 자세 중에는 콤보가 쓰지 않는 사격 팔 들기·총 회전 축에만 더한다.

| 동작 | 연출 |
|---|---|
| 재장전 (1.25초) | 3F 만에 팔을 내리꽂고 상체를 비틀며 빈 탄창을 걷어차듯 뽑아 던짐(바닥에 한 번 튀고 사라짐) → 버팀 → 총을 머리 위로 띄워 세 바퀴 회전(`GunSpin` 축) → 4F 만에 내리꽂아 탄창 장착(불꽃·쇳소리·충격파) → 장전 튕김(총구 섬광) → back 이징 복귀 |
| 사격 | 0.45초 넘게 쉬다 쏘는 첫 발은 총구가 튀어 오르는 퀵드로, 매 발 상체가 좌우로 번갈아 비틀림 |
| 충전 | 단계가 오를수록 다리를 벌리고 낮게 버티며 광선검 팔이 총 팔을 받친다. 단계 상승마다 움찔 |
| 충전 레이저 | 2F 만에 상체가 뒤로 꺾이고 총이 치솟는 반동 포즈 → 0.12초 버팀(떨림) → 탄성 복귀. 강하면(>0.5) 밀려나는 동안 발이 바닥을 긁어 불꽃·쇳자국 |
| 지속 레이저 | 깊게 앉아 다리를 벌리고 버티는 자세 + 진동 |
| 미사일 락온 | 낮게 웅크린 준비 자세 (슬로우 중이라 실제 시간으로 붙는다) |
| 미사일 발사 | 3F 만에 뛰어올라 가슴을 젖히고 양팔을 벌림 → 발사마다 몸이 떨림 → 다 쏘면 0.1초에 내리꽂듯 착지(충격파·먼지) → 복귀 |
| 회피 | 첫 2프레임 몸이 사라지고 출발 자리에 하늘빛 잔상 |

## 광선검 특수기 (`scripts/blade_tech.gd`)

| 기술 | 입력 | 동작 |
|---|---|---|
| 기 모으기 | 좌클릭 0.2초(`HOLD`) 넘게 유지 | 제자리에 서서 낮게 웅크려 칼을 등 뒤로 당긴다. 1.1초(`CHARGE_TIME`)에 최대. 노즐을 -82°까지 눕혀 뒤로 뿜고, 불꽃 혀(1~3F 수명 박스)·불티·배기·`boost_wash`, 촤라라락 소리(roll/dash 간격 0.11→0.028초, 높이 1.2→2.1). 바닥 경로 미리보기 3선, 최대면 분홍으로 깜빡임 |
| 줌아웃 | 기 모으는 동안 | 모은 정도 0.25·0.5·0.75·1.0 문턱마다 `CameraRig.set_charge_zoom()` 로 한 칸씩 (1.0 → 1.1 → 1.2 → 1.31 → 1.45). 단계가 오를 때 줌 스프링에 뒤로 차는 충격을 넣고 단단한 스프링(70)으로 툭 물러난다. 돌진 끝 0.35초 뒤 1.0 |
| 일반 돌진 | 최대 전에 놓기 | k 에 따라 4~9m · 0.1~0.16초 · 폭 1.1~1.5m · 피해 6~16. 칼을 앞으로 1.5~2배 늘여 찌르며 지나간다. 경로 위 적은 한 번. 끝에서 초승달 + 충격파. k≥0.3 이면 잔상 줄기 3가닥 |
| TEMPEST | 최대에서 놓기 | 14m · 0.36초 · 폭 1.15m(예전 2.3m의 절반). 몸을 눕혀 6바퀴 드릴 회전, 칼을 옆으로 뻗되 길이 0.9배(예전 1.8배). 광선검 리본 수명을 0.5초(`SPIRAL_LIFE`, 평소 0.038초)·폭 1.1배로 바꿔 경로에 광선검 색 나선 잔상이 남는다(틱 사이 각도를 잘게 샘플, 사라진 뒤 되돌림). 같은 적을 0.06초마다 최대 5번 × 6, 끝에서 반경 1.6m 원형 참격 10(초승달·충격파·굴절도 절반). 잔상 줄기 5가닥(`BeamAfterimage`, 광선검 빨강·분홍·흰빛) |
| 연기 잔흔 | 돌진 끝 | 최대 돌진은 연기 크기·충격파·굴절을 예전의 절반으로. 0.9m 간격으로 0.08초 + 경로 비율 × 0.1~0.16초 늦게 연기가 터져 경로를 따라 쫓아오고, 끝에 닿는 순간 큰 연기·먼지·굴절·착지음 |
| 회피 레이저 | 콤보 중(자세 중이거나 링크가 열려 있을 때) 좌+우 동시 | `SwordCombo.suspend()` 로 콤보를 멈추고 다음 단 링크를 연다. 19m/s 로 뒤로 물러서며(감속, 무적) 4F 뒤 `_fire_laser(0.55)` (에너지 소모 없음, 임팩트 프레임 없는 단계). 물러서는 중 누른 검은 버퍼에 남는다 |

돌진이 끝나면 속도를 곧바로 3m/s 로 떨어뜨린다(남은 속도로 미끄러지지 않게). 대시·피격·경직·궁극기는 `_combo_break()` 에서 함께 끊는다.

## 광선검 잔상 (SaberTrail)
- 수명 0.038초(약 2프레임). 손잡이~칼끝(1.65배로 뻗음)을 이어 만든 넓은 리본. 가산 혼합 형광색.
- 스윙 중에는 지난 틱과 이번 틱 사이 자세를 최대 12번 더 계산해 칼 위치를 넘기므로, 한 프레임에 170° 도는 칼도 매끈한 호를 그린다.
- 늙을수록 안쪽 경계가 칼끝 쪽으로 올라와 끝이 뾰족한 초승달이 된다. 흰 심 → 형광 분홍 → 전기 보라, 칼끝 너머로 가는 실선.
- 몸에 대한 칼끝의 상대 속도가 7m/s 이하면 보이지 않는다 (돌진처럼 몸이 통째로 움직이는 것은 잔상을 만들지 않는다).
- 관통 일격이 준비된 동안(칼날이 불타는 동안)은 불꽃빛으로 물든다.

## 몸 리본 (대시 · 돌진)
- `SaberTrail.body()` 로 같은 리본을 팔·다리에 붙인다: 왼팔 어깨→포구, 오른팔 어깨→손, 양 무릎 위→발끝 (`player.gd` `_ready`).
- 대시(드릴 회전)·돌진(콤보 파고들기·관통 일격) 중에만 켜진다. 회전하면 몸 둘레로 나선처럼 감기고, 돌진하면 뒤로 곧게 끌린다.
- 색: 몸체 장갑과 같은 크림 계열. 수명 0.3초. 대시·돌진 중에는 광선검의 분홍 초승달 리본을 끈다.

## 돌진 마찰 (`scripts/rush_fx.gd`)
- 돌진(콤보 파고들기·관통 일격)과 강한 레이저 반동으로 밀려나는 동안 두 발 아래 바닥의 이전 → 현재 구간을 넘긴다 (`player.gd` `_update_rush`).
- `scrape()`: 긁힌 구간을 따라 뒤·위로 튀는 가는 불티. `heat()`: 달아오른 쇳자국 두 줄(1.5초에 식음). `brake()`: 멈추는 순간 불꽃 + 쇳소리.
- 확인: `--rushshow` (옆 대시 → 먼 적 돌진 ×2 → 관통 일격).
