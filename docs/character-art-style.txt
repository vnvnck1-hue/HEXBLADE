작업 방식:
1. 새 컨셉 그림은 먼저 눈으로 확인해 캐릭터 특징만 텍스트로 추출한다.
2. 생성 도구의 참조 이미지에는 최초 네 장만 넣는다. 새 컨셉 그림과 중간 생성물은 새 캐릭터의 그림체 기준에 넣지 않는다.
3. 얼굴과 상반신 시안으로 스타일을 먼저 대조한다. 본 사용자의 전체 요청 범위가 전신/다수 시점이면 시안 검증 후 그 범위를 계속 수행한다.
4. 검증에는 최초 원본을 사용한다. 새 결과를 기준으로 삼아 차이를 누적하지 않는다.
5. 승인된 같은 캐릭터의 표정/의상 편집은 정체성 보존을 위해 해당 캐릭터를 편집 대상으로 사용할 수 있으나, 그림체의 최종 판단 기준은 여전히 최초 네 장이다.
6. 생성 결과의 완벽한 그림체 일치를 자동 보증하지 않는다. 새 기준 테스트는 사용자 검토 전이며, 최초 원본을 대체하지 않는다.

- 얼굴: 원본 수준의 머리/어깨 비율, 짧고 뾰족한 턱, 간결한 작은 코/입, 기울어진 위 눈꺼풀과 짙은 윗속눈썹. 원형 인형 눈이나 길어진 사실적 얼굴을 피한다.
- 눈: 원본처럼 단순하고 뚜렷한 홍채/동공/작은 반사. 반짝임과 홍채 세부를 늘리지 않는다.

- 명암: 넓은 기본색과 큰 그림자 면, 보라 계열의 재질 그림자와 절제된 칠한 하이라이트. 현실적인 3D/에어브러시 그라데이션 금지.

- 의상: 부피를 보여주는 큰 주름만 사용. 촘촘한 스티치·잔주름·때·미세 하드웨어를 임의로 추가하지 않는다.
