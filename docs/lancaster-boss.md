# LANCASTER — 광폭화 보안 로봇 (보스)

버려진 시설의 보안 로봇이 폭주해 벌레든 침입자든 무자비하게 지운다. 컨셉 시트 4장(PURGE FIRE · CLOSE PURGE · AREA LOCKDOWN ·
THREAT & MOTION)을 바탕으로 했다. 시트의 3:1 크기는 무시하고 **플레이어 메카(1.80m)의 두 배 = 3.6m** (보스방 8 키로 ×1.5 / ×2.5).
다른 보스와 달리 플레이어처럼 재빠르게 옆걸음 · 분사 대시로 움직이며 템포 높게 싸운다.

체험: `training.cmd` → 허수아비 홀 **왼쪽 벽의 넓은 통로** 끝 보스방. 들어가면 기동하고, 패널 · 숫자 키가 보스 프리셋으로 바뀐다.

## 모델 (관절 계약)

원본 외형(부피 · 표면 · 텍스처)은 바꾸지 않고 파츠를 관절로 묶기만 했다 (자르기 없음). 왼쪽(-X) = 개틀링 팔, 오른쪽(+X) = 집게 팔.

```
pelvis ─ thigh_l/r > shin_l/r > foot_l/r            ← 하체 (이동 방향)
       └ torso (허리 피벗)                           ← 상체 (조준 방향, 따로 돈다)
           ├ lights (청록 표시등 면) · vent_l/r (가슴 통풍구) · pod_l/r (어깨 위 보안 포드)
           ├ shoulder_l > upperarm_l > forearm_l > barrel_l (총열, 축 둘레로 회전)
           └ shoulder_r > upperarm_r > forearm_r > hand_r > claw_a (갈고리) / claw_b (엄지)
부착점 pt_muzzle · pt_eject · pt_claw · pt_spike · pt_jet_l/r · pt_vent_l/r · pt_lens_l/r · pt_foot_l/r · pt_eye_1~3 · pt_chest
```

가슴 얼굴의 눈 세 점은 큰 면 위 텍스처라 떼어낼 면이 없어, 빌드 때 면을 촘촘히 찍어 청록 자리를 셋으로 묶어 `pt_eye_*` 로 두고
게임에서 발광 구를 얹는다 (광폭화 때 붉게).

## 애니메이션 (LancasterRig)

- **하체**: 두 발을 월드에 고정하고 2관절 IK. 발이 제자리에서 벗어나면 번갈아 딛는다(빠를수록 보폭 · 박자 빠름), 디딜 때 골반이 내려앉고
  먼지 · 발소리 · 진동. 디딘 발이 다리 길이 밖이면 골반을 낮춰 발이 뜨지 않는다. `plant`(버팀)면 제자리 디딤을 멈추고(돌 때만 딛는다),
  `air`(분사 대시 · 도약)면 다리를 접고 발이 몸을 따라온다. `stomp` 오른발 들기, `kneel` 무릎 꿇기.
- **상체**: 하체 yaw 와 조준 yaw 의 차만큼 torso 가 스프링으로 비틀린다(±1.7rad). 하체는 이동 방향을 보고, 뒷걸음질이면 조준 쪽을 본 채 뒤로 걷는다.
- **팔 · 몸통 자세**: `pose` 사전(관절 → 기본 자세에서 더할 회전)을 관절 스프링이 따라간다. `snap()` 임팩트 프레임, `kick()` 반동 · 피격.
- **개틀링**: `gun_aim` 만큼 상완을 돌려 총열 축이 조준점을 향하게(자세 위에 덧씌움), 총열은 `spin` 으로 돈다.
- 집게 벌림 · 포드 회전/들기 · 등 분사 불꽃 · 총열 열기 · 통풍구 열기 · 눈/표시등 색.

## 보스방 (TrainingBossRoom)

홀(30×22) 왼쪽에 폭 5칸 · 길이 8칸 통로와 28×24칸 방(`ArenaMap._stamp` · `_carve_line`). 감염 오염물은 홀에만. 허수아비 씬 자체에만 만들고
상속 씬(드론 · 유체 · 배경 시험장)에는 없다. `--bossroom=off` 로 끔.

| 키 (방 안) | |
|---|---|
| 1 | 다시 소환 (기동 연출부터) |
| 2 | 패턴 세트: 전체 · 제압 사격(burst/sweep/slug) · 근접 제압(claw/spike/stomp) · 구역 봉쇄(pods/stomp/sweep) · 패링 연습(claw/slug) · 이동만 |
| 3 | 처치 가능 ↔ 무적 (체력 1 아래로 안 내려가고 잠시 뒤 회복) |
| 4 | 페이즈 1 ↔ 2 (광폭화 연출) |
| 5 | 템포 보통 ×1 · 빠름 ×1.25 · 광폭 ×1.55 |
| 8 | 크기 플레이어 × 2.0 / 1.5 / 2.5 |
| 9 | 행동 정지 (제자리 조준만) |
| 0 | 다음 패턴 바로 시전 (세트에서 차례로) |
| 6 · 7 | 재화 무한 · 플레이어 무적 (허수아비와 같음) |

방 안에서는 카메라 시선을 보스 쪽으로 조금 옮기고 ×1.18 줌아웃한다 (`CameraRig.frame_bias` · `frame_zoom`).
확인용 인자: `--bossroom`(입구에서 시작, 봇은 보스와 싸움) · `--bossset=<id>` · `--bosstempo=0~2` · `--bossphase=2` · `--bossimmortal`.

## 임팩트 스윙 (패링 공격)

광선검 콤보(준비 → 1~4프레임 스윙 → 여운)와 같은 결. 돌진하는 동안은 감긴 준비 자세 그대로 몸만 앞으로 기울여 날아들고,
닿기 0.05초 전에 `LancasterRig.swing()` 이 관절을 스프링 없이 **3프레임** expo 이징으로 임팩트 자세(찌르기 = 쭉 뻗음 · 내려찍기 = 바닥까지 ·
휘둘러 베기 = 반대편까지)로 몰아 뻗고, 끝나면 남은 속도가 스프링에 넘어가 살짝 지나쳤다 돌아온다. 같은 순간 금빛 잔상 호(`LancasterFX.smear`,
검 궤적 셰이더의 금빛 사본) · 찌르기 섬광 줄 · 늘였다 찌그러뜨리기 · 낮은 바람 소리 · 카메라 반동. 스윙 순간 금빛 전신 덮개는 걷어 자세가 읽히게 하고
(판정 창은 그대로). 패링되어도 튕겨 나지 않는다(연결 동작으로 이어짐). 확인: `_capture/lancaster_swing_show.gd` → `output/lancaster-boss-20261006/sheet_swing_*.png`.

## 패링 성공 연출 ([용어](parry-camera-screen-effects.md))

공통 `Parry._success` 가 적의 `parry_feel()`(없으면 "heavy")로 세기를 나눈다. LANCASTER 는 연타의 중간 타 = "light", 마지막 타 = "heavy".

| | 중간 타 (light) | 마지막 타 · 단발 (heavy) |
|---|---|---|
| 히트스톱 (실제 초, 기본 HARD) | 0.11 사실상 완전 정지(시간 배율 0.002), 슬로우 없음 → 곧바로 정상 속도 | 0.16 완전 정지 → 슬로우 0.3배 몇 프레임 → 복귀 |
| 임팩트 프레임 | 반전 1프레임 | 원판 1 + 반전 1프레임 |
| 접촉점 VFX (`ParryFX.burst`) | 히트 스파크 · 임팩트 버스트(별 · 충격파 고리 2겹) · 반격 빛줄기 · 반격 방향 불꽃 · 굴절 충격파(`Distortion.burst`), 크기 ×0.6 | 같은 구성, 고리 3겹, ×1 |
| 화면 (`ParryFX` 오버레이) | 접촉점 중심 **줌 블러**(8샘플) · **쇼크웨이브 왜곡 고리** · 색수차 · 집중선 · 섬광선, 세기 0.6 | 세기 1 |
| 카메라 (`CameraRig.parry_impact`) | 펀치 인(FOV 펄스 + 다가섬) · 공격 방향 **카메라 킥** · 짧은 셰이크, ×0.75 | ×1.25 + 패링 줌인(`parry_cine`) |

카메라 스프링은 게임 시간이라 히트스톱 동안 멈췄다가 끝나는 순간 툭 튀어 나가고, 스프링으로 원래 구도로 돌아온다(연속 패링에도 누적되지 않게 한 번만큼씩).
**히트스톱 프리셋** (`Parry.STOP_PRESETS`, 보스방 **P / Shift+P**, 실행 인자 `--parrystop=id`, 씬을 다시 불러도 유지):

| id | 중간 타 / 마지막 타 | 성격 |
|---|---|---|
| hard (기본) | 0.11 / 0.16초 | 딱 멈춤 (시간 배율 0.002) |
| shiver | 0.12 / 0.20초 | 멈춘 채 화면이 부들부들 떨림 (카메라 h/v_offset, 실제 시간) |
| crunch | 0.08 / 0.11초 + 2프레임 움직였다 0.07 / 0.09초 다시 정지 | 두 번 끊어 씹히는 느낌 + 약한 떨림 |
| heavy | 0.17 / 0.28초 | 묵직하게 길게 + 떨림 |
| soft | 0.07 / 0.085초 | 예전 값 (배율 0.06, 아주 느리게 움직임) |

플레이어는 패링 성공 뒤 **살짝 경직**(`Player.PARRY_RECOIL` 0.2초, 원거리 패링은 0.12초, 전류 불꽃 없는 `stun_soft`) — 다음 타 섬광 전에 풀린다.

## 소리

분사 소리는 `LancasterFX.jet_burst()` — Sfx 의 `"boost"` 는 플레이어 부스터용 **반복(loop)** 소리라 그냥 틀면 멈추지 않는다(보스전 내내 부스터 소리가 울리던 버그). 짧게 틀고 줄였다 끈다.

## 남은 일

- 효과음은 기존 합성음(Sfx)을 피치만 바꿔 썼다. 전용 개틀링 · 분사 · 유압 소리는 미제작.
- 크기를 바꾸면 판정 반경 · 공격 반경 · 대시 속도가 함께 비례하지만 패턴 수치 밸런스는 ×2.0 기준.
- 본편(섹터 런 등) 보스 배치 · 전용 전장은 아직 없다 (허수아비 씬 체험방만).
