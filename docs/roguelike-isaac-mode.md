# 로그라이크 모드 기획서 — 「HEX DEPTHS」 (아이작의 번제 분석 기반)

작성 2026-10-12 · 상태: **1차 구현 완료(플레이 가능)** · 실행 `launchers\scenes\rogue_run.cmd` 또는 로비 → 테스트 씬 → "로그라이크 · HEX DEPTHS"

> 기존 내러티브(청소업체·사장·드론 파트너·MAMMOTH 등)와 게임 설정은 **이 모드에서 모두 쓰지 않는다**.
> 남기는 것은 **템포 빠른 전투 코어**뿐이다: 이동·대시(패링·2단 대시)·부스터·광선검 6단 콤보·기본 총·충전 레이저·E 도약 내려찍기·R 미사일 궁극기.
> 그 위에 아이작식 **층·방 구조, 경제, 아이템·장신구·알약·카드, 공격 변형/결합, 변신**을 얹는다.

## 1. 아이작의 번제(The Binding of Isaac: Rebirth ~ Repentance) 리서치·분석

> 출처는 게임 자체의 공개된 규칙(플레이·공식 패치 노트·커뮤니티 위키에서 널리 정리된 사실)이다. 개수는 리펜턴스 기준 근삿값이며, 아래 "분석"은 이 프로젝트의 해석이다.

### 1.1 한 판의 구조
| 요소 | 아이작의 규칙 | 재미의 원천 (분석) |
|---|---|---|
| 층(Floor) | 지하실 → 동굴 → 심연 → 자궁 … 2층씩 한 챕터. 층마다 방 그리드를 새로 생성 | 짧은 단위(층 5~8분)의 반복 + 점점 깊어지는 위험 |
| 방 그리드 | 13×13 슬롯 위에 1×1·1×2·2×1·2×2·L자 방을 **문으로 직접** 잇는다. 시작 방에서 BFS로 뻗고 고리를 피한다 | 화면 하나 = 방 하나라 전투 밀도가 높고 경로가 읽기 쉽다 |
| 방 진입 | 들어가면 **문이 잠기고** 적을 모두 잡아야 열림 | 전투 → 보상 → 탐색 리듬이 강제된다 |
| 막다른 방 | 보스방(가장 먼 막다른 곳)·아이템방·상점·희생방·저주방·도전방·서재·아케이드 등 특수방이 **막다른 방**에 배정 | "어디로 갈까"라는 작은 결정이 매 층 생긴다 |
| 비밀방 | 여러 방에 인접한 빈 슬롯에 숨겨짐. **폭탄으로 벽을 부수면** 열림. 슈퍼 비밀방은 한 방에만 인접 | 지도를 읽는 퍼즐 · 폭탄 소비의 이유 |
| 보스 | 층 끝 보스 → 아이템 1개 + 트랩도어(다음 층) | 층마다 확실한 보상과 끝맺음 |
| 악마/천사방 | 보스 처치 후 확률로 문이 열린다. 악마방은 **체력 그릇으로 아이템을 산다**, 천사방은 무료 | 위험과 보상의 거래, 빌드 방향 선택 |
| 저주(Curse) | 층마다 확률: 어둠·미로·미지(체력 ??)·장님(아이템 ??)·길 잃음(지도 없음) 등 | 같은 맵 생성기에 변주를 준다 |
| 챔피언 | 일반 적이 색이 바뀌며 강화(체력·속도·사망 시 폭발 등), 대신 보상↑ | 익숙한 적에 긴장감 추가 |

### 1.2 경제와 체력
- **동전·폭탄·열쇠** 3종 자원. 동전 = 상점, 폭탄 = 비밀방·바위·적, 열쇠 = 잠긴 아이템방(2층 이후)·상점·상자.
- **체력**: 빨간 하트(그릇·회복 가능) · 소울 하트(그릇 없이 덧붙음, 먼저 깎임) · 블랙 하트(깎이면 방 전체 피해) · 영원 하트 등. 피해는 **반 칸 단위**.
- 방을 정리할 때마다 **방 보상**(동전/하트/폭탄/열쇠/알약/카드/배터리/상자)이 확률로 떨어진다.

### 1.3 아이템 체계 (리펜턴스 기준 수집품 약 700개 이상)
| 분류 | 규칙 | 대표 예 |
|---|---|---|
| 패시브 | 주우면 영구 적용. **스탯형**(공격·연사·사거리·탄속·이동·행운) / **공격 변형형**(탄 모양·궤적·효과) / **패밀리어**(따라다니는 동료) / **규칙 변경형**(지도·상점·확률) | Sad Onion, Inner Eye, Spoon Bender, Brimstone, Brother Bobby, Compass |
| 액티브 | 한 개만 소지. **방을 정리할 때마다 충전**(1~6칸), 버튼으로 사용 | D6(리롤), Book of Belial, Necronomicon, Teleport |
| 장신구(Trinket) | 한 개만 소지(교체 시 바닥에 떨굼). 작은 패시브·확률 효과 | Lucky Toe, Rusted Key, Paper Clip |
| 알약(Pill) | **색과 효과의 대응이 판마다 무작위**, 먹어 봐야 정체를 안다. 좋은 것/나쁜 것 혼재 | Health Up, Bad Trip, Telepills, 48 Hour Energy |
| 카드·룬 | 정체가 공개된 즉시 효과. 텔레포트·자원·일시 버프 | The Fool, The Sun, Hagalaz |
| 품질 등급 | 아이템마다 품질 0~4, 아이템 풀(아이템방·상점·보스·악마·천사·비밀)별로 출현 | 풀이 빌드 방향을 은근히 유도 |

### 1.4 시너지 — "아이템이 서로 결합해 새 공격이 된다"
아이작 시너지의 핵심은 **공격 파이프라인의 합성**이다. 각 아이템이 "탄을 만드는 방식"·"탄의 궤적"·"맞았을 때 효과"·"탄의 종류(눈물·레이저·혈사포·폭탄)" 중 한 단계를 바꾸고, 이것들이 곱해져 의도하지 않은 조합이 나온다.
- Brimstone(혈사포) + Tammy's Head → 사방 혈사포 / Brimstone + Spoon Bender → 휘어지는 빔
- Technology(레이저) + Inner Eye → 3갈래 레이저 / Dr. Fetus(폭탄 발사) + Brimstone → 폭발 고리
- Ipecac(폭발 탄) + Spoon Bender → 유도 박격포
- Tiny Planet(공전) + 사거리 → 위성 탄막
→ 분석: **"탄의 종류" × "개수/배치" × "궤적" × "명중 효과"** 를 독립 축으로 만들면 조합 수가 기하급수로 늘어난다. 거기에 몇 개는 **이름 붙은 특수 결합**(전용 연출)으로 보상감을 준다.

### 1.5 변신(Transformation)
특정 테마(태그)의 아이템을 **3개** 모으면 **외형이 바뀌고 강력한 추가 능력**을 얻는다(리펜턴스 15종 정도).
- Guppy(고양이 아이템 3개) → 날기 + 공격 시 파리 소환 / Beelzebub(파리) → 날기 + 파리가 적 탄 흡수
- Seraphim(천사) → 날기 + 공격↑ / Leviathan(악마) → 날기 + 블랙하트 2 / Fun Guy(버섯) → 체력 그릇 +1
- Spun(주사기) → 공격·속도↑ / Bob(독) → 독가스 자취
→ 분석: 변신은 **중간 목표**를 준다("하나만 더 모으면!"). 태그가 보이면 아이템 선택에 이유가 생긴다.

### 1.6 그 밖의 독특한 기믹
- 희생방(가시 바닥에 스스로 피해 → 누적 횟수별 보상) · 저주방(들어갈 때 피해, 대신 보상) · 도전방(체력이 가득일 때만 입장, 웨이브 → 아이템)
- 색이 다른 바위(틴티드 록) → 폭탄으로 부수면 소울하트·열쇠 / 화톳불(닿으면 피해, 쏘면 꺼짐) / 상자(열쇠로 여는 황금 상자)
- 액티브 충전용 **배터리**, 아이템 리롤(D6), 정보 은닉(장님 저주·미확인 알약)
- 같은 판 안에서 **이미 나온 아이템은 다시 나오지 않는다**(풀에서 제거)

### 1.7 그대로 가져오지 않을 것 (분석)
- **느린 템포**: 아이작은 발사 방향 고정·저속 이동. 우리는 360° 조준·대시·검 콤보가 있어 훨씬 빠르다 → 방 크기를 화면 1.3배 정도로 키우고 적 수를 늘린다.
- **불투명한 정보**: 아이템 설명이 게임 안에 거의 없다 → 줍는 순간 이름+한 줄 설명 배너, Tab 키로 보유 아이템·스탯·시너지·변신 진행도 패널.
- **반 칸 피해 + 무적 시간**은 유지(빠른 전투에서도 실수가 바로 죽음으로 이어지지 않게).

### 2.3 층 구성
| 층 | 이름 | 방 수(일반) | 특수방 | 보스 |
|---|---|---|---|---|
| 1 | 녹슨 지하층 | 7~8 | 아이템·상점 + 1 | GORGER (거대 촘퍼) |
| 2 | 배수 터널 | 8~9 | 아이템(열쇠)·상점 + 1~2 | TWINFANG (쌍둥이 요격기) |
| 3 | 주조 구역 | 9~10 | + 2 | CRAWLER KING |
| 4 | 심층 갱도 | 10~11 | + 2 | BROOD QUEEN (개미 여왕) |
| 5 | 코어 외곽 | 11~12 | + 2 | BASTION (포대 요새) |
| 6 | 헥스 코어 | 12~13 | + 2 | HEX HEART (최종) |
- 생성: 시작 슬롯 (4,4) 에서 BFS로 뻗되 **이미 이웃이 2개 이상인 칸은 건너뛴다**(아이작과 같은 고리 방지). 막다른 방이 모자라면 다시 생성.
- 보스방 = 시작에서 가장 먼 막다른 방. 아이템방·상점·그 밖의 특수방 = 나머지 막다른 방.
- 비밀방 = 일반 방 2개 이상과 인접한 빈 슬롯. 그 방향 벽에 **금 간 벽**이 생기고, 폭탄으로 부수면 구멍 → 비밀방(격리된 섬)으로 이동.
- 2층부터 아이템방·상점은 **열쇠로 연다**(금색 차단막에 열쇠를 들고 닿으면 열림).
- 보스 처치 → 아이템 + 트랩도어. 2층부터 확률로 **악마/천사 포털**.

### 2.4 방 종류
| 방 | 규칙 |
|---|---|
| 일반 전투방 | 진입 시 차단막, 적 3~9기(층·방 크기 비례), 15% 챔피언. 정리 → 방 보상 + 액티브 1칸 충전 |
| 아이템방(보물) | 아이템 받침대 1개 (선택지 아이템이 있으면 2개 중 1개) |
| 상점 | 아이템 2개(15¢/진열) + 소모품 3개(하트 3¢, 폭탄 5¢, 열쇠 5¢, 알약 4¢). 할인 쿠폰이면 반값 |
| 보스방 | 보스 + 체력바 → 아이템 · 트랩도어 · 하트 |
| 비밀방 | 동전·폭탄·열쇠 뭉치 또는 비밀 풀 아이템 |
| 저주방 | 들어갈 때 반 칸 피해(비행이면 무시) · 악마 풀 아이템 또는 상자 |
| 희생방 | 가운데 가시 바닥: 밟아 피해 받을 때마다 누적 보상 (1·2회 동전, 3회 천사 아이템, 5회 하트, 7회 악마 아이템 …) |
| 도전방 | 체력이 가득일 때만 입장 · 웨이브 2번 → 보스 풀 아이템 |
| 서재 | 액티브 아이템 2개 중 1개 |
| 악마방 | 아이템 2개, **빨간 체력 그릇 1~2개**로 구매 (그릇이 없으면 소울 3칸) |
| 천사방 | 천사 풀 아이템 1~2개, 무료(하나 가지면 나머지 사라짐) |

### 2.5 체력·피해
- `Player.hp` = 빨간 하트 **반 칸** 수. 시작 3칸(6), 최대 그릇 12칸.
- 소울·블랙은 `RogueRun` 이 들고, Player `hit_guard` 훅이 먼저 깎는다(블랙이 깎이면 방 전체 40 피해).
- 공격력 단위: 아이작처럼 **기본 3.5**. 탄 피해 = 공격력, 검·레이저·미사일은 기존 피해 × (공격력/3.5) 비례 (`Enemy.dmg_hook`).
- 적 체력은 층마다 +25%, 보스는 전용 체력.

### 2.6 공격 변형 파이프라인 (축 합성)
```
[발사 계기] 우클릭 연사 ─┐
                       ├─ ① 탄 종류: 탄환 / 레이저(즉발) / 충전 빔 / 폭탄 탄 / 톱날 / 미사일
```

각 축은 독립이라 자유롭게 곱해진다(예: 3갈래 + 유도 + 분열 + 독). **이름 붙은 결합**은 특정 아이템 두 개(또는 태그)가 모이면 ①을 새 공격으로 갈아 끼우거나 특수 연출을 붙인다.
