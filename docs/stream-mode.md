# 무한 비행 모드 (종 스크롤 슈팅)

흐르는 도로 위를 부스터로 끝없이 날아가며, 화면 위에서 편대로 날아 들어오는 적을 격추하는 무한 모드.
끝이 없고, 시간이 지날수록 섹터가 올라 더 빠르고 어려워진다. 격추되면 비행 거리·점수가 기록된다.

- 실행: 로비 테스트 씬 목록 **무한 비행 · 종 스크롤 슈팅** 또는 `launchers\scenes\stream_run.cmd`
- 씬 `scenes/stream.tscn`, 코드 `scripts/stream/`
  - `stream_main.gd` (`StreamMain extends Main`) — 흐르는 공간 · 섹터 · 편대 감독 · 기록 · 자동 플레이
  - `stream_fighter.gd` (`StreamFighter extends Enemy`) — 경로 비행 전투기
  - `stream_drone.gd` (`StreamDrone extends Enemy`) — 앞쪽에 버티다 이탈하는 포격 드론
- 테스트 `tests/stream_mode_check.gd` (24항목)

## 구조

- 추격 보스전(MAMMOTH)과 같은 방식: 플레이어는 원점 근처에 머물고 바닥·구조물·연출이 +Z(화면 아래)로 흐른다.
  배경은 `boss_stage.gd` 를 그대로 쓰고, `WorldFlow.attach` 로 연기·파편·바닥 흔적이 공간을 따라 흘러간다.
- 플레이어는 부스터 무한 비행(`Player.infinite_boost`), 좌우 차선(±9.6m) · 앞뒤 z −9 ~ +6 안에 묶인다. 무기·검·궁극기·패링은 본편 그대로.
- 카메라는 `BossCamera` 에 플레이어보다 11m 앞의 시선 당김 점(`anchor`)을 보스 자리로 넘겨, 화면 위쪽(적이 오는 쪽)을 더 넓게 본다.
- 적 탄·전투기는 이 좌표에서 움직이므로 화면 기준으로 날아다닌다. 격추된 잔해는 도로 속도의 35% 로 뒤로 흘러가고,
  떨어진 재화도 초속 3.5m 로 화면 아래로 흘러가 놓치면 사라진다.

## 섹터 (난이도)

| 항목 | 값 |
|---|---|
| 섹터 상승 | 30초마다 (`SECTOR_TIME`) |
| 도로 속도 | 24 m/s + 섹터당 2.2 (최대 44) — 비행 거리도 이 속도로 쌓인다 |
| 동시 적 수 | 5 + 섹터×2 (최대 22, 정예가 살아 있으면 7) |
| 편대 간격 | 3.0 − 섹터×0.18 초 (최소 0.9) × 0.85~1.2 |
| 적 체력 배율 | 1 + (섹터−1)×0.14 (`Enemy.hp_mul`) |
| 정예 | 4섹터마다 경고와 함께 크롤러 + 호위 (격추 2000×섹터 · 미사일 2 · 에너지) |

## 편대

| 이름 | 등장 섹터 | 내용 |
|---|---|---|
| line | 1 | 요격기 4~6기 가로 한 줄 직진 |
| vee | 1 | 요격기 5기 V 자 |
| snake | 1 | 요격기 6기 한 줄로 사인파 |
| swoop | 2 | 요격기 5기가 위 구석에서 반대편으로 휘어 나감 |
| hook | 2 | 폭격기 3기가 내려와 멈춰 쏜 뒤 돌아 나감 |
| gunship | 2 | 포격 드론 2~3기 (11~15초 버티다 이탈) |
| dive | 3 | 요격기가 멈춰 연사 후 플레이어 쪽으로 급강하 |
| pincer | 3 | 양쪽 구석에서 3기씩 엇갈림 |
| striker | 4 | 요격 돌격기(Striker) + 요격기 |
| bomber | 4 | 폭격기 2 + 사인파 호위 4 |
| storm | 6 | 휘어 들어오는 요격기 4 + 폭격기 + 드론 혼합 |

- 요격기(DART): 체력 1(×2.5×배율), 조준 단발 2회. 폭격기(WING): 체력 3, 부채꼴 3발 3회. 화면 안(플레이어보다 위)에서만 쏜다.
- 화면 밖으로 빠져나간 적은 처치 없이 사라지고 **놓침**으로 센다 (락온된 적은 풀릴 때까지 남는다).
- **PERFECT**: 한 편대를 하나도 놓치지 않고 전멸시키면 500×섹터 점수 + 미사일/에너지 하나.

## 기록 · 화면

- 오른쪽 위 점수 칸 아래: `SECTOR · 비행 거리 / 격추 · BEST`.
- 격추되면 `DESTROYED`(또는 `NEW RECORD!`)와 비행 거리·섹터·격추·놓침·점수. R 다시 출격, Esc 로비.
- 최고 기록은 `user://stream_best.cfg` (자동 플레이 `--bot` 은 남기지 않는다).

## 검증 인자

- `--bot --seconds=N` : 자동 플레이 후 `STREAM t=… sector=… dist=… kills=… escaped=…` 를 찍고 종료
- `--sector=N` : N 섹터에서 시작 · `--godmode` : 무적 · `--seed=N` : 편대 무작위 고정
- 예: `powershell -File tools\godot.ps1 wait --fixed-fps 60 res://scenes/stream.tscn -- --bot --seed=1 --seconds=70`

## 남은 일 (제안)

- 전용 배경: 지금은 MAMMOTH 추격전 도로를 그대로 쓴다. 우주 시설 통로·구간마다 바뀌는 배경이면 진행감이 커진다.
- 지상 적: 도로 속도가 빨라 지상 포탑은 화면에 머무는 시간이 너무 짧아 넣지 않았다 (느린 구간·운반 레일이 필요).
- 섹터 보스: 정예 크롤러 대신 MAMMOTH·LANCASTER 같은 보스를 일정 섹터마다 넣는 것.
