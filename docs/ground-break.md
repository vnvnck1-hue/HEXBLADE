# 바닥 파괴 연출 (GroundBreak)

스킬이나 강타가 바닥을 깨뜨리는 연출입니다. 판이 들리고, 암석이 솟고, 바닥이 찌그러지고, 파편이 튑니다.
사용자가 준 영상 캡처 5장을 참고했습니다(바닥 색 그대로의 각진 판이 기울어 솟고, 서 있는 파편 무리와 흩어진 작은 조각이 함께 보임).
**판정은 없고 연출만 있습니다.**

- 코드: `scripts/presentation/ground_break.gd` (`GroundBreak`)
- 부르기: `GroundBreak.burst(지면 위치, 세기 0~1, 공격 방향)` — 높이는 `Main.gy` 로 다시 잽니다
- 테스트: `tests/ground_break_check.gd` · 캡처: `_capture/ground_break_show.gd` → `output/ground-break-20261005/sheet.png`

## 스타일

| id | 이름 | 모습 |
|---|---|---|
| `crumble` | 깨짐 튐 (기본) | 깨진 구멍 + 가장자리에 작게 들린 판 + 파편 튐. 암석 솟음에서 솟는 기둥만 빼고 파편 튐을 섞은 것입니다. |
| `slab` | 판 들림 | 충격 지점에서 바닥이 방사형 판(고리 3개 × 7~9조각 + 가운데 부채꼴)으로 갈라집니다. 판마다 중심에서 가장 먼 변이 경첩이 되어, 안쪽 판일수록 높이 들립니다(52~80° / 22~42° / 0~11°). 판 사이 틈과 빈자리는 어두운 금으로 보이고, 바깥으로 들쭉날쭉한 금이 뻗습니다. 들린 뒤 잠깐 덜컹거리다 끝에 바닥 속으로 가라앉습니다. |
| `spike` | 암석 솟음 | 각지고 끝이 비스듬히 깨진 기둥들이 바깥으로 기울어진 채 바닥을 뚫고 솟았다가(0.08초, 살짝 넘침) 다시 들어갑니다. 가운데 기둥이 크고, 반쯤은 공격 방향으로 쏠립니다. 가장자리에는 작게 들린 판이 있습니다. |
| `buckle` | 찌그러짐 | 바닥 면 자체가 물결처럼 튀어 오르며 퍼진 뒤, 주름진 둔덕 고리와 가운데 금으로 굳었다가 천천히 펴집니다. |
| `scatter` | 파편 튐 | 바닥 덩어리들이 공격 방향으로 쏟아져 튀고, 벽에 막히고, 구르다 멈춥니다. 가운데에는 별 모양 구멍이 남습니다. |
| `mix` | 대파괴 | 판 들림 + 가운데 암석 + 파편 튐을 한꺼번에 냅니다. |
| `off` | 끔 | 예전 그대로입니다. |

스타일은 `static` 이라 씬을 다시 불러도 유지됩니다. 실행 인자 `--ground=id` 로도 정할 수 있습니다.

## 어디서 나오나

| 동작 | 세기 |
|---|---|
| E 도약 내려찍기 착지 (`LeapSlam._slam`) | 1.0 (반경 약 3.4m) |
| 검 콤보의 무거운 일격 적중 (`SwordCombo._heavy_hit`, cut 의 `heavy`) | 0.55 |
| 미사일 착탄 — 지면에서 1.3m 안일 때 (`Missile._explode`) | 0.3 |
| 허수아비 씬 F4 / Shift+F4 (조준점) | 1.0 / 0.45 |

돌진·휠윈드는 **지나간 자리 흔적**을 남깁니다 (아래 절).

## 지나간 자리 흔적

돌진 공격과 휠윈드가 지나간 자리에 **살짝 찌그러진 자국 + 작은 파편 몇 개 + 짧은 금**을 남깁니다. `Player._physics_process` 첫머리의 `GroundBreak.follow(self, dt)` 한 줄이 매 틱 플레이어 상태를 보고, 지나간 거리마다(제자리에서 돌면 시간마다) `trail_mark` 를 냅니다.

| 출처 | 감지 | 세기 · 간격 |
|---|---|---|
| 대시 중 일격참 · 관통 일격 | `lunge_t > 0` | 0.42 · 1.15m |
| 기 모으기 돌진 (최대 TEMPEST 는 더 세게) | `tech.rushing()` | 0.36 (0.5) · 1.05m |
| 2단 대시 휠윈드 | `whirl.active()` | 0.32 · 0.95m, 제자리 0.16초 |
| Q 합체 휠윈드 | `PartnerDrone.inst.whirl_t >= 0` | 0.36 · 1.0m, 제자리 0.22초 |

- 찌그러짐은 큰 연출과 같은 모양 함수에 높이 배율 0.38(`TRAIL_AMP`)을 곱하고, 가벼운 격자(6고리 × 18조각)로 만듭니다. 크기·간격·옆 위치를 조금씩 흔들어 도장처럼 줄지어 보이지 않게 했습니다.
- 수명 1.7초, 초당 14개 상한(`TRAIL_BUDGET`, 큰 연출 예산과 따로). 공중(발이 지면에서 0.9m 넘게 떠 있음)에서는 남기지 않습니다. 스타일이 OFF 면 흔적도 없습니다.

허수아비 씬에서 **= / Shift+=** 로 스타일을 바꾸면 플레이어 앞에 바로 미리보기가 나옵니다.

## 바닥과 똑같아 보이게

- 조각은 **그 자리 바닥 재질**을 씁니다. 맵 바로 아래 자식 중에서 `MechDecals.RECEIVER` 층에 있고 AABB 가 낮은 MeshInstance 의 `material_override` 를 바닥으로 보고, 위치가 들어가는 것을 고릅니다. 바닥 셰이더는 월드 좌표로 무늬를 읽으므로 들린 판에도 그 자리 무늬·2m 줄눈·조명 풀이 그대로 나옵니다.
- 들린 판·암석·파편은 그 재질을 복제해 **조금 밝힙니다**(`floor_value`·`lift` ×1.32). 그림자 쪽 해의 몫도 `shade_floor` .36 → .62 로 올립니다. 바닥과 같은 밝기면 기운 면이 짙은 남색으로 죽어 원화의 밝은 조각처럼 읽히지 않습니다. **안 들린 바깥 판은 바닥 재질 그대로** 써서 경계가 보이지 않습니다.
- 찌그러짐은 완만한 경사라 셀 셰이딩(2단 명암)이 명암을 지워 버립니다. 그래서 바닥 셰이더 코드를 복제해 `ALBEDO = clamp(col * COLOR.rgb, …)` 로 바꾸고, 면마다 해 쪽 방향과의 각도와 높이로 정점 색 명암을 과장합니다(평평하면 1 = 바닥과 같은 색).
- 금·구멍은 조명을 받지 않는 반투명 데칼(`instance uniform fade`, 공용 재질 하나)입니다. 판보다 아래에 그려져 판이 덮고, 틈으로만 보입니다.
- 면을 감는 방향: 바닥 셰이더가 `cull_disabled` 라 뒷면은 법선이 뒤집힙니다. 그래서 `_tri` · `_flat_tri` 는 원하는 바깥 법선 쪽이 앞면(Godot 앞면 = 시계 방향)이 되게 감습니다.

## 상한과 캐시

- 조각 460개 · 연출 10개를 넘으면 가장 오래된 연출부터 지웁니다. 새 연출은 초당 5개까지만 받습니다(미사일 일제 사격이 한 프레임에 조각 수백 개를 만들지 않게).
- 조각 재질은 GroundBreak 노드(씬마다 하나)가 들고 있다가 씬과 함께 사라집니다. 정적 캐시는 데칼 재질 하나, 대체 단색 재질 하나, 찌그러짐 셰이더(바닥 셰이더 종류만큼)뿐입니다.
- 흐르는 씬(추격 보스전, `WorldFlow.active()`)에서는 내지 않습니다. 도로가 움직여 바닥에 붙은 조각이 어긋나기 때문입니다.
