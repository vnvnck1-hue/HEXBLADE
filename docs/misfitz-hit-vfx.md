# MISFITZ 식 타격 VFX (기본 타격 버스트)

레퍼런스: 사용자 첨부 `MISFITZ · ATTACK / CONCEPT ART · ENEMY 05` 의 'Hit' (보관 `output/misfitz-hit-20261006/reference.png`).
첨부는 **정지 프레임 1장**(1280×720, 애니메이션 아님)이라, 'Hit' 아래 나란히 그려진 두 단계(정점 A · 소멸 B)를 키프레임으로 확대 분석해 그 사이 시간표는 직접 설계했다.

## 레퍼런스 관찰
- **정점 A**: 비대칭 3갈래 별 — 위쪽 긴 가지 · 오른쪽 긴 가지 · 왼쪽 아래 짧은 가지(약 0.6). 흰 심지 → 연분홍 면(#f8d2fa) → 마젠타 테두리(#ff2ee8), 가지마다 한쪽 면은 짙은 마젠타(#c214d6) 베벨.
  별 뒤로 계단처럼 밀린 잔상 2겹(마젠타 · 보라), 그 뒤 큰 보라 별 덩어리(#9b2cf0)와 가는 보라 광선, 원형 보라 광채, 화면에 똑바로 선 네모 픽셀 조각(보라 · 라벤더 · 분홍).
- **소멸 B**: 별 가지의 골이 파고들어 가는 선 가지만 남음(흰 심지는 남음). 보라 덩어리가 **속 빈 윤곽 파편 3개**(ㄱ자 · 삼각형 · 사다리꼴+가시)로 깨져 바깥으로 흩어짐(#7f46dc). 픽셀 조각은 흩어지며 사라짐.

## 시간표 (일반 타격, 60fps 프레임)
| 시간 | 프레임 | 내용 |
|---|---|---|
| 0~0.033s | 0~1 | 흰 별이 0.55→1.12배로 튀어나오며 흰색→마젠타, 광채 켜짐 |
| 0.033~0.10s | 2~6 | 정점 A (잔상 · 보라 덩어리 · 광선 · 픽셀) |
| 0.10~0.17s | 6~10 | 골이 파고들어 가는 별, 보라 덩어리 → 채운 파편 → 속 빈 윤곽 |
| 0.17~0.30s | 10~18 | 소멸 B: 별 짧아지며 투명, 파편 · 픽셀 흩어짐 |

강타: 크기 1.3배 · 시간 1.25배 · 잔상 3겹 · 픽셀 16개. 별 반경 = 대상 몸 폭 × 0.4 (처음 0.8 → 사용자 요청으로 절반).

## 색 세트 (2026-10-07)
- **보라** (레퍼런스 그대로) = 근접 공격: 검 · 관통 일격 · 패링 · 반사 등 아래 원거리 목록에 없는 모든 피해.
- **노랑** = 원거리 공격 `MisfitzHit.RANGED` = bullet · laser · missile. 같은 명암 구조로 연노랑 면 #fff4c4 · 노랑 테두리 #ffd21e · 주황 베벨 #e88a00 · 잔상 #ffbe28/#ff7a1a · 뒤 덩어리 #ff9a1e · 윤곽 파편 #e0701e · 광채 #ffb020.
- 피해 원천은 `HitSpark.spawn(…, source)` → `MocoFX.hit(…, source)` → `MisfitzHit.make(…, tone)` 로 넘어간다 (Enemy · 보스 4종 · LANCASTER 호출부에서 source 전달).

## 코드
- `scripts/presentation/misfitz_hit.gd` (`MisfitzHit.make/emit`) — `MocoFX` 의 ImmediateMesh 하나에 그림 (노드 · 머티리얼 · 정적 캐시 없음). 긴 두 가지의 가운데가 표면 밖(공격이 온 쪽)을 향하고 좌우 무작위 반전.
- `MocoFX.style`(static, `STYLES` = misfitz 기본 · moco 예전), `MocoFX.slow`(버스트만 느리게), 실행 인자 `--hitfx=moco`. `--vfx=old` 는 예전처럼 HitSpark 방추.
- 허수아비 씬 **8** 프리셋 전환 · **Shift+8** 0.2배속 보기, 패널 '연출 프리셋 · 타격 VFX'.
- 확인 캡처 `_capture/misfitz_hit_show.gd` → `output/misfitz-hit-20261006/` (`sheet_misfitz.png` 레퍼런스 + 총(노랑) · 미사일(노랑 강타) · 검(보라 강타) 20프레임씩, `compare_normal.png`, 프레임 폴더는 git 제외).
