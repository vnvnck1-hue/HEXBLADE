# 브롤스타즈 식 화면 (BrawlLook)

목표: Supercell 「브롤스타즈」와 같은 카메라 렌즈·조명·카툰 셰이딩. 코드 `scripts/presentation/brawl_look.gd`,
카메라 프리셋 `CameraRig.BRAWL`, 외곽선 규칙 `ToonOutline.set_brawl`. **기본 켜짐**, 게임 중 **N 키**로 끄고 켬,
실행 인자 `--look=classic` 이면 예전 화면으로 시작. 비교 캡처 `_capture/brawl_look_show.gd` → `output/brawl-look-20261004/`.

## 1. 리서치

### 공개 자료에서 확인한 것
- Supercell 은 브롤스타즈의 렌더링 기술을 공개적으로 자세히 설명한 적이 없다. 확인되는 사실은
  - 3D 게임이며 부감 쿼터뷰(“isometric-like”) 시점, 모바일 작은 화면에서의 **가독성**을 최우선으로 한 밝은 색·단순한 형태
    ([RetroStyle Games 분석](https://retrostylegames.com/blog/game-art-design-like-brawl-stars/), [Medium](https://medium.com/@RetroStyle_Games/exploring-the-art-style-of-brawl-stars-a2667bbbea3d)).
  - 조명은 “극적인 효과보다 또렷한 시인성” 위주로 단순하다(같은 글).
  - FX 팀(Octopo Studio)은 Unity + Amplify Shader 로 공용 마스터 셰이더(Unlit·Lit·Stencil)를 만들어 쓴다
    ([Coloso 강의 소개](https://coloso.global/en/products/vfxstudio-octopostudio-us)).
  - 캐릭터 제작 파이프라인 소개 ([gamedev.net 클립](https://gamedev.net/news/making-of-a-brawler-character-creation-for-brawl-stars-clip-3-r4113/)),
    디자인 원칙 ([PocketGamer.biz](https://www.pocketgamer.biz/5-creative-pillars-for-designing-brawlers-in-supercells-brawl-stars/)).
- 카메라: Godot 포럼의 재현 사례는 **아주 좁은 FOV(15°) + 멀리 높은 위치 + X 축 -60°** 로 “원근 투영인데 거의 평행해 보이는” 화면을 만든다
  ([Godot Forum](https://forum.godotengine.org/t/how-to-get-camera-perspective-view-like-brawl-stars/23689)).
  즉 정사영이 아니라 **망원 렌즈 원근**이다 — 블록의 앞면이 보이고, 위쪽이 아주 살짝 멀어 보인다.
- 림라이트는 프레넬(시선과 면 법선의 각) 기반이 일반적이다 ([Godot Shaders · Fresnel](https://godotshaders.com/snippet/fresnel/),
  [Unity Toon Shader · Rim Light](https://docs.unity3d.com/Packages/com.unity.toonshader@0.9/manual/Rimlight.html)).

### 실제 화면 관찰 (Supercell 공식 사이트의 게임 화면 이미지)
| 항목 | 관찰 |
|---|---|
| 카메라 각 | 술통 윗면 타원의 세로/가로 ≈ 0.7 → 내려다보는 각 약 45~50°. 캐릭터가 거의 정면으로 보인다 |
| 렌즈 | 울타리 기둥·벽 세로선이 거의 평행 → 좁은 화각 망원. 화면 위아래 크기 차가 작다 |
| 조명 | 고명도·고채도, 따뜻한 흰빛. 그림자 쪽도 밝다(환경광 강함). 극적인 명암 없음 |
| 그림자 | 짧고 옅고 부드럽다. 검정이 아니라 바닥색을 어둡게 한 유색 그림자 |
| 셰이딩 | 넓은 색면 + 2단 정도의 부드러운 명암. 윗면이 밝고 옆면이 한 톤 낮은 블록. 금속 반사·거친 질감 없음 |
| 캐릭터 | 채도 높고 밝다, 윤곽 쪽 밝은 테두리빛, 얇은 짙은 외곽선. 몸 안쪽 꺾임선 없음 |
| 발밑 | 둥근 접지 그림자 + 팀 색 원(자신 초록 · 아군 파랑 · 적 빨강) |
| 배경 | 안개·비네트·강한 블룸 없음. 이펙트만 발광 |

## 2. 게임 적용

| 항목 | 이전 | BrawlLook |
|---|---|---|
| 카메라 | TACTICAL: 오프셋 (0,15,8) = 62° 부감, FOV 36° | **BRAWL: (0,15.9,13.3) = 50° 부감, FOV 26°**, 거리 20.7m. 바닥이 보이는 세로 넓이(≈12.5m)는 같게 맞춤 |
| 해 | (-62°,28°), 1.25, 흰빛, 그림자 진하게 | **(-56°,-104°)** 화면 왼쪽 위에서 — 그림자가 물체 오른쪽으로 떨어져 망원 부감에서도 보인다. 1.15, 따뜻한 흰빛, `shadow_opacity` 0.62, 흐림 2.2, 그림자 거리 70m |
| 환경광 | 보라 (0.5,0.5,0.85)×0.5 | 중립에 가까운 하늘빛 (0.74,0.76,0.92)×0.72 — 그림자 쪽도 밝게 |
| 후처리 | SSAO 1.6 · 반경 1.2 | SSAO 0.7 · 반경 0.7(접지 정도), 채도 1.0(캐릭터 머티리얼에서만 올림) · 대비 1.03 · 밝기 1.02, 글로우 0.4 |
| 파츠 셰이딩 | 엔진 Burley(카툰은 O 키) | **부드러운 2단 셀**(경계 폭 0.14~0.2, 해에만) · 그림자 쪽은 보라·파랑 색조(`shade_tint`) · 윗면 밝게(`top_lift`) · 작은 둥근 하이라이트(캐릭터·소품만, 바닥·벽은 무광) · 채도 1.12. 점광원은 거리 감쇠 그대로 |
| 림라이트 | 없음 | 캐릭터·소품만. 프레넬³ × 위쪽 가중, 자기 색 55% + 하늘빛 45% |
| 캐릭터 그림자 | 진하게 | 드리운 그림자 영향 45%(`shadow_k`) — 울퉁불퉁한 몸의 자기 그림자 얼룩 제거. 텍스처 감마 0.78 로 구운 짙은 명암을 들어 올림 |
| 바닥·벽 | Claude 배경 텍스처 그대로 | 바닥은 같은 F01 텍스처를 읽는 브롤 바닥 셰이더(채도 1.12). 벽 블록(W01 MultiMesh·GLB)은 월드용 브롤 셰이더 — 위에서 빛 받아 윗면 밝고 앞면 한 톤 낮은 블록, 그림자는 오른쪽 바닥으로 |
| 외곽선 | (O 키) 모든 경계 + 꺾임선 | **캐릭터 실루엣만** 얇고 짙게(1.25px, 깊이 임계 0.02). 바닥·벽끼리, 파츠 안쪽 꺾임선은 긋지 않음 |
| 발밑 | 플레이어 청록 링 | + 모든 캐릭터 둥근 접지 그림자, 적은 붉은 팀 원(가스통 등 소품은 원 없음) |

### 동작 방식
- 머티리얼만 바꿔 끼운다. 판정·게임 진행과 무관.
  - 조명을 받는 불투명 `StandardMaterial3D`(코드 단색 `Pal.lit/mech`, GLB 텍스처 모두) → 브롤 셰이더. 색·텍스처·노멀맵·UV·발광·컬링을 옮긴다.
    원본은 메시의 메타(`bl_orig` / 표면은 `bl_surf`)에 보관해 N 키로 되돌린다.
  - 변환 결과는 **원본 머티리얼의 메타**에 붙여 둔다(정적 사전에 쌓지 않음 → 씬을 다시 불러도 늘지 않는다).
  - Claude 배경 바닥 셰이더(`ClaudeBgDress.FLOOR_SHADER`)는 같은 텍스처를 읽는 브롤 바닥 셰이더로, 배경 블록 `MultiMeshInstance3D` 는 메시 머티리얼을 덮어쓰기로.
  - 맵(`ArenaMap`) 아래 메시와 4.5m 넘는 큰 메시는 “월드”: 림라이트 없음, 러프니스 0.5 = 외곽선 분류 표식.
  - 투명·발광 단색(`Pal.flat`)·빌보드 이펙트는 그대로.
- 새로 생기는 적·파편은 `SceneTree.node_added` 로 잡아 바꾼다(PaintedLook 과 같은 방식).
- 외곽선 분류(노멀·러프니스 버퍼의 러프니스): 0 = 제외 · 0.42~0.58 = 월드 · 그 밖 = 캐릭터. 둘 다 그릴 대상이고 한쪽이 캐릭터일 때만 실루엣 선.
- PaintedLook(K)과는 동시에 켜지지 않는다. K 로 칠 질감을 켜면 브롤 룩이 꺼지고, N 으로 켜면 칠 질감이 꺼진다.
- 적용 씬: `Main` 을 그대로 쓰는 방 탐색·섹터 런·허수아비·벌레/기믹 시험장·배경 시험 씬. 보스전(추격·용광로)·심연·거미는
  자체 카메라·조명 연출이 있어 손대지 않았다.

### 고친 문제 (2026-10-04, 사용자 보고: 바닥이 얼비쳐 비정상적으로 밝아짐)
원인이 두 가지였다. 진단 도구 `_capture/brawl_haze_find.gd`(얼룩 지점 밝기를 재며 노드 숨김 · 그림자 끔 · 해 방향 바꿈 실험).
1. **바닥·벽의 반사 하이라이트**: 캐릭터용 작은 하이라이트(`dot(N,H) > 0.93`)가 바닥에도 켜져 있었다. 방 바닥의 완만한 지형 굴곡에서
   법선이 반사 방향과 맞는 넓은 구간이 한꺼번에 하이라이트를 받아 구름 모양 흰 얼룩이 생겼다(얼룩 지점 0.636 ↔ 주변 0.358, 해 방향을 바꾸면 사라짐).
   → `spec_k` 기본 0(무광), 캐릭터·소품만 0.22.
2. **점광원(총구 섬광·폭발·레이저)이 범위 전체를 평평하게 밝힘**: `light()` 가 `ATTENUATION`(점광원은 거리 감쇠 포함)을 그림자처럼 문턱으로 끊고
   그림자 쪽 몫도 감쇠 없이 더했다. 에너지 7~14 인 레이저 조명이 켜지면 화면의 18~23% 가 하얗게 날아갔다.
   → `LIGHT_IS_DIRECTIONAL` 로 나눠 해만 셀 공식, 점·스포트 조명은 `ATTENUATION` 을 그대로 곱한다(수정 후 최대 3%, 예전 화면과 같음).

### 강력 레이저 어둠 연출 복원 (2026-10-04, 사용자 보고: 레이저 때 주변이 너무 밝고 빛 표현이 깨짐)
예전 화면은 `Main.dramatic(true)` 가 해 1.25→0.08 · 환경광 →0.05 로 꺼서 레이저 광원만 남긴다. 브롤 룩에서 이것이 깨진 원인 세 가지:
1. 점광원을 셀처럼 받아(입사각 무시) 낮게 뜬 레이저 조명이 범위 안 바닥 전체를 평평하게 밝혔다 → **예전과 같은 램버트(입사각) × 거리 감쇠**.
2. 림라이트를 발광(EMISSION)으로 넣어 해가 꺼져도 테두리가 빛났다 → 림라이트를 **해에서 나오는 빛**으로(`light()` 의 방향광 경로, `v_rim`).
3. `dramatic(false)` 가 예전 조명값으로 되돌려 레이저 뒤에 브롤 조명이 풀렸다 → `BrawlLook.base_light(scene)` 값으로 되돌아온다.
덤으로 적 발밑 붉은 원도 해 밝기에 맞춰 어두워진다(최저 30%).
확인 `_capture/brawl_laser_show.gd -- --seed=4 [--classic]` (발사 0.7초 뒤, `laser_brawl.png` / `laser_classic.png`):
빔에서 먼 곳 밝기 — 예전 0.343→0.096, 브롤 수정 전 0.371→0.233, **수정 후 0.370→0.122**.

### 배경·캐릭터 톤 분리 (2026-10-04, 사용자 요청: 배경 전체 톤을 눌러 시인성 확보)
측정 `_capture/brawl_tone_probe.gd -- --seed=4 --tag=이름` — 같은 화면을 캐릭터(플레이어·적) 켜고/끄고 찍어 달라진 픽셀 = 캐릭터, 나머지 = 배경.

| | 캐릭터 밝기 | 배경 밝기 | 밝기 비 | 캐릭터 채도 | 배경 채도 | 채도 비 |
|---|---|---|---|---|---|---|
| 전 | 0.403 | 0.345 | 1.17 | 0.527 | 0.581 | 0.91 (배경이 더 진함) |
| 후 | 0.406 | 0.269 | **1.51** | 0.498 | 0.429 | **1.16** |

조절값은 `BrawlLook` 상수: `WORLD_VALUE` 0.6 · `WORLD_SAT` 0.5 · `WORLD_TINT`(살짝 차갑게) — 바닥 셰이더와 월드 파츠(맵 아래·큰 메시·배경 블록)에 적용,
`CHAR_SAT` 1.32 · `CHAR_VALUE` 1.06 · `CHAR_SHADE`(그림자 쪽을 덜 푸르게, 따뜻한 몸색이 회색으로 죽지 않게) · `RIM` 0.68 — 캐릭터·소품.
화면 전체 채도 보정은 1.1 → 1.0(배경까지 진해지므로 캐릭터 머티리얼에서만 올림), 환경광은 하늘빛 → 덜 푸른 중립 (0.74,0.76,0.92).
덤: 레이저 어둠 연출에서 빔에서 먼 곳 밝기 0.122 → 0.102 (예전 화면 0.096 과 거의 같음).

## 3. 남은 차이 (브롤스타즈와 “같은” 화면까지)
- **에셋 색·형태**: 브롤 바닥은 따뜻한 밝은 타일, 장애물은 바닥과 색상이 확실히 다르다. 지금 바닥·벽은 같은 보라 계열이라
  형태 대비가 약하다 — 셰이더가 아니라 텍스처·팔레트 결정이 필요하다(사용자 결정).
- 메카 플레이어 텍스처는 위장 무늬·구운 명암이 많아 브롤 캐릭터의 단순한 색면과 다르다. 셰이더 보정(감마)으로 완화만 했다.
- 수풀(숨는 풀숲) 같은 브롤 고유 지형 표현은 게임 규칙에 없으므로 만들지 않았다.
- 실제 기기·여러 해상도에서의 외곽선 두께·그림자 품질은 눈으로 확인 필요.
