[내러티브 콘셉트와 초반 플로우](docs/내러티브_콘셉트와_초반_플로우.md): 생체 조직과 로봇이 결합하는 세계관, 남성 파일럿과 여성 캐릭터, 첫 출격부터 MAMMOTH 격파·귀환까지의 시나리오 제안입니다. 캐주얼·엉뚱함 조건은 해제했으며, 시나리오와 생체 변이는 아직 게임에 구현하지 않았습니다.

## 실행

게임을 켜면 **로비**(`scenes/lobby.tscn`)가 나옵니다.

| 메뉴 | 내용 |
|---|---|
| 메인 게임 · HEX SECTOR RUN | 포탈로 경로를 골라 섹터 2곳을 돌파하는 로그라이트 런 (`docs/sector-run.md`) |
| 테스트 씬 | 방 탐색 아레나(기존 방 조합 게임, `main.tscn`) · **전투 테스트 · 허수아비**(`training.tscn`) · MAMMOTH 추격전(`boss.tscn`) · VULCAN 용광로(`forge.tscn`) · **LAYER 01 심연 성소**(`abyss.tscn`) · **SHAFT 07 거미 보스 SHIPWRIGHT**(`spider.tscn`) 단독 실행 |
| 종료 | 게임 종료 |

게임 중 **Esc** 를 누르면 로비로 돌아옵니다(섹터 런은 중단됩니다).

- `run_game.cmd` 더블클릭: **`godot-version.txt`에 고정한 Godot 버전(현재 4.7.2-stable)으로만** 실행합니다. 다른 버전이 PC에 깔려 있어도 쓰지 않습니다.
- 새 PC에서 처음 실행하면 프로젝트 안 `.tools/godot/`(git 제외)에 그 버전을 자동으로 준비합니다. 같은 버전이 이미 설치된 곳(winget, 옆 폴더 `.tools/godot`, 환경 변수 `GODOT_HOME`)이 있으면 복사하고, 없으면 공식 릴리스에서 내려받아 SHA512로 검증합니다. 미리 해 두려면 `setup_godot.cmd`.
- `open_editor.cmd`: 편집기로 엽니다. 편집기에서 F5를 누르면 실행됩니다.
- `run_tests.cmd`: `tests/*.gd` 전체를 고정 버전으로 헤드리스 실행합니다.
- 다른 PC로 작업을 옮길 때의 규칙과 주의점은 [AGENTS.md](AGENTS.md)에 있습니다.
- 렌더러는 Forward+(Vulkan)입니다.

## 조작

| 입력 | 동작 |
|---|---|
| WASD / 방향키 | 이동 (화면 기준) |
| 마우스 | 조준 (상체는 조준 방향, 하체는 이동 방향) |
| 우클릭 유지 | 연사. **탄창 30발**: 30발을 다 쏘면 자동으로 재장전(1.25초)하고, **T** 로 언제든 수동 재장전합니다. 재장전 중에는 쏘지 않고, 빈 탄창을 걷어차듯 뽑아 던짐 → 총을 머리 위로 띄워 세 바퀴 돌림 → 탄창을 내리꽂음(불꽃) → 장전 튕김 순서로 과장된 재장전 동작을 하며, 남은 탄은 조준점 옆 숫자와 왼쪽 AMMO 막대로 보입니다. 쏠 때마다 사격 팔과 함께 **어깨 장갑까지** 뒤로 밀리며 들렸다가 스프링처럼 돌아옵니다. 탄속 60m/s의 노란 예광탄으로, 총구에서 자라나 1.5m 길이로 뻗습니다. 쏠 때마다 총구 화염이 번쩍이고 황동 탄피가 튀어 바닥에 쌓입니다. 한 프레임에 지나간 구간 전체로 판정합니다 |
| 좌+우클릭 동시 유지 → 하나라도 놓기 | 충전 레이저포. 충전 중에는 사격·검이 나가지 않습니다. 대시 중에도 충전이 유지됩니다. 충전 단계마다 색이 바뀝니다: 청록(1단) → 파랑(2단) → 자홍(3단) → 흰금(최대). **에너지**를 씁니다: 최소 발사 단계~1단 1칸, 2단 2칸, 최대 3칸. 가진 에너지로 쏠 수 있는 단계까지만 모이고, 에너지가 없으면 충전되지 않습니다(NO ENERGY). 최대로 모아 놓으면 **2초 지속 레이저**를 쏩니다. 빔은 조준을 **무겁게 천천히** 따라가며(최대 약 80°/초), 초고속 줄무늬·속도선·역풍 줄기가 나오며, 주변이 급격히 어두워지고 빔 조명이 경로를 비춥니다. 지속 레이저 중에 Space 를 누르면 레이저를 끊고 바로 대시합니다 |
| Space | 드릴 회피: 몸을 수평으로 눕혀 머리를 조준 방향에 두고 축 회전하며 돌진 (무적). **대시가 끝나는 순간**(마지막 0.1초 ~ 끝난 뒤 0.06초)에 다시 누르면 쿨다운 없이 **2단 대시**가 나갑니다. 너무 일찍 누르면 그 대시는 연결할 수 없습니다. 2단 대시는 잔상·소용돌이·충격파가 무지개빛으로 바뀌고 PERFECT 가 뜹니다 |
| Shift 유지 | 백팩 부스터 비행. BOOST 게이지를 소모하며, 다 쓰면 과열되어 30%까지 회복해야 다시 사용 |
| Shift 누른 채 Space 길게 (0.18초) | **점프**. 누르고 있는 동안 발밑 청록 링이 조여들고, 다 조여들면 뛰어오릅니다(정점 약 1.5m). 짧게 떼면 평소처럼 대시가 나가고, Space 만 누르면 기다림 없이 바로 대시합니다. 패링 창이 열려 있으면 패링이 먼저입니다 |
| 좌클릭 길게 → 놓기 | **기 모으기 돌진** (`scripts/blade_tech.gd`). 0.2초 넘게 누르고 있으면 그 자리에 서서 기를 모읍니다(1.1초에 최대). 모을수록 등 뒤 부스터가 수평으로 눕혀지며 불꽃 혀·불티·배기를 촤라라락 거세게 뿜고, 바닥에 돌진 경로(가운데 선 + 폭 선)가 길게 그려지고(절반·최대에서 핑), **카메라가 25%·50%·75%·100% 문턱마다 한 칸씩 계단식으로 줌아웃**해 멀리 있는 적까지 보여 줍니다(1.0 → 1.1 → 1.2 → 1.31 → 1.45배, 돌진 뒤 0.35초 지나 돌아옴). 떼면 **마우스 방향으로** 돌진합니다: 모은 만큼 4~9m · 피해 6~16, 지나간 적을 한 번씩 벱니다. **최대로 모으면 TEMPEST**: 대시처럼 몸을 눕혀 6바퀴 드릴 회전하며 14m 를 돌진하고, 광선검을 옆으로 뻗어 회오리처럼 휘둘러 폭 1.15m 경로의 적을 0.06초 간격으로 최대 5번(×6) 벤 뒤 끝에서 원형 참격(반경 1.6m, 10)이 한 번 더 터집니다. 이때 광선검 리본이 0.5초 동안 남아 경로에 광선검 색 **나선 잔상**을 그리고, 강력 레이저 잔상처럼 잔상 줄기 5가닥이 일렁이다 부서지며, 한 박자 늦게 연기 잔흔이 경로를 따라 쫓아오며 터집니다. 짧게 떼면 평소 콤보 검이고, 콤보·관통 일격이 이어지는 중의 클릭은 기다리지 않고 바로 나갑니다 |
| 콤보 중 좌+우클릭 동시 | **회피 레이저**: 검술 콤보 사이에 좌·우클릭을 함께 누르면 순간적으로 뒤로 물러서며(무적 0.3초) 4프레임 뒤 단타 레이저를 쏩니다. 에너지를 쓰지 않습니다. 링크가 열린 채라 곧바로 좌클릭하면 다음 단으로 이어집니다(물러서는 중에 눌러도 끝나자마자 나감) |
| 좌클릭 (E / F) | 광선검 **6단 콤보** (젠레스 존 제로·드래곤볼식 과장 연출, 자세한 설계: `docs/sword-combo.md`). 우클릭을 누른 채 좌클릭하면 검 대신 충전이 시작됩니다. 1타 섬광 삼연참(파고들며 6프레임에 3번 벰) → 2타 반동 사격(역베기 → 뒤로 공중제비를 돌며 물러나 공중에서 총 4발 → 2프레임 만에 되돌아와 찌르기) → 3타 순섬 난무(적 둘레로 순간이동하며 사방에서 X자 6번 + 십자 베기) → 4타 선풍(0.33초에 5바퀴 돌며 7번 베는 회오리, 몸은 잔상으로만 보임) → 5타 도약 올려베기(두 번 올려 베며 떠오름) → 6타 낙월·지연참(공중에서 두 바퀴 돌며 내리꽂고, 한 박자 뒤 주변 허공에 칼자국 6개가 연달아 터짐). 다단히트는 짧은 정지(0.014~0.035초)로 끊어 치고 마무리 타격만 길게 멈춥니다. **각 타격이 적중해야만** 다음 단이 부드럽게 이어지고(선입력 가능), 헛치거나 장갑에 막히면 몸이 끌려가는 오버스윙 자세로 늘어지며 0.46초 동안 검을 못 씁니다. 멀리 있는 다음 적에게는 순간 돌진으로 파고들어 이어 벱니다. 스윙은 2~4프레임, 광선검 잔상은 약 2프레임만 번쩍 남는 넓은 형광 초승달 리본입니다. 돌진하는 동안 강철 발이 바닥을 긁어 마찰 불꽃이 뒤로 튀고, 긁힌 자리에 흰빛에서 검붉게 식어 가는 쇳자국 두 줄이 1.5초쯤 남습니다. 대시·돌진 중에는 팔다리에 몸체 톤(크림) 리본이 감깁니다. 2단 대시에 성공하면 **3초 동안 칼날이 붉게 불타오르고**, 그 안에 휘두른 검은 **관통 일격**입니다: 9m 안의 적을 3프레임(0.05초) 만에 꿰뚫고 적 뒤 2.2m까지 빠져나간 뒤, 한 박자 늦게 경로 위의 적이 20 피해로 한꺼번에 베입니다. 3초가 지나면 불이 꺼지며(꺼지기 0.8초 전부터 깜빡임) 관통 일격도 사라집니다 |
| R / Q 유지 → 놓기 | 궁극기 락온 미사일. 누르고 있는 동안 슬로우모션(0.18배, 최대 실제 시간 2초)이 걸리고, 카메라가 줌아웃해 주변을 보여 줍니다. 포인터는 락온 크로스헤어로 바뀌고 카메라가 포인터 쪽으로 따라 움직입니다. 포인터로 적을 스치면 락온됩니다(최대 10기). 락온된 적에는 붉은 빗금이 덮이고, 조여 드는 괄호와 LOCK 표식이 붙습니다. 미사일이 1발 이상 있어야 발동합니다. R 을 떼거나 2초가 지나면 **가진 미사일을 모두** 쏩니다. 락온한 적들에게 한 발씩 돌아가며 유도되고, 락온이 없으면 주변 바닥 아무 데나 떨어져 터집니다. 목표가 먼저 죽으면 다른 적을 찾지 않고 그 자리에 떨어집니다 |
| I | 임팩트 프레임 켜기/끄기. 3단 이상 충전 레이저와 최대 레이저를 쏘는 순간 화면이 1~4프레임 동안 순수 흑백으로 바뀝니다(원판 → 반전). 총구를 소실점으로 하는 집중선이 함께 나옵니다. 실행 인자 `--noimpact`로 끈 채 시작할 수 있습니다 |
| O | 카툰 렌더링 켜기/끄기. 조명 파츠의 두 단 셀 음영과 깊이·노멀 경계 외곽선 후처리를 함께 전환하며, 끄면 일반 음영으로 돌아갑니다. 발광 파츠(예광탄·속도선 등)는 선을 긋지 않습니다. 기본값은 꺼짐이며, 실행 인자 `--toon`으로 켠 채 시작할 수 있습니다 |
| K | 하스스톤 식 핸드 페인팅 질감 켜기/끄기(시험). 파츠마다 위 밝고 아래 어둡게 칠한 그라디언트, 윗모서리 밝은 선·아랫모서리 짙은 선, 리벳, 따뜻한 그림자, 지형 색 보정. 씬을 다시 불러도 유지되며 `--look=hearth` 로 켠 채 시작. 설명: [docs/hearthstone-look.md](docs/hearthstone-look.md) |
| V | 카메라 프리셋 전환: CLASSIC / ACTION / CINEMATIC / TACTICAL(기본) |
| H / Shift+H | **HUD 프리셋** 다음/이전: STRIKER(기본, 젠레스 존 제로식 좌상단 기체 카드 + 우하단 원형 스킬 버튼) / CORNERS(왼쪽 아래 생존 · 오른쪽 아래 무장) / COCKPIT(기체 · 조준점 둘레 호) / TACTICAL(압축한 좌상단 패널) / LEGACY(기존 나열). 고른 프리셋은 재시작해도 유지되고, 실행 인자 `--hud=이름`으로 골라 시작할 수 있습니다. 리서치 · 설계: [docs/hud-presets.md](docs/hud-presets.md) |

## 전투 테스트 · 허수아비 (`training.tscn`)

코드: `scripts/training/training_main.gd` (Main 상속), `scripts/training/dummy.gd` (`TrainingDummy`, Enemy 상속이라 검·총·레이저·미사일 락온·패링·절단 연출이 실제 적과 같습니다).

- 허수아비는 맞으면 기둥째 젖혀졌다 스프링처럼 돌아오고, 밀려나도 제자리로 돌아옵니다.

| 키 | 설정 |

| 1 | 허수아비 다시 세우기 · 기록 초기화 |

## 플레이어 액션 연출 (젠레스 존 제로풍)

모든 액션은 **키 포즈로 1~3프레임 만에 튀어 들어가고 → 몇 프레임 버티고 → 넘쳤다 돌아오는** 리듬입니다 (`scripts/presentation/player_motion.gd`, 자세한 표: `docs/sword-combo.md`).

- **재장전**: 탄창 걷어차 뽑기(3F) → 총을 머리 위로 띄워 세 바퀴 회전 → 내리꽂아 장착(4F, 불꽃) → 장전 튕김 → 복귀. 빈 탄창은 바닥에 튀고 사라집니다.
- **사격**: 쉬다 쏘는 첫 발은 총구가 튀어 오르는 퀵드로, 매 발 상체가 번갈아 비틀립니다.
- **충전 레이저**: 단계마다 다리를 벌리고 낮게 버팁니다. 발사 순간 2프레임 만에 상체가 꺾이고 총이 치솟으며, 강하게 쏘면 밀려나는 동안 발이 바닥을 긁습니다. 지속 레이저는 깊게 앉아 버팁니다.
- **미사일**: 락온 중 웅크린 준비 자세 → 3프레임 만에 뛰어올라 양팔을 벌린 채 일제 사격 → 내리꽂듯 착지.
- **회피**: 첫 2프레임 몸이 사라지고 출발 자리에 잔상만 남습니다.
- 확인: 전투 테스트장 `res://scenes/training.tscn -- --bot --techshow` (반쯤 모은 돌진 → 최대 돌진 → 콤보 중 회피 레이저), 테스트 `tests/blade_tech_check.gd`.
- 확인: `-- --actshow` (연사 → 자동 재장전 → 3단 레이저 → 지속 레이저 → 미사일), `-- --comboshow` (6단 콤보).

## 적 체력

일반 적은 기본 체력에 `Enemy.HP_SCALE`(2.5배)를 곱해 시작합니다(드론 10 · 요격기 13 · 포탑 23 · 크롤러 35). 착지한 적 머리 위에 체력바가 떠 있고(다치지 않았으면 흐리게), 깎인 만큼 흰 잔량이 잠시 남았다가 따라 내려옵니다. 5 단위 눈금이 있습니다. 보스는 기존 상단 체력바를 씁니다.

## 콤보와 점수

미니맵 아래에 점수와 연속 콤보가 표시됩니다. 적을 처치할 때마다 콤보가 1 오르고, 3초 안에 다음 적을 처치하면 이어집니다(남은 시간 막대 표시). 한 번 처치할 때마다 `100 × 콤보 수`점을 얻고, 검으로 처치하면 2배, 관통 일격으로 처치하면 3배를 얻습니다. 피격되면 콤보가 끊깁니다. 결과 화면에 점수와 최대 콤보가 나옵니다.

## 패링 (젠레스 존 제로 방식)

일부 적 공격은 **금빛으로 예고되는 패링 공격**입니다. 닿기 직전(0.26초 전 ~ 0.07초 후)에 **Space(대시)** 를 누르면 대시 대신 반격이 나가며 패링합니다. 대시 쿨다운 중에도 패링은 됩니다. 창이 열리기 전에 너무 일찍 누르면 0.32초 동안 패링할 수 없습니다(연타 방지, 발밑 링이 어둡게 바뀜).

모든 패링 공격은 **과장된 준비동작 → 십자 별빛 알림 + 기체 전신 금빛 섬광 → 알림 후 정확히 0.5초 뒤 명중** 순서라 타이밍이 매번 같습니다(`Parry.TRAVEL`). 알림은 공격 지점에 뜨는 화면을 가를 만큼 거대하고 얇은 금빛 십자 별빛(강한 섬광·순간 조명 동반)으로, 가로 줄기가 먼저 과장되게 뻗었다 튕겨 돌아오고 이어서 세로 줄기가 한 번 같은 동작을 합니다. 판정은 `parry.gd` 상단 상수(`EARLY`·`LATE`)에서 조정합니다.

| 종류 | 누가 | 예고 | 패링 결과 |
|---|---|---|---|
| 원거리 · 패링 탄 | 기본 드론 (공격 주기마다 45%, 동시 2발까지) | 준비동작(0.8초): 뒤로 물러서며 몸을 크게 젖혀 들어 올리고 납작하게 웅크린 채 떨며, 코어가 금빛으로 부푼다 → 십자 별빛과 함께 발사. 구체 속도는 발사 거리로 정해 항상 0.4초 만에 닿고, 빠른 만큼 진행 방향으로 길게 늘어난다 | 쏜 적에게 30m/s 로 되받아쳐 12 피해 + 금빛 폭발 |
| 근접 · 돌진 베기 | 고속 요격기 (8m 안, 3.5~5.5초마다) | 준비동작(0.7초): 크게 물러서며 기수를 치켜들고 떠올라 떤다 → 십자 별빛 + 금빛 발광과 함께 0.4초 뒤 닿도록 돌진(가까우면 그 자세로 잠깐 버틴 뒤 돌진) | 적이 크게 튕겨 나가 **2.2초 경직**(머리 위 별이 돌고, 받는 피해 2배) |

- **타이밍 신호**: 패링 공격이 다가오면 플레이어 발밑의 금빛 링이 바깥에서 조여들고, 쐐기가 공격 방향을 가리킵니다. 링이 안쪽 목표 링에 겹치며 하얗게 깜빡이는 순간(판정 창이 열림)에 공격 지점에서도 흰 섬광과 '핑' 소리가 한 번 더 납니다.
- **성공 연출**: 전투 속도를 끊지 않게 짧습니다. 흑백 임팩트 프레임 2프레임 → 2프레임 정지 → 몇 프레임 0.3배 슬로우(0.11초에 정상 복귀). 글자 UI 없이, 화면을 거의 가로지르는 얇은 금빛 섬광선이 잠깐 그어지고 접촉점 집중선·색수차가 0.3초 안에 걷힙니다. 접촉점에서는 별 섬광·충격파 3겹·불꽃·반격 궤적 빛줄기·순간 조명이 터지고, 금속 충돌음이 울립니다.
- **카메라**: 쿼터뷰 그대로 플레이어와 적 사이로 시선을 조금 옮기며 적당히 줌인(거리 0.87배, 0.05초)했다가 0.45초에 원래대로 돌아옵니다(`camera_rig.gd` `parry_cine`, `CINE_ZOOM`).
- **보상**: 대시 쿨다운과 검 쿨다운이 바로 초기화되고, 다음 검은 **관통 일격**이 됩니다. 되받아친 탄으로 처치하면 점수 3배.

## 붉은 섬광 · 컷인 · 격파 쇼타임 (젠레스 존 제로식 연출)

자세한 내용: `docs/zzz-presentation.md`. 세 가지 모두 연출 전용 모듈(`scripts/presentation/`)이며 판정·피해·보상은 바꾸지 않습니다.

- **붉은 섬광 = 막을 수 없다, 피하라** (`danger_fx.gd`): 금빛은 패링할 수 있는 공격, 붉은빛은 패링이 안 되는 강한 공격입니다. 닿기 0.4초 전(패링 공격과 같은 리듬)에 공격 지점에서 붉은 십자 별빛이 **두 번 맥동**하고 낮은 경고음이 납니다. 대상: 요격기 차지 레이저, 크롤러 도약 내려찍기, MAMMOTH 거수포, VULCAN 노심 화염 방사.
  붉은 공격의 판정 범위 안에서 **대시 무적으로 피하면 퍼펙트 회피**: 0.25배 슬로우(실제 0.3초에 복귀), 청백 잔상·별 섬광·충격파. 보상은 없습니다.
- **컷인 타이포** (`cut_in.gd`): 드문 순간에만 비스듬한 띠와 굵은 기울임 글자가 화면을 가릅니다 — 최대 레이저(FULL BURST), 관통 일격으로 2기 이상 동시 처치(PIERCE ×N), 보스 2페이즈(PHASE 2). 흑백 임팩트 프레임이 끝난 뒤 들어옵니다. 패링은 지금처럼 글자 없이 둡니다. `--nocutin` 으로 끕니다.
- **보스 격파 쇼타임** (`showtime.gd`): 보스 결정타 순간 한 번만 게임을 멈추고 보여 줍니다. 흑백 2프레임 → 보스를 낮게 올려다보는 클로즈업 컷(강조색·먹색 2도 망점 필터, HUD 숨김, 큰 컷인) → 약 1초 뒤 원래 카메라로 돌아오고 0.3초에 걸쳐 정상 속도로 복귀합니다. 탄이 모두 지워진 뒤라 판독성을 해치지 않습니다. 궁극기 락온 중이면 컷인만 나옵니다. MAMMOTH 는 격파 연출(궤도 파손과 전복, `mammoth_b_director.gd`)이 시간·카메라를 맡으므로 쇼타임 대신 컷인 타이포(MAMMOTH DOWN)만 얹습니다. `--noshowtime` 으로 끕니다.

## 적의 거리 벌리기

플레이어가 3.6m 안으로 붙으면 적은 일정 확률로 둘 중 하나로 거리를 벌립니다(한 번 하면 2.4~4초 쉼). 공격을 준비하거나 쏘는 중에는 하지 않습니다.

| 행동 | 내용 |
|---|---|
| 뒷걸음질 | 플레이어를 바라본 채 0.65초 동안 반대쪽으로 물러선다 |
| 이탈 대시 | 반대쪽(비스듬히)으로 0.2초 순간 대시해 잔상을 남기고, 잠깐 멈칫한 뒤 그 기체의 공격 중 하나를 무작위로 쏜다 |

| 기체 | 확률 (붙어 있는 동안 0.45초마다) | 뒷걸음질 : 이탈 대시 | 이탈 대시 뒤 공격 |
|---|---|---|---|
| 기본 드론 | 40% | 75 : 25 | 조준 연사·부채꼴·원형탄 중 하나 |
| 고속 요격기 | 50% | 30 : 70 | 속사·차지 레이저·돌진 베기 중 하나 |
| 중력 크롤러 (거미 상태에서만) | 45% | 55 : 45 | 삼안 3연사·도약 내려찍기 중 하나 |

광선검을 등 뒤로 순간이동해 피하던 **회피 반격은 삭제**되었습니다. 이제 붙어서 휘두른 검은 적이 피하지 않습니다.

바닥 해치에 고정된 포탑과 두 보스(MAMMOTH·VULCAN)는 제자리 패턴으로 싸우므로 거리를 벌리지 않습니다. 확률은 각 기체 `_ready` 의 `evade.chance / back_w`, 동작 수치는 `scripts/evade.gd` 상단 상수에서 조정합니다.

## 테스트 씬: 방 탐색 아레나

로비의 **테스트 씬 → 방 탐색 아레나** 로 들어가는 기존 방 조합 게임입니다.

시작 방에서 출발해 통로로 이어진 **전투방 9곳**을 모두 정리하면 승리합니다. 체력 5칸을 모두 잃으면 패배합니다.

- 맵은 실행할 때마다 새로 생성됩니다. 같은 맵을 다시 보려면 `-- --seed=숫자`로 실행합니다.
- **바닥 굴곡** (`terrain.gd`): 방마다 작고 완만한 둔덕(높이 0.4m 안팎)과 얕게 오목한 자리 2~5곳이 있어 평지만 이어지지 않습니다. 단차는 없고 모두 걸어서 부드럽게 지나가며, 따로 표시하지 않고 조명 음영으로만 드러납니다. 통로·출입구 주변은 평평합니다. 적·탄·이펙트도 바닥 높이를 따릅니다.
  `-- --flat` 으로 실행하면 완전한 평지입니다. 확인: `-- --terrainshow` (출발 방 굴곡을 봇이 걸어 봄), `Godot --headless --path . -s tests/terrain_jump_check.gd -- --seed=11` (굴곡에 단차가 없는지, 걸어서 지나가는지, 실제 키 입력으로 점프 단타/길게 판정 검사).
- 방 형태는 8종입니다: 홀(엄폐물 포함), 원형 광장, L자 회랑, 십자 교차로, 기둥 홀, 고리 광장(가운데 기둥 섬), 팔각 홀, 동굴(원 여러 개가 합쳐진 불규칙형).
- 방은 앞 방에서 뻗어 나가며 트리처럼 이어지고, 가까운 방끼리는 추가 통로가 뚫려 고리형 동선이 생깁니다. 통로는 두 번 이상 꺾이며 구불구불합니다.
- 전투방에 들어서면 출입구가 붉은 차단막으로 닫히고 적이 소환됩니다(동시에 최대 4기). 모두 격파하면 차단막이 열리고 체력이 1칸 회복됩니다.
- **넓은 방**: 전투방 9곳 중 3곳(생성 순서 3·6·9번째)은 보통 방의 **2배 · 2.5배 · 3배** 크기로 넓게 찍힙니다(`map.gd` `BIG_ROOMS`, 자리가 모자라면 배율을 0.1씩 줄여 최소 2배). 기둥·엄폐물도 같이 커지고, 넓은 바닥에 낮은 엄폐벽이 몇 무더기 더 놓입니다. 방 이름 앞에 '대형'이 붙고, 크기만큼 적이 더 많이(2배 방 ×1.5, 3배 방 ×2) 동시에 더 많이 나오며, 플레이어 둘레 16m 안에서 소환됩니다. 맵 격자는 180×180 입니다.
- **웨이브 방**: 넓은 방 중 바닥이 가장 넓은 방은 **5웨이브 방**입니다(`ArenaMap.WAVES`). 들어서면 WAVE 1 / 5 가 뜨고, 한 웨이브를 모두 격파하면 2.4초 숨을 돌린 뒤 다음 웨이브가 몰려옵니다. 웨이브별 적은 5 · 6 · 7 · 8 · 10기이고(`main.gd` `WAVE_SIZES`) 웨이브마다 패턴 난이도가 한 단계씩 오르며, 마지막은 FINAL WAVE 입니다. 5웨이브를 모두 정리해야 차단막이 열립니다. 오른쪽 위에 `WAVE n / 5 · ENEMIES n` 이 표시됩니다.
  확인: `Godot --headless --path . -s tests/room_wave_check.gd` (여러 시드의 넓은 방·웨이브 방 생성, 5웨이브 진행, 30발 탄창·재장전, 어깨 피벗, 회피 반격 삭제 검사).
- 시작 방에서 멀수록 난이도가 올라 적이 많아지고 부채꼴·원형탄 패턴이 섞입니다.
- 전체 적의 20%는 **고속 요격기(Striker)** 입니다. 방마다 반올림 오차를 다음 방으로 넘겨 전체 비율을 맞춥니다(`main.gd` `STRIKER_RATIO`). 뒤로 젖힌 날개와 붉은 발광선을 단 흰 기체로, 플레이어처럼 빠르게 선회하고 잔상을 남기며 옆으로 대시합니다. 짧은 예고 뒤 빠른 탄 4연사를 쏘고, 가끔 멈춰 서서 **차지 레이저**를 쏩니다. 충전하는 1초 동안 바닥에 붉은 띠와 조준선으로 공격 범위를 예고합니다. 앞 0.65초는 조준을 따라오고, 마지막 0.4초는 방향이 고정된 채 빠르게 깜빡입니다(`striker.gd`, `laser_warning.gd`).
- 전체 적의 15%는 **고정 포탑(Turret)** 입니다(main.gd TURRET_RATIO, 요격기와 같은 이월 방식). 십자 받침 위에 파란 포탑 머리와 위아래 두 포신을 얹은 기체로, 옆에 탄약 상자와 탄피가 놓여 있습니다. 하늘에서 떨어지지 않고, 벽가나 구석(우선)의 바닥 해치에 숨어 있다가 나옵니다(map.gd wall_spot). 해치 테두리 경고등이 점점 빠르게 깜빡이고 이음새에서 불똥이 새다가, 두 덮개가 아래로 열리며 연기가 나고, 승강판이 포신을 위로 접은 포탑을 밀어 올립니다. 고정되면 포신을 내려 펴고 사격을 시작합니다. 포탑은 벽을 등지고 방 안쪽을 보며, 부서진 뒤에도 승강판과 꺼진 테두리가 바닥에 남습니다(	urret_hatch.gd). 움직이지 않고 밀려나지도 않으며, 체력이 23으로 높습니다. 머리가 느리게(2.3 rad/s) 돌기 때문에 옆으로 돌아 들어가면 조준을 따돌릴 수 있고, 벽이 가리면 쏘지 않습니다. 조준이 맞으면 0.6초 동안 포신이 돌기 시작하고 포구와 센서가 달아오르며 붉은 조준선이 깜빡인 뒤, 두 포신을 번갈아 8연사합니다. 쏠 때마다 포신이 뒤로 밀리고 탄피가 튀어 바닥에서 튕깁니다. 광선검으로 베면 받침은 남고 포탑 머리만 두 동강 납니다(	urret.gd).
- 전체 적의 12%는 **중력 크롤러(Crawler)** 입니다(`main.gd` `CRAWLER_RATIO`, 같은 이월 방식). 노란 장갑 구체에 짙은 금속 뚜껑과 정면 삼안(파란 발광)을 단 기체로, 평소에는 **구체 상태로 당구공처럼 벽을 튕기며 초고속(19m/s)으로 굴러다닙니다.** 벽이나 다른 적에 부딪히면 반사되고, 튕길 때마다 플레이어 쪽으로 조금 꺾여 들어옵니다. 3~5번 튕기면 급제동해 멈춥니다(`crawler.gd`).
  - **구체 상태는 무적**입니다. 총알은 장갑에 맞으면 **도탄**이 되어 튕겨 나가 주변으로 흩어지고(벽에 한 번 더 튕김), 검·관통 일격·레이저·미사일도 불꽃과 함께 모두 튕겨 냅니다. 검으로 치면 GUARD 와 함께 플레이어가 밀려나고 검 콤보 쿨다운도 초기화되지 않습니다. 빠르게 구르는 동안에는 **몸통 박치기 판정**이 있어 닿으면 피해를 입습니다(대시 무적으로 뚫고 지나갈 수 있음).
  - 멈춘 뒤 **거미처럼 다리 4개를 펼치고 뚜껑을 뒤로 젖혀 붉은 약점 코어를 드러냅니다(WEAK POINT).** 이 동안만 피해가 들어가고(체력 35, 검 5번), 연사에 거의 밀려나지 않습니다. 거미 상태에서는 앞을 들어 올려 힘을 모은 뒤 **세 눈에서 3갈래 3연사**, 이어서 깊게 웅크렸다가 **도약 내려찍기**(착지 지점 예고 → 착지 충격파 + 원형탄 10발)를 하고 다시 구체로 접혀 굴러 나갑니다.
  - 애니메이션은 모두 **느린 준비 → 몇 프레임짜리 임팩트 → 탄성 복귀**의 강약으로 트위닝합니다(Tween: 준비 `EASE_IN`, 임팩트 1~3프레임 `EXPO`, 복귀 `ELASTIC`). 발진 전에는 반대로 젖히며 납작하게 웅크리고 제자리에서 헛돌며 불꽃을 튀기다가 2프레임 만에 앞으로 쭉 늘어나며 튀어 나가고, 벽에 부딪히면 1프레임 동안 납작하게 눌렸다가 튀어 나옵니다. 변신은 천천히 웅크리고 몸을 비틀며 뚜껑 틈으로 붉은 빛이 새다가 3프레임 만에 다리가 튀어나오고 몸통이 솟으며(살짝 넘쳤다 자리 잡음), 접을 때는 몸을 천천히 들어 올려 떨다가 3프레임 만에 구체로 떨어집니다. 다리는 2관절 IK 로 발을 바닥에 두고 걸음을 뗍니다.
- 오른쪽 위 미니맵은 가까이 간 곳만 드러납니다. 방 표식은 대기(분홍 원), 전투 중(깜빡이는 빨강), 정리됨(파랑 점)을 나타냅니다.

타격감을 위해 명중 시 흰색 섬광과 몸체 튕김을 넣었습니다. 로봇은 스프링 기울기와 찌그러짐으로 사격·레이저 반동, 피격, 착지, 찌르기에 반응하고, 서 있을 때는 숨을 쉽니다. 부스터 비행 중에는 떠오르며 다리를 모으고 노즐 불꽃과 배기를 뿜습니다. 사망 시에는 파츠가 흩어지고, 승리하면 점프하며 한 바퀴 돕니다. 적은 공격 전 뒤로 젖혔다가 쏘는 순간 앞으로 튕기고, 맞으면 맞은 방향으로 휘청입니다.
적의 죽음 연출은 5종입니다: 광선검 절단(비스듬히 잘린 두 조각이 달아오른 절단면을 드러내며 미끄러져 떨어지고, 식어 가며 불똥을 떨어뜨림), 즉시 폭발, 과부하(떨며 부풀다 대폭발), 튕겨 날아감(회전하며 연기를 뿜다 추락 폭발), 전원 차단(코어가 꺼져 떨어지고 쓰러져 지직거리다 붕괴). 검으로 죽이면 항상 절단, 레이저로 죽이면 과부하가 자주 나옵니다. 죽으면 몸체가 조각나 튀고 바닥에서 튕기며 흩어집니다(`debris.gd`).
카메라는 `camera_rig.gd`의 프리셋별로 추적 속도, 이동 선행, 좌우 기울기, 대시·발사 FOV 펀치, 부스터 속도 줌아웃, 격파 지점 끌림을 다르게 씁니다.
히트스탑 동안에는 카메라 추적과 흔들림도 함께 멈추고, 흔들림은 부드러운 노이즈를 씁니다. 격파 순간에는 짧게 시간을 멈추고 화면을 약하게 흔듭니다. 화면 흔들림은 조준을 방해하지 않도록 작게 잡았습니다.

## 추격 보스전 — MAMMOTH

`boss_battle.cmd` 로 바로 실행하거나, 게임 중 **B** 키로 방 탐색 → 추격 보스전 → 용광로 보스전 순서로 오갑니다.

- 뒤로 달아나며(후진) 포구를 플레이어에게 겨눈 채 싸우는 4궤도 데포르메 중전차입니다. 플레이어는 부스터가 **무한**으로 켜진 채 날아서 쫓아갑니다.
- 배경은 무한 반복됩니다. 플레이어와 보스는 원점 근처에 머물고, 바닥 셰이더 무늬·양옆 벽/가로등/탑 구간(12m × 11개 재활용)·공중 바람 줄기가 도로 속도(1페이즈 42m/s → 2페이즈 56m/s)로 뒤로 흐릅니다.
- 속도감: 화면 가장자리 방사형 모션 블러와 색수차, 깜빡이는 집중선(`speed_fx.gd`), 바닥 이음선 번짐, 고속 주행 미세 진동, 도로 속도로 흩날리는 배기·흙먼지·부스터 불꽃.
- 등장하면 화면 상단에 큰 체력바가 차오릅니다. 깎인 만큼 흰 잔량이 뒤따르고, 40% 위치에 페이즈 경계 눈금, 아래에 현재 패턴 이름이 표시됩니다.

| 페이즈 | 패턴 | 피하는 법 |
|---|---|---|
| 1 | 쌍포 조준 연사 | 왼포는 현재 위치, 오른포는 이동 예측 위치로 좁은 부채꼴 3회. 옆으로 크게 움직이다 방향을 꺾는다 |
| 1 | 개틀링 교차 소사 | 양쪽 보조포가 X자로 쓸어내는 탄줄. 탄줄의 끊긴 틈(5발 쏘고 3발 쉼)으로 빠져나간다 |
| 1 | 추적 미사일 폭격 | 서 있던 자리에 0.32초 간격으로 경고 원이 찍히고 1.15초 뒤 폭발. 계속 움직인다 |
| 1 | 틈새 원형탄 | 원형 파동 4번. 틈이 매번 좌우로 옮겨 가므로 틈을 따라 이동한다 |
| 2 | 이중 나선 탄막 | 빠른 4갈래 나선 + 반대로 도는 큰 탄 4갈래 + 쌍포 조준탄 |
| 2 | 레인 포격 | 5차선 중 3차선에 1초 예고 후 포격. 안전 차선(붙은 두 칸)이 매번 바뀐다 |
| 2 | **거수포 (강력 예고 공격)** | 2.6초 충전하며 화면이 어두워지고 폭 5m 붉은 띠로 사선을 예고, 1.8초에 조준 고정. 맞으면 **체력 3칸**. 쏜 뒤 3.5초간 코어가 과열되어 **약점 노출 · 피해 2배** |

- 체력 40%에서 2페이즈: 탄이 모두 지워지고 연쇄 폭발과 함께 보조포·미사일 포드·귀 포드·장갑 조각이 떨어져 나가 도로에 튕기며 뒤로 흘러갑니다. 떨어진 자리는 달아오른 소켓과 그을음이 남고 불꽃·연기를 계속 뿜습니다. 도로 속도도 빨라집니다.
- 격파: **죽음 연출 B안 "궤도 파손과 전복"**(5.7초 컷씬)이 재생됩니다. 궤도가 뜯겨 나간 차체가 관성으로 돌며 도로를 긁고, 공중에서 뒤집히며 포탑이 뜯겨 나가고, 지붕으로 떨어져 갈리다 연쇄 폭발한 뒤 쿼터뷰로 돌아오면 승리 화면이 뜹니다. 연출 중 플레이어는 반대 차선으로 자동 비행하며 무적입니다. 감독은 `scripts/lab_mammoth_b/mammoth_b_director.gd` 로, 로비의 연출 테스트 씬과 같은 것을 씁니다.
- **강력 레이저 피격 들림**: 충전 레이저·지속 레이저에 맞으면 맞은 쪽 차체가 들리며(반대쪽 궤도 모서리가 축이 되어 도로에 갈림) 마구 떨리다가, 다시 떨어질 때 모서리가 도로를 찍습니다. 왼쪽에서 맞으면 왼쪽이 들립니다 (`scripts/presentation/mammoth_hit_lift.gd`).
- **흐르는 공간** (`scripts/presentation/world_flow.gd`): 도로가 흐르는 만큼 연출도 함께 흘러갑니다. 탄피·벽/몸체 파편·잔해 조각은 바닥에 닿는 순간 흐르는 도로에 끌려 구르며 화면 아래로 빠져나가고, 연기·불꽃·폭발·충격파·미사일 연기 꼬리는 공기처럼 처음엔 제자리였다가 점점 도로 속도로 끌려갑니다(짧은 섬광은 거의 제자리). 폭발 그을음·레이저 그을음 같은 바닥 흔적은 도로와 같은 속도로 흐릅니다. 총구 화염·검기·레이저 빔처럼 기체에 붙은 연출과 보스 공격 예고(판정)는 흐르지 않습니다.
- 기본총 연출: 추격전 카메라가 멀고 넓어 총 연출을 1.6배로 그리고(`BossMain.VIEW_K` → `ToonGunFX.view_k`), 착탄 연출은 판정점 대신 차체 겉면(`BossEnemy.fx_point`)에 띄워 차체에 가려지지 않게 합니다.
- **근접 견제 (붙어서 검만 휘두르기 방지)**: 보스 중심 7.5m 안에 붙어 있으면 패턴과 별개로
  - 0.25초 푸른 섬광 뒤 장갑 틈에서 **푸른 경직탄**을 플레이어 쪽 부채꼴로 흩뿌립니다(1페이즈 5발/1.2초, 2페이즈 7발/0.85초).
  - 0.6초마다 확률(기본 35%, 오래 붙어 있을수록 최대 +30%)로 **밀쳐내기 충격파**를 씁니다. 반경 9m 푸른 경고 원이 0.55초 차오른 뒤 터지며, 안에 있으면 앞으로 크게 밀려나고(피해 없음, 돌진·대시가 끊김), 앞쪽 반원으로 푸른 경직탄 11발이 퍼집니다. 대시(구르기) 중이면 밀리지 않습니다. 쿨다운 3.2초, 거수포 충전 중에는 쓰지 않습니다.
  - 검으로 보스를 맞혀도 검 쿨다운이 초기화되지 않습니다(일반 적 처치 시 초기화는 그대로).
- **푸른 경직탄**: 크고 느린 푸른 구체. **검(베기·관통 일격)으로 지워지지 않고**, 맞으면 체력 1칸 + **0.7초 경직**(이동·사격·검·대시·충전 불가, 모으던 충전·지속 레이저 취소). 레이저로는 지울 수 있습니다. 근접 견제 외에도 틈새 원형탄·이중 나선(느린 큰 탄)·거수포 충전 중 원형탄에 섞여 나옵니다. 수치는 `boss_enemy.gd` 상단 `NEAR_R`·`SHOCK_*`·`STUN_TIME`.
- 보스는 검·관통 일격에 한 번에 죽지 않습니다(각각 12, 22 피해). 체력·페이즈 경계는 `boss_enemy.gd` 상단 `MAX_HP`·`PHASE2_AT`, 도로 속도는 `boss_main.gd` 의 `SPEED_1`·`SPEED_2` 입니다.

## 용광로 보스전 — VULCAN

`forge_battle.cmd` 로 바로 실행하거나, 게임 중 **B** 키로 방 탐색 → 추격 보스전 → 용광로 보스전 순서로 오갑니다.

- 전장: 사방이 용암인 용광로 한가운데 떠 있는 **팔각 발판**(반경 12m) 하나. 벽 대신 발판 가장자리가 경계이고, 동·서쪽으로 이어지던 통로는 붉은 차단막으로 막혀 있습니다. 둘레에 쇳물 통·용암 폭포·쇠사슬에 매달린 도가니·용광로 벽이 서 있고, 용암에서 불티와 연기가 끊임없이 피어오릅니다.
- 보스: 발판 북쪽 용광로 구덩이에서 솟아오르는 **거대 로봇 VULCAN**. 하반신이 용암에 잠긴 채 움직이지 않고, 두 팔(끝이 도가니 포신인 2관절 IK 팔)과 둥근 얼굴판의 **다섯 눈**으로 싸웁니다. 머리는 플레이어를 내려다보며 따라가고, 턱에서는 쇳물이 흘러내립니다.
- 팔을 내려찍은 뒤 포신이 발판에 박혀 있는 동안에는 **포신도 맞출 수 있습니다**(피해 1.35배, 검으로 베면 CRUSH). 박힌 포신은 플레이어를 밀어냅니다.
- 쇳물 웅덩이(내려찍기·슬래그가 남김)는 몇 초간 남아 밟으면 피해를 입습니다(대시 중에는 무시).

| 페이즈 | 패턴 | 피하는 법 |
|---|---|---|
| 1 | 용광포 화염 분사 | 한 팔이 포신을 겨누고 바닥에 **부채꼴**로 범위 예고(0.7초에 조준 고정) → 불길. 좌우 번갈아 4회. 부채꼴 옆으로 빠지거나 대시 |
| 1 | 도가니 내려찍기 | 포신이 머리 위에서 따라오다 원 경고 뒤 내려찍음 → 충격파 탄 12발 + 쇳물 웅덩이. 박힌 포신을 공격할 기회 |
| 1 | 오안 조준 사격 | 다섯 눈이 차례로 달아올라 조준 3연탄 ×10, 이어서 남쪽 반원 탄막 2파(두 번째는 반 칸 어긋남) |
| 1 | 슬래그 낙하 | 도가니가 기울어 쇳물을 쏟고, 플레이어 자리와 발판 곳곳에 원 경고 → 1.1초 뒤 쇳물 덩이 낙하 |
| 2 | **노심 화염 방사 (강력 예고 공격)** | 1.9초 충전 동안 화면이 어두워지고 부채꼴 전체 + 시작 사선을 예고 → 굵은 화염 빔이 발판을 끝에서 끝까지 쓸어 감. 맞으면 **체력 2칸**. **대시(무적)로 빔을 뚫고 지나가야** 함. 쏜 뒤 3.6초 과열: **약점 노출 · 피해 2배**, 두 팔도 발판에 늘어져 공격 가능 |
| 2 | 연속 내려찍기 | 두 팔이 번갈아 6회, 충격파 탄 16발 |
| 2 | 용암 분출 | 남은 발판을 8조각 부채꼴 + 가운데 원으로 나눠 6조각과 가운데에 예고 → 용암 기둥. 붙은 두 조각만 안전, 4회 |
| 2 | 쌍 용광포 교차 분사 | 두 팔이 동시에: 한쪽은 현재 위치, 한쪽은 이동 예측 위치 |

- 체력 40%에서 2페이즈: 포효 → 가슴 장갑판과 창살이 터져 나가 **노심이 드러나고**, 두 팔로 발판을 내리치면 바깥 고리 8조각이 갈라져 달아오른 뒤 북쪽부터 차례로 **용암에 가라앉습니다**. 전장 반경이 12m → 8m 로 줄어 플레이어는 안쪽으로 밀려납니다. 용암도 더 밝게 끓습니다.
- 격파: 눈이 하나씩 꺼지고 팔이 늘어져 용암에 잠기며 연쇄 폭발 → 대폭발과 함께 머리·팔이 튕겨 나가고 몸통이 용암 속으로 가라앉습니다.
- 체력·페이즈 경계는 `forge_boss.gd` 상단 `MAX_HP`·`PHASE2_AT`, 발판 크기는 `forge_stage.gd` 의 `R_OUTER`·`R_INNER` 입니다.

## 검증용 실행 인자

씬을 지정하지 않고 실행 인자(`--bot`·`--capture=` 등)를 주면 로비를 건너뛰고 섹터 런으로 바로 들어갑니다(`--test` 를 더하면 방 탐색 아레나). 아래 방 탐색 명령은 `main.tscn` 을 직접 지정합니다.

아래의 `Godot --path .` 는 고정 버전 실행기로 바꿔 씁니다: `powershell -File tools\godot.ps1 wait <인자...>` (`--path` 는 실행기가 붙입니다). 예: `powershell -File tools\godot.ps1 wait --fixed-fps 60 res://scenes/main.tscn -- --bot --seed=1`

```
Godot --path . --fixed-fps 60 res://scenes/main.tscn -- --bot --seed=1       # 자동 플레이 (방을 찾아가며 전투)
Godot --path . res://scenes/main.tscn -- --bot --overview --seed=1           # 맵 전체 조감
Godot --path . --fixed-fps 60 res://scenes/main.tscn -- --capture=DIR --every=10 --seconds=30 --bot
Godot --path . --fixed-fps 60 res://scenes/main.tscn -- --capture=DIR --every=2 --seconds=6 --showcase   # 연출 순서 재생
Godot --path . --fixed-fps 60 res://scenes/boss.tscn -- --capture=DIR --every=10 --seconds=70 --bot --godmode   # 보스전 자동 플레이 (무적)
Godot --path . --fixed-fps 60 res://scenes/boss.tscn -- --capture=DIR --every=3 --seconds=45 --bot --hug   # 보스에 붙어 검만 연타 (근접 견제 검증: BOSS_SHOCK / PLAYER_STUN 로그)
Godot --path . --fixed-fps 60 res://scenes/forge.tscn -- --capture=DIR --every=30 --seconds=40 --bot --godmode   # 용광로 보스전 자동 플레이 (무적)
Godot --path . --fixed-fps 60 res://scenes/forge.tscn -- --capture=DIR --every=30 --seconds=34 --bot --godmode --fastp2   # 6초 뒤 바로 2페이즈로
Godot --path . --fixed-fps 60 res://scenes/abyss.tscn -- --capture=DIR --every=60 --seconds=200 --bot --godmode   # 심연 성소 전 페이즈 자동 플레이
Godot --path . --fixed-fps 60 res://scenes/abyss.tscn -- --capture=DIR --every=60 --seconds=40 --bot --godmode --phase=5   # 중간보스부터 (--phase=6 은 2페이즈부터)
Godot --path . --fixed-fps 60 res://scenes/abyss.tscn -- --capture=DIR --every=30 --seconds=10 --foeshow --campreset=2   # 적 셋 근접 관찰
Godot --path . --fixed-fps 60 res://scenes/boss.tscn -- --capture=DIR --every=2 --seconds=16 --godmode --fastp2 --fastkill=1   # 2페이즈 1초 뒤 격파 → 격파 연출 + MAMMOTH DOWN 컷인 확인 (CUTIN 로그)
Godot --path . --fixed-fps 60 res://scenes/forge.tscn -- --capture=DIR --every=3 --seconds=40 --godmode --fastp2 --fastkill=16   # 노심 화염 방사 붉은 섬광 · 퍼펙트 회피 → 격파 쇼타임 (DANGER_WARN / PERFECT_EVADE 로그)
Godot --path . --fixed-fps 60 res://scenes/main.tscn -- --capture=res://_capture/crawl --every=1 --seconds=18 --crawlershow --seed=3 --campreset=3   # 전투방에 크롤러 하나: 구르기·반사·도탄·변신·공격·처치 (CRAWLER/CPOS 로그 → _capture/crop.py 로 근접 시트)
Godot --path . --fixed-fps 60 res://scenes/main.tscn -- --capture=DIR --every=2 --seconds=11 --parryshow  # 패링 탄 드론 + 5.5초 뒤 돌진 요격기, 자동으로 패링 (PARRY 로그의 f 값 ÷ every = 프레임 번호)
Godot --path . --fixed-fps 60 res://scenes/main.tscn -- --capture=DIR --every=2 --seconds=20 --evadeshow  # 전투방에 드론 둘·요격기·크롤러, 봇이 붙어서 검을 연타 (EVADE back/dash 로그)
Godot --path . --fixed-fps 60 res://scenes/main.tscn -- --capture=DIR --every=3 --seconds=8 --turretshow  # 시작 방 벽가 해치에서 포탑 둘을 올려 등장·조준·연사·절단·폭발 확인
```

폭발 시연 영상(근접 · 슬로모션 · 게임 시점): `Godot --path . --fixed-fps 60 --write-movie _capture/explo1/f.png -s _capture/explosion_show.gd`

공간 왜곡(굴절 충격파 · 폭발 아지랑이, `scripts/distortion_fx.gd`) 시연: `Godot --path . --fixed-fps 60 --resolution 1280x720 --write-movie _capture/distort/f.png -s _capture/distortion_show.gd`

`_capture/cap.ps1`이 위 캡처를 실행하고 콘택트 시트를 만듭니다(Python + Pillow 필요).

## 한정 재화 (에너지 · 미사일)

- **에너지** 최대 3칸(`Player.ENERGY_MAX`): 충전 레이저 탄창. 9초마다 1칸씩 저절로 차고(`ENERGY_REGEN`), 적이 떨어뜨리는 청록 결정을 주워도 찹니다.
- **미사일** 최대 12발(`Player.MISSILE_MAX`, 시작 4발): 궁극기 탄. 적이 죽을 때 가끔(30%, `Main.DROP_MISSILE`) 그 자리에 주황 미사일 아이템이 튀어나옵니다. 플레이어가 직접 가서 닿아야 먹히고, 18초 뒤 깜빡이다 사라집니다. 가득 차 있으면 먹지 않고 남습니다. 보스전에서는 보스 체력이 10% 깎일 때마다 보스 앞에 떨어집니다.
- HUD 왼쪽: 최대치만큼 아이콘 칸이 늘 반투명하게 있고, 가진 개수만큼 불투명하게 켜집니다. 얻으면 튀어 오르며 켜지고, 쓰면 번쩍이며 꺼집니다. 충전 중에는 쓰일 칸이 깜빡이고, 다음 에너지 재충전 진행도가 칸 아래 줄로 보입니다.
- 섹터 런에서는 두 재화가 체력처럼 다음 칸으로 이어집니다. 검증: `Godot --headless --path . -s tests/ammo_check.gd`
