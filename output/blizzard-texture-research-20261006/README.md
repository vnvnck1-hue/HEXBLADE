# 블리자드 배경 텍스처 리서치와 분석

2026-10-06. 사용자가 앞선 3안에 “별 변화가 없다”고 평가하고, 먼저 블리자드식 배경 텍스처를 리서치하고 이미지 자료를 모으라고 요청했다. 이번 단계는 **자료 수집과 분석까지**다. 새 텍스처 생성이나 본편 적용은 하지 않았다. 앞선 42장 시안은 채택되지 않은 비교 자료로 보존한다.

## 결론

앞선 시안은 현재 색과 UV 형태를 보존하는 데 집중했고, 넓은 면에 대각선 붓결과 작은 모서리 마모를 더했다. 실제 하스스톤 보드와 WoW의 금속 텍스처에서는 **큰 면의 밝고 어두운 덩어리, 두꺼운 베벨, 접합부의 깊이, 재질마다 다른 하이라이트**가 먼저 읽힌다. 이 차이가 앞선 시안에는 충분하지 않았다.

현재 배경의 전체 명도·채도를 유지하는 것과, 각 면 내부의 명암을 평평하게 유지하는 것은 다르다. 다음 작업에서는 넓은 밝은 면과 어두운 홈을 재배치해 입체감을 키우되, 화면 전체의 청보라 색감과 밝기 균형을 유지해야 한다. 평균 HSV 차이가 작다는 검증만으로 원하는 그림체를 입증할 수 없다.

## 작가 설명으로 확인한 사실

Ben Thompson은 The Box의 첫 이미지와 마지막 이미지가 시네마틱 팀의 고해상도 출력 위에 표면 질감·색을 페인트오버한 자료이고, 두 번째는 인게임 모습이라고 설명한다. 같은 묶음 안의 모든 이미지를 인게임 텍스처로 취급하면 안 된다. [작가 원문](https://benthompsonart.artstation.com/projects/d88Ro1)

Robin Dao는 Nathria 보드에서 자신이 모델링·UV·텍스처 정리·애니메이션 등을 맡았고, 2D 일러스트는 Jay Axer가 만들었다고 설명한다. 보드 그림과 3D 결과는 연결된 제작물이다. 이것을 모든 블리자드 게임이 같은 제작 방식이라는 주장으로 확대하지 않는다. [작가 원문](https://robindao.artstation.com/projects/9Eb1WQ)

Ryan Cooper는 공개할 수 있는 Mechagon 텍스처를 한 시트로 모았다고 설명한다. 시트 자체는 재질 표현 분석에, 배경 스크린샷은 조명과 사용 맥락 분석에 쓴다. 이미지 하단에는 추가 작업자로 Lianna Tai와 Ishmael Hoover도 표기되어 있어 공동 작업 크레딧을 유지한다. [작가 원문](https://lowpoly.artstation.com/projects/58o3EP)

Ishmael Hoover의 공개 강의 소개에는 스타일 분석·프리비즈·선·명도·색·추가 텍스처·프레젠테이션 단계가 제시된다. **공개 소개와 목차만 확인했으며 유료 강의 전체를 시청한 것은 아니다.** [제작자 공개 소개](https://www.artstation.com/marketplace/p/WJrG/creating-stylized-textures-for-games-ishmael-hoover)

## 앞선 시안이 약했던 이유

1. A/B/C가 서로 다른 재질 해석보다 붓결·베벨·마모의 강도 차이에 머물렀다. 작은 크기의 실제 모델에서는 차이가 줄었다. [직전 실제 비교](../hearthstone-prop-textures-20261006/comparison_detail.png)
2. 평균 명도·채도 유지에 지나치게 집중했다. 그 조건 자체는 사용자 요청에 맞지만, 재질과 입체감이 더 뚜렷한지 판단하는 기준을 대체할 수 없다.
3. 모든 넓은 면에 비슷한 사선 붓질을 주어, 금속의 반사 면·패널의 층·원통의 곡률이 약하게 구분됐다.
4. 작은 마모와 가장자리 선은 늘었지만, 큰 면의 밝고 어두운 덩어리를 충분히 다시 설계하지 않았다.
5. 14종 전체를 먼저 확장해 스타일이 약한 문제가 여러 파일에 반복됐다. 다음에는 바닥·벽·탱크처럼 성격이 다른 대표 프랍에서 표현을 먼저 확인해야 한다.

## 다음 제작 기준 제안

현재 단계에서 새 제작을 실행하지 않았다. 재개 시 아래 기준으로 진행한다.

- **유지할 것:** 본편의 전체 청보라 색감과 명도·채도 균형, 원래 모델·UV·반복 규격, 거친 손상을 피하라는 기존 취향.
- **분명히 바꿀 것:** 큰 명암 덩어리, 패널의 층과 베벨 두께, 볼트·홈의 깊이, 원통의 반사 띠, 재질별 스트로크 방향.
- **새 3안은 표현 구조를 다르게:** 둥근 주조 금속 / 판이 겹쳐진 판금 / 두꺼운 도장·에나멜의 세 방향으로 먼저 바닥·벽·탱크 샘플을 설계한다. 색만 바꾼 세트나 마모량만 다른 세트는 피한다. 사용자 채택 전 제안이다.
- **먼저 큰 덩어리 검토:** 흑백 축소 이미지에서도 면의 깊이와 재질 차이가 읽히는지 본다. 거친 노이즈와 작은 흠집은 마지막이다.
- **게임 카메라 크기로 검토:** UV PNG 확대, 무조명 모델, 동일 조명의 실제 쿼터뷰를 함께 비교한다. 작은 인게임 크기에서 차이가 안 보이면 전체 프랍으로 확장하지 않는다.
- **색 유지의 해석:** 화면 전체의 밝기·색 균형을 유지하면서 한 판 안의 밝은 면과 어두운 홈은 달라질 수 있게 한다. UV 섬 평균 수치만 맞춘 결과로 성공을 판단하지 않는다.
- **직접 적용용 결과:** 선택한 그림은 PNG 그대로 사용하고, 실제 적용 시 기존 절차 붓 혼합과 재착색으로 다시 해석하지 않는다. 바닥은 기존 4m 월드 XZ 반복, 나머지 프랍은 원래 UV를 사용한다.

## 수집 검증

6개 출처와 30개 원본 URL이 각각 저장 파일에 연결됨을 확인했다. 30장 모두 이미지 디코딩 성공, 저장 SHA256 일치. 대표 보드·텍스처 시트·금속 확대를 육안 확인했다. 직접 페이지 수집은 403으로 실패했고 일부 브라우저 자산 묶음도 실패했으나, 브라우저에서 확인한 공개 원본 URL을 직접 내려받아 최종 원본 30장은 모두 확보했다. 실패한 수집 시도는 `pages_manifest.json`에 남겨 최종 성공 결과와 구분한다.

이번에 게임 코드·본편 리소스 변경, 엔진 실행, 새 이미지 생성, 커밋·푸시는 하지 않았다.
