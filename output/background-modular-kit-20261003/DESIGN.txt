HEXBLADE 보라/코랄 정비시설 모듈 키트 — 모델링용 설계 v2
상태: 42종 컬러 3면도 및 조립 설계 인수본. 실제 모델/텍스처 납품본은 아님.
기준: 사용자 승인 01_base_v6_reference_palette / 03_infected_v6_reference_palette.
범위: 해당 원화의 바닥, 벽, 문, 배관, 난간, 작업용 소품, 감염물. 실제 GLB/게임 배치 제작은 이번 범위 아님.
낱개 나사까지 독립 에셋으로 나누지 않는다. A04는 판+걸이+공구 3개의 조립 프랍이며, 모델 제작 시 하위 메시로 분리한다.

1. 도면 읽기 / 좌표
Godot 좌표: +Y 위, -Z 정면, X 가로. 단위 m.
FRONT= -Z에서 +Z를 봄, RIGHT= +X에서 -X를 봄, TOP= +Y에서 -Y를 봄.
도면의 회화적 미세 차이보다 이 문서와 kit_manifest.json의 치수/접속 정의가 우선.
PNG는 컬러 모델링 가이드이며 CAD 투영으로 생성된 것이 아니다. 이미지의 픽셀 길이를 실제 치수로 환산하지 말 것.
Blender 제작 시 단위를 미터로 설정하고 Godot 변환 후 위 축과 접속점이 일치하는지 확인.
공통 배치 그리드 .25m, 바닥 주 모듈 2m, 벽 높이 3m. 비균일 스케일로 길이 맞추기 금지.
도면별 필요한 치수는 X/Y/Z로 기록. 회전은 건축 90도 단위, 감염만 표면에 맞게 회전 허용.

2. 피벗 계약
floor: 좌측 앞 윗모서리 (0,0,0), X=[0,width], Z=[0,depth], Y=[-height,0].
F04 돌기는 Y=0~.02. 충돌 바닥은 평평한 Y=0.
wall: 좌측 앞 바닥 (0,0,0), X=[0,width], Y=[0,height], Z=[0,depth].
W02 이음 덮개는 이 범위를 유지하고 배치 시 X=-.125, Z=-.12 오프셋.
W03 L 모서리 캡은 두 벽이 만나는 코너 기준. .08 두께의 L 단면, 각 날개 .35, 건축 치수에는 더하지 않음.
prop: 바닥 중심 (0,0,0), X/Z 중심 정렬, Y=[0,height].
mount: 벽에 닿는 후면 중심 (0,0,0), X/Y 중심 정렬, Z=[-depth,0].
decal: 좌측 앞 코너, X/Z 양수, Y=.002. 두께 .002는 띄움 거리이며 실제 두꺼운 판이 아님.
pipe: 접속 중심선 원점. P01은 X=0부터2, 끝단 법선 -X/+X.
rail: 아래 기둥 기준 바닥 높이 Y=0 유지. 바의 실제 Y 최솟값으로 피벗을 옮기지 않음.
organic: 부착 표면 원점, 바닥 배치 시 +Y가 바깥쪽. I01/I06 첫 목 중심 X=0,Y=.06,Z=0.

3. 바닥 / 벽 조립
F01 2x2 슬롯 = F02 2x1 두 장 = F03 2x.5 네 장. F04 1x1 네 장도 같은 슬롯.
외곽 F05 2x.25는 기존 바닥 위에 겹치는 판이 아니라 .25 폭 외곽 슬롯을 채움.
타일 실제 외형 폭/깊이는 명목치수 그대로. 경계 위쪽 8mm 베벨로 줄눈 표현, 판을 축소해 틈을 뚫지 않음.
모든 바닥 상면 Y=0, 옆판 바닥 Y=-.2. 접합부의 돌출 볼트는 금지; 도면의 옆 볼트는 페인트/노멀 또는 매립.
큰 마모 칠은 면 중앙/선택 모서리에만. 한 타일 전체를 둘러싼 밝은 코랄 테두리는 억제.
W01은 X 2m 간격으로 이어붙임, 벽 하단 Y=0. W02는 이음 앞을 덮는 장식이므로 벽 간격에 추가하지 않음.
W06은 벽 정면 Z=-.1~0, W07은 벽 두께 중심 Z=.125에 정렬하여 .05씩 양쪽 돌출.
직각 벽은 겹치는 코너 영역 .25x.25를 한쪽 벽만 소유하도록 배치; 중복 내부 면은 모델링 단계에서 제거/숨김.
W03 L 캡은 외부 모서리의 얇은 장식 겹침을 의도한다. 양쪽 벽의 전체 높이나 길이를 늘리지 않음.

4. 문 조립
W04 총폭4, 높이3, 깊이.5. 통과 구멍 X=.25~3.75,Y=0~2.5.
W05 두 장 각1.74x2.48x.12. 닫힌 상태 왼쪽 X=.255~1.995, 오른쪽 X=2.005~3.745, Y=.01~2.49.
문짝 앞면 Z=.06, 뒷면=.18. 문틀과 문짝은 독립 메시. 오른쪽은 반대손 형상으로 제작(음수 스케일 미사용).
중앙 이음10mm, 좌우 벽 여유5mm, 상하10mm. 통로 너비3.5m.
완전 열림은 각 문짝을 바깥쪽1.75m 이동. 양옆 W01 한 장씩은 비어 있는 포켓용 벽으로 사용하고 내부는 충돌에서 제외.
포켓 내부 깊이 .04~.20 보장(문 앞뒤 각각 .02 여유). 일반 벽을 그대로 두고 문을 관통시키지 말 것; 포켓용 W01은 같은 외피, 내부만 빈 파생형.
중앙 바닥에는 문턱을 추가하지 않는다. 문 상단 레일은 W04 헤더 내부에 포함.
W04 양쪽 세로 기둥에도 Z=.04~.20 관통 슬릿을 남겨 문짝이 포켓으로 이동하게 한다. 이 구간에 볼트/가로 보강재/충돌을 넣지 않는다.

5. 배관 접속
모든 주 배관 외경 .25, 내경 .21. 끝면 법선과 중심을 맞춰 스냅한다.
P01 A=(0,0,0), 법선(-1,0,0); B=(2,0,0), 법선(1,0,0).
P02 곡률 중심=(0,0,0), 중심선 r=.5, XZ 1사분면:
 A=(.5,0,0), 법선(0,0,-1); B=(0,0,.5), 법선(-1,0,0).
P02 외형은 X/Z 0~.625, 소켓 중심선 반경 .5와 외형 치수 .625를 혼동 금지.
P03 A=(-.5,0,0),법선(-1,0,0); B=(.5,0,0),법선(1,0,0); C=(0,0,.5),법선(0,0,1).
P04 링은 연결점 중앙에 배치, 축 X, 양쪽 .06씩 덮음. 외경.35 내경.252. 접속점마다 링 1개만.
P05는 열린 끝 한 곳에만. 링+캡 동시 중복 금지.
벽 부착 중심선은 벽 앞면에서 .25m 떨어짐: 관 반경 .125, 링 반경 .175이므로 벽 여유 최소 .075.
P01은 필요 시 .5/1m 길이 파생 제작 가능하되 UV 반복률과 단면 동일. 원형 단면을 비균일 확대 금지.
A12 가는 도관 .08은 별도 규격이며 주 배관 .25와 직접 연결하지 않음.

6. 난간 접속
R01 수평 바 중심 Y=.25/.95, 지름 .08, X=0~2. 기둥 없음.
R03 단독 기둥을 X=0,2,4...에 1개씩 배치. 공유 지점 기둥을 중복 배치하지 않음.
R01은 기둥 중심까지 삽입하며 겹침은 내부 삽입 구간만. 끝 노출은 기둥이 막음.
R02 코너는 반경 .25 곡선; 끝 중심은 (.25,Y,0),(0,Y,.25), 각 Y=.25/.95.
R02를 쓸 때 직선 바 끝은 코너 이론 교점에서 .25m 전에서 종료. 해당 구간은 R01 길이 파생 1.75m로 제작, 단면과 UV 유지.
R02의 .5x.5 값은 배치 예약 영역. 실제 외형은 곡선+반경 .04이므로 .29 범위.
난간은 이동을 막는 장식 경계. 전투 중앙이나 문구멍 앞에는 놓지 않음.
R03의 기본 소켓 축은 로컬 Z. 직선 X 난간에서는 기둥을 Y축 90도 회전한다. 중간 기둥은 같은 두 높이에 양방향 관통 구멍, 끝 기둥은 한쪽만 열린 파생형. PNG는 끝 기둥 외관을 보여준다.
R03 받침 .25x.25 안에 소켓을 넣는다. 코너 곡선 한가운데 기둥을 중복 추가하지 않고 양쪽 직선 끝에서 지지한다.

7. 프랍 결합
A01 작업대 2m는 W01 한 장 폭. 후면을 벽에서 .05m 띄우며 깊이 .75m. A04 공구판 중심 높이1.8m.
A05/A08은 작업대 상면 Y=1 위, A09는 상판 앞 모서리에 걸침. 기본 피벗 예외 A09는 접히는 선 중앙.
A02 수납장은 바닥 부착, A03 전기함은 후면 부착. 외형을 섞어 벽 자체 대신 쓰지 않음.
A10 벽등 중심2.5m, A11 표시등 중심1.25m. A13 호스는 A04 옆 빈 벽에 부착.
A07 빗자루는 독립 소품, 설치 때만 기울임. 기울임 후 발이 바닥을 뚫지 않게 재정렬.
A04의 판/훅/공구3개, A01의 상판/서랍, A02의 문, A05의 뚜껑/손잡이는 하위 메시 분리 대상으로 둔다.
현재 요청은 배경 프랍이며 문 개폐 이외 상호작용/물리/파괴 기능을 추가하지 않음.

8. 감염 레이어
기본 벽/바닥을 감염 버전 모델로 복제하지 않음. I01~I06 독립 에셋과 표면 마스크로 중첩.
I01 양끝 접속 목 지름 .12, 중심 (0,.06,0),(1,.06,0), 법선 -X/+X.
I02 중심선 반경 .25, 접속 중심(.25,.06,0),(0,.06,.25), 법선 -Z/-X.
I03 주 목(-.5,.06,0),(.5,.06,0), 분기(0,.06,.4), 각각 -X/+X/+Z; 목 주변 .08 구간은 일정 단면.
I06 (0,.06,0) -X 방향 접속, X=.5에서 봉합된 끝. 막힌 끝끼리 붙이지 않음.
I04 얇은 막은 바닥/벽에 맞춰 5~15mm 띄우거나 버텍스 밀착. I05는 넓은 부착면으로 감싼다.
목 이음은 I04 막 조각으로 국소 덮기 가능. 조각이 없는 외곽은 I06으로 마감.
벽 회전은 +Y 부착 법선을 해당 벽 법선으로 회전; 평면 XY/바닥XZ를 혼동하지 않음.
감염도0: 없음. 1: 이음 주변 줄기/막. 2: 벽과 배관 주변 분기/포낭 추가. 3: 주변부 밀도 증가.
전투 바닥 중앙과 문 3.5m 통과 구멍은 비움. 감염으로 충돌 실루엣이 바뀌면 별도 레벨디자인 승인 필요.

9. 통합 텍스처 사양(제작 기준, 실제 텍스처 파일 아님)
팔레트 앵커: 바닥 #56438A / 암부 #423665 / 색 변화 #6E4382 / 코랄 #CE5F54 / 발광 #AC41A6 / 민트 #5C857C.
이미지의 조명색을 그대로 알베도에 굽지 말 것. 민트는 작은 상태등뿐이며 플레이어 스킬 표시와 경쟁 금지.
공통 밀도512px/m. 2m 바닥 1024px 범위. 소품은 동일 밀도, 클로즈업 필요 시 별도 승인.
BASE: 2048x2048 반복 보라 금속, .25m 샘플=128px. 4m 주기. 90도 회전에도 방향성 줄무늬/강한 그림자 없음.
TRIM: 2048x2048, 폭 방향 실제4m: 코랄 .25m(128px), 어두운 배관 .5m(256px), 베벨 .25m(128px), 벽면1m(512px), 나머지2m는 보조 중성면. 길이 방향4m 반복.
PROP: 2048x2048 공용 아틀라스, 16px 경계 확장(최종 mip 검증 필요). 공유 볼트/손잡이/매립 패널 색은 같은 스와치.
ORGANIC: 별도2048x2048. 줄기는 길이 방향1m 주기, 목 둘레 단면 모두 같은 UV 방향. 막 알파 가장자리 컬러 확장16px.
Emission는 A10/A11 마스크만, 알베도에 강한 글로우 굽기 금지. Roughness 기본 .75~.9, 금속감은 회화적 색면 우선.
AO는 틈에만 약하게, 넓은 바닥 어둠을 AO로 굽지 않음. 씬 전체 방향 그림자는 텍스처에 금지.
건축 베벨 폭20~40mm, 타일 맞닿는 경계8mm, 소품10~20mm. 도면의 과장 하이라이트를 외형 두께로 해석하지 않음.
안전선은 D 계열 단일 UV 규격, 직선 폭 .25m, 코너 r=.5m. 원화의 끊긴 표시 리듬은 별도 알파 마스크 변형으로 조절.
색 변화 A/B/C는 같은 명도 범위를 유지하되 눈에 띄는 큰 얼룩/오염은 기본 타일이 아닌 별도 레이어.

10. 검증 결과 읽기
각42개 시트: FRONT/RIGHT/TOP 외관과 승인 팔레트를 검토. 기계적 실측 투영이 아니며 베벨/끝단/회화적 비율은 도면 간 미세 차이가 있다.
assembly.svg는 수치 기반 조립 보조도. PNG보다 소켓 좌표/반경/문 개구부 치수에 우선한다.
kit_contracts.json은 재생성 가능한 연결 규격, build_kit.mjs는 바닥·문·소켓·텍스처 밀도 수치 검증과 도감 생성기.
8x8m 예시 바닥의 타일 슬롯 합계 면적64m², 겹침0, 빈칸0를 수치 검사.
문 통과 폭/문짝 간극, 배관 끝 중심/법선, 난간 중복 기둥, 감염 끝목 지름을 규격 계산으로 검사.
이미지는 정확한 메시 조립 증거가 아니다. 실제 모델 제작 후 같은 소켓으로 GLB 조립/UV seam/게임 카메라 가독성 검증 필요.
이번 산출물은 모델링 착수용 도면과 조립 계약이며, 실제 모델 완성 또는 엔진 테스트 통과로 보고하지 않는다.

11. 모델러 전달 순서
F01/W01/W04/W05로 8x8m 회색 블록아웃 → 바닥 대체 슬롯/문 포켓 확인 → P/R 소켓 계열 → A 프랍 → I 감염 레이어 순서.
크기/접속은 kit_contracts.json 및 DESIGN.txt, 외관/색면/마모는 최신 PNG를 사용한다. 픽셀 길이로 역측정하지 않는다.
기본 레이어는 보라색의 조용한 큰 면, 코랄은 경계/손잡이, 마젠타는 작은 조명에 한정한다. 감염은 기존 구조를 가리는 주변부 덧칠이며 별도 월드 재질이 아니다.
완성 모델에는 동일 기준으로 GLB 피벗/소켓 검사, 타일 3x3 반복 이음, mip 경계, 전투 카메라에서 실루엣/명도 분리 테스트가 필요하다.
