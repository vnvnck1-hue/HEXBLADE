# 정비실 원화 3안

**최신 수정본은 [v2/](v2/README.md)**. 사용자가 최초 시안은 실사에 가깝다고 평가하여 핸드드로잉/블리자드·하스스톤·워크래프트·LoL 계열로 3장 모두 다시 그렸다. 아래는 최초 제작 당시 기록이다.

2026-10-12 · 사용자 요청: 밋밋한 배경을 원화로 디자인한 텍스처를 그대로 입히는 방향으로 개선하기 전, 적당한 컨셉 3가지 원화를 먼저 보여주기.

내장 image_gen으로 각각 새로 생성한 1536×1024 PNG다. 기존 정비실 실제 캡처와 보라·코랄 배경 v6을 살펴보고 공간/색의 특징만 텍스트로 전달했다. 생성에 입력 이미지나 외부 원본 그림을 사용하지 않았다.

1. [코랄 작업실](01_coral_workshop.png): 보라 바닥, 코랄 동선과 작업대, 크림 벽. 따뜻하고 사용 흔적이 있는 정비 공간.
2. [청록 냉각 설비실](02_teal_cooling_bay.png): 청록·남색·민트, 냉각 탱크와 배관, 차분하고 차가운 설비 공간.
3. [크림 청소·정비 도크](03_cream_service_dock.png): 크림 벽/서랍, 연보라 바닥, 세이지 설비와 코랄 하드웨어. 밝고 친근한 레트로 산업 공간.

추천은 3안. 기존 보라 바닥을 유지하면서 벽·가구를 명확하게 나누기 쉽고 청소업체 정비 공간의 인상이 강하다. 1안은 더 따뜻하고 사용감이 강하며, 2안은 냉각시설 구역의 대안으로 적합하다. 추천/신규 디테일은 제안이며 사용자가 선택한 확정 디자인은 아니다.

세 장은 전체 공간 디자인 원화이며 모델 UV에 바로 연결할 텍스처 아틀라스는 아니다. 새 난간·계단·도구·해치 등 원화의 입체 실루엣을 실제로 재현하려면 추가 모델링이 필요하다. 이후 선택한 원화를 바탕으로 기존 모델의 UV/면에 맞춰 표면 텍스처를 제작하고 실제 조명과 비교한다. 이번 요청은 원화 제작까지다.

실제 프롬프트는 [prompts.json](prompts.json), 생성 원본 경로·SHA256·복사 일치·PNG 디코딩·해상도·육안 검토 기록은 [validation.json](validation.json)에 있다. `.gdignore`로 Godot 임포트 제외. 기존 게임 코드·씬·재질·에셋 적용이나 커밋/푸시를 진행하지 않았다. 시작 시 존재한 다른 세션의 성능/등장 연출 변경과 미추적 파일은 보존했다.
