# 정비실 원화 v2 — 핸드드로잉 스타일 수정

2026-10-12. 사용자 피드백: 1차는 실사에 가까우므로 LoL·블리자드·하스스톤·워크래프트 계열의 핸드드로잉으로 다시 그리기.

기존 3컨셉을 각각 명시적인 편집 대상으로 내장 image_gen에 전달하여 재작화했다. 각 호출의 입력은 해당 기존 원화1장만이다. 외부 게임의 이미지를 입력하거나 캐릭터를 생성하지 않았다. 넓은 붓질/색면, 과장된 베벨, 두꺼운 형태, 보라/청록색 그림자, 단순화한 볼트/배관/마모로 수정했다. 브랜드 이름은 사용자가 지정한 시각적 방향을 프롬프트로 전달한 것이며, 해당 게임의 실제 에셋은 사용하지 않았다.

1. [코랄 작업실](01_coral_workshop.png) — 보라/코랄의 따뜻한 작업 공간.
2. [청록 냉각 설비실](02_teal_cooling_bay.png) — 청록/민트/노랑의 선명한 설비 공간.
3. [크림 청소·정비 도크](03_cream_service_dock.png) — 크림/연보라/세이지/코랄의 밝은 정비 공간.

세 이미지 모두 1536×1024. 원본 경로, 편집 대상, SHA256 복사 일치와 디코딩/육안검사는 `validation.json`, 실제 호출 프롬프트는 `prompts.json`에 보존했다. 최초 시안은 상위 폴더에 그대로 보존한다. 최신 검토 대상은 이 v2 폴더다.

전체 공간 원화이며, 실제 UV 텍스처 아틀라스가 아니다. **2026-10-12 사용자 선택: 3번 크림 청소·정비 도크.** 이후 제작의 스타일/색/공간 기준은 `03_cream_service_dock.png`다. 사용자 후속 질문은 적용 방법이며, 모델/텍스처 제작 착수는 이번 설명 작업에서 수행하지 않았다. [적용 순서](implementation.md). 코드·씬·모델·게임 재질 변경 없음. 테스트 실행/커밋/푸시 없음.
