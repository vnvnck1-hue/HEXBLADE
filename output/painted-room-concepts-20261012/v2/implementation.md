# 선택한 3안의 적용 순서

2026-10-12 사용자 선택: `03_cream_service_dock.png`. 크림 벽/가구, 연보라 바닥, 세이지 탱크/배관, 코랄 상판/하드웨어. 넓은 붓질과 단순한 색면·칠한 명암을 기준으로 삼는다.

## 현재 코드에서 확인한 조건

- `scenes/texture_diorama.tscn`은 기존 F01/W01/A01/A02와 탱크/배관 등 실제 게임 자산을 사용하는 별도 정비실이다.
- W01/A01 등의 기존 제작은 모델을 UV 아틀라스로 펼친 뒤 코드로 만든 붓질/음영을 구워서 GLB로 내보낸다.
- 본편 기본 바닥은 PNG를 직접 샘플링하지만 벽은 기존 UV 음영과 새 붓질 이미지/색을 혼합한다. 선택 원화의 벽을 충실하게 보여주려면 시험용 재질에서 새 PNG를 직접 사용해야 한다.
- 디오라마의 현재 시험 텍스처는 바닥/벽/프랍/설비 카테고리별 공통1장이다. 작업대와 수납장처럼 서로 다른 UV/그림을 쓸 파츠에는 모델별 재질 연결이 필요하다.

## 제작 순서

1. 선택 원화와 같은 게임 방향에서 기존 정비실 모델을 비교한다. 표면으로 표현할 홈/칠/작은 마모와 입체 실루엣으로 표현할 베벨/둥근 탱크/파이프를 구분한다.
2. 바닥·벽·작업대·수납장부터 형태를 맞춘다. 원화의 두툼한 면을 살리는 데 필요한 시각적 모델 조정은 별도 시험 자산에 수행한다. 난간/계단/소품 등 기존 모델에 없는 추가 형상은 텍스처만으로 재현되지 않으며 별도 모델 작업 범위로 기록한다.
3. 원화 기준으로 각 모델의 보이는 면에 대응하는 표면 그림을 제작한다. 원화는 사선 원근·가림·장면 그림자를 포함하므로 그대로 잘라 붙이면 면이 늘어지거나 그림자가 중복될 수 있다. 기준 시점 투영/왜곡 보정으로 살릴 부분과 새로 그릴 면을 정한다. 숨은 측면/뒷면은 같은 스타일로 보완한다.
4. 그림을 모델별 UV에 정렬하고 필요한 패딩/이음 보정만 거친 최종 PNG를 연결한다. 표면 붓질·색·명암은 PNG가 결정한다. 런타임 절차적 붓 혼합/색 재해석을 추가하지 않는다. 재료별 텍스처는 게임 카메라에서 충분히 읽히는 해상도로 정한다.
5. 별도 정비실에서 실제 조명과 비교한다. 원화의 칠한 음영에 실제 그림자가 겹치는 정도를 조정하고, 플레이어/적/공격 표시를 함께 놓아 가독성을 확인한다. 바닥 반복 이음, 정면/옆면과 다른 카메라 각도에서 표면 정렬도 확인한다.
6. 사용자에게 원화·기존 정비실·새 정비실의 같은 방향 비교를 보여준다. 원화와 비슷하다는 판단은 실제 Godot 렌더로 확인한다. 본편 확대는 시험 결과를 확인한 뒤 진행한다.

먼저 보여줄 제작 결과는 바닥 PNG·W01 벽 아틀라스와 해당 모델에 연결한 실제 정비실 비교다. 전체 원화에서 마음에 든 스타일이 실제 표면에서도 유지되는지 가장 빠르게 확인할 수 있다. 후속은 작업대/수납장→탱크/배관→벽 장치/주변 소품이다.

현재는 사용자 선택과 적용 방안만 기록했다. 새 텍스처 제작/모델/게임 적용은 아직 수행하지 않았다.
