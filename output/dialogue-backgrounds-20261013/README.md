# 포트레이트 대화 배경 시안 2종

2026-10-13. 사용자 요청: 첨부 화면처럼 포트레이트 뒤에 사용할 배경 두 장, 인물과 톤 분리를 확실히 해 시인성을 유지한다.

후속 상태: 같은 날 사용자의 실제 적용 요청으로 두 배경을 게임에 연결했다. 적용/캡처/검증은 `output/dialogue-backgrounds-applied-20261013/README.md` 참고. 아래는 최초 시안 제작 당시의 기록이다.

- `01_blue_service_hangar.png`: 먹청색 정비 격납고. 밝은 금발·피부·흰 의상과 대비하도록 낮은 채도의 차가운 색면으로 구성.
- `02_dusty_brick_briefing_room.png`: 적갈색 브리핑룸. 보라·민트 계열 인물과 색을 분리하는 따뜻하고 낮은 채도의 배경.

중앙 단독 인물과 좌우 25%/75% 두 인물 배치를 고려했다. 인물 자리에는 큰 낮은 대비의 면을 두고 주요 설비·조명은 가장자리로 옮겼다. 배경만 포함하며 인물·글자·UI·레터박스는 없다. 원본 생성 파일을 수정 없이 복사했다. 규격·파일 SHA256·인물 영역 표본 밝기 측정은 `validation.json`에 있다.

내장 `image_gen`으로 각 시안을 별도 생성했다. 첨부 레퍼런스는 환경 구도와 명암 분리만 참고했다. 현재 대화 화면은 관찰해 배치를 확인했으며 생성 입력에는 넣지 않았다. 캐릭터는 생성하지 않았다. 실제 전체 프롬프트는 `prompts.json`에 보관했다.

사용자 검토용 시안이며 게임에는 연결하지 않았다. 실제 포트레이트 합성/플레이 검증과 Godot 회귀는 수행하지 않았다. `.gdignore`로 시안 폴더를 임포트에서 제외했다. 적용 시 선택 PNG를 리소스 폴더로 복사하고 현행 대화 레이아웃에서 최종 시인성을 확인해야 한다.
