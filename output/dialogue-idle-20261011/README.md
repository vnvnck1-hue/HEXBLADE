# 대화 포트레이트 아이들링

2026-10-11 · 남주를 제외한 전체 대화 인물7명/원화18장에 적용.

- 사장, 정비사, 첫 청소 파트너, 미라, 세나, 노아, 에이린.
- 기존 대화 실행기 또는 로비의 대화 항목. F1~F5 대본에서 자동으로 작동한다.
- 각자 다른 속도/위상/진폭으로 숨쉬기, 허리축 미세 기울기, 머리끝과 옷/리본의 지연 움직임. 듣는 사람도 계속 움직인다.
- M 움직임 줄이기를 켜면0.2초 동안 부드럽게 정지하고 끄면 이어진다. 남주 대사창 그림에는 모션을 넣지 않았다.

## 구현

`scripts/dialogue/dialogue_idle_motion.gd`가 합체 컷인의 `scripts/drone/diagonal_cutin.gdshader`를 그대로 사용한다. 공용 셰이더에 `clip_enabled` 하나를 추가해 대화에서는0, 기존 합체 컷인에서는 기본1로 사선 클립을 제어한다. 합체의 UV 머리/옷가지/리본 변형은 동일하며 대화용의 작은 주기 운동과 감쇠 스프링으로 구동한다. 가슴 모핑은0이다.

`DialoguePortrait`의 현재/이전 표정/그림자가 각각 재질을 갖고 표정마다 자기 원화의 마스크를 사용한다. 기존 자리, 반전, 등장/퇴장, 표정 교차 전환과 화자 강조는 유지한다. 원화 파일은 수정하지 않았다. 색·타원 영역·얼굴 보호 영역으로 생성한 RGB 마스크를 유한 원화18장에 캐시하며, 프레임마다 이미지 처리는 하지 않는다. 첫 원화 마스크 로드 때만 CPU 작업이 있다. 마스크 경계는 검정 외곽선/투명 실루엣과 같이 움직이도록 부드럽게 확장했다.

## 재현/검증

고정 실행기 `powershell -File tools/godot.ps1 wait --fixed-fps 60 -s res://_capture/dialogue_idle_show.gd`로 실제 화면을 캡처하고 렌더 픽셀 검사를 한다. `pack_preview.py`를 Pillow가 있는 Python으로 실행하면 GIF10장과 `preview_validation.json`을 만든다.

`tests/dialogue_idle_check.gd`는7명/모든 표정의 마스크와 연속 움직임, 듣는 상태, 표정 교차 전환, 반전/그림자, M키 실제 입력, 남주 제외, 큰 dt 안정성, 재질3개/마스크18장으로 고정되는 캐시를 검사한다. `render_checks.json`은 몸을 고정해도7명 모두 실제 셰이더 픽셀이 변하고, 움직임 줄이기 때 픽셀 변화가0임을 확인한다. `render.log`·`regression.log`·`bot_*.log`와 최종 `validation.json`에 결과를 보관한다.

다른 작업자의 변경과 기존 원화를 보존했다. 커밋·푸시는 하지 않았다.

최종 검증: 전체55종 PASS·ERROR0·SCRIPT ERROR0, 모션 전용96항목 PASS, 실제 렌더10항목 PASS. F1~F5 대본bot5종 모두 끝까지 정상 진행·ERROR0. 기존 합체 컷인 실제 렌더/보이스/스프링/사선 클립 정상(최대 clip_err0, ERROR0), 화면은 cutin_verified.png에 보관했다. 검증된 대화 화면을 사용자 확인용으로 실행했다.
