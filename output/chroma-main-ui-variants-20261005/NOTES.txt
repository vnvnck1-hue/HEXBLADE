HEXBLADE 인게임 메인 UI 컨셉 4안 — 2026-10-05

사용자 요청: 실제 전투 화면을 참고해 채택 그래픽 무드로 메인 UI를 여러 방향으로 디벨롭.
제작: 내장 imagegen. 게임 코드·씬·리소스 연결은 변경하지 않은 정지 컨셉 원화.
편집 기준: 직전 채택 스타일의 03_combat_cleanup.png.
기능 참고: 고정 Godot 4.7.2 실제 본편 자동 플레이 캡처 03_combat_action.png.
두 입력은 source_styled.png / source_actual.png로 원본 그대로 보존.

공통 무드: 짙은 남보라 면, 아이보리 절단 테두리, 민트 상태색, 라임 망점, 주황 BOOST, 코랄 위험 표시.
배경과 전투 구도를 공통 기준으로 사용했지만 생성 과정에서 국소 재표현이 있으므로 픽셀 동일 결과는 아님.

01_corner_panels.png — 익숙한 네 모서리 배치, 초상 상태 카드 + 독립 원형 스킬.
  현재 UI에 적용하기 쉬운 방향. 상·하단 정보를 번갈아 확인해야 하는 특성.
02_equipment_cards.png — 상단 메카/TRIAD 공유 띠, 하단 우측 2×3 사선 장비 카드.
  장비 그림·탄약·충전 정보를 크게 읽히게 함. 카드의 점유 면적과 테두리 밀도는 높음.
03_bottom_console.png — 체력·지원·장비를 하단 하나의 도크로 통합.
  상단 시야와 상태 확인의 일관성. 하단 접근 적/바닥 예고와의 겹침은 구현 시 검토 필요.
04_minimal_hex.png — 육각 초상, 얇은 상태바, 육각 스킬 묶음.
  패널 면적을 줄여 전장을 드러냄. 대비가 밝은 바닥에서도 유지되도록 실게임에서는 작은 배경 면 필요.

추천: 01 배치 + 04의 간결한 선과 육각 디테일. 장비 강조가 우선이면 02.

비교를 위한 예시 값(실제 입력 캡처의 상태를 그대로 읽은 값은 아님):
HP 4/5, BOOST 2/3, SUPPORT 65/100, ROOM 0/9, ENEMIES 2,
SCORE 100, COMBO 3, RMB 탄약 17/30, L+R 에너지 1/3, R 미사일 0.
Q DOCK, X SHIELD, Z CLEAN, LMB 검, RMB 총/T 재장전, SPACE 회피 부츠,
SHIFT 쌍발 부스터, L+R 에너지, R 미사일, E 내려찍기.

확인: 최종 4장 전체 육안 확인, 핵심 상태 글자와 키 정보 확인.
04 에너지 옆 불필요한 숫자 10은 내장 imagegen으로 한 번 교정해 제거.
제한: 생성된 게이지 길이/보조 눈금은 값과 정확하게 대응하지 않는 부분이 있음.
미니맵은 공간 배치 제안이며 원본 게임의 좌표/점 개수와 정밀 일치하지 않음.
실제 적용 시 텍스트·숫자·게이지·맵을 코드로 재구성해야 함.
검증 JSON은 PNG 치수·복사 SHA256 확인용이며 게임 동작/배치 테스트가 아님.
본편 적용·엔진 실행·커밋·푸시 없음. 다른 작업과 미추적 파일 보존.
