# 플로팅 전투 UI 시안 · 2026-10-11

사용자 첨부 전투 화면을 바탕으로 크림색 글자·민트 체력·주황 부스트·라임 포인트를 유지하고 공용 빽판을 제거한 세 가지 디자인 시안. 내장 image_gen으로 제작했다.

| 파일 | 방향 | 특징 |
|---|---|---|
| [01_comic_cutout.png](01_comic_cutout.png) | 코믹 컷아웃 | 굵은 외곽선과 독립 아이콘으로 원안의 코믹 느낌을 가장 가깝게 유지. |
| [02_open_line.png](02_open_line.png) | 오픈 라인 | 작은 초상과 얇은 선, 정렬된 스킬로 화면 여백을 확보. |
| [03_diagonal_arcade.png](03_diagonal_arcade.png) | 사선 아케이드 | 큰 숫자와 브러시 글자, 열린 부채꼴 스킬 배치로 속도감을 강조. |

추천: 1안의 코믹 컷아웃과 2안의 간결한 배치 조합. 3안은 강한 아케이드 연출에 적합하다.

공통: 플레이어·드론 판, 상단 정보 판, 미니맵 판, 스킬 원형 배경, 키캡 판 제거. 독립 아이콘·글자별 외곽선/그림자·게이지 선은 유지. 전투 배경이 요소 사이로 보이도록 구성했다. B의 체력 5칸, C의 Q/X/Z 키캡 제거 및 장식/숫자 규모 보정을 추가했다.

세 장 모두 육안으로 주요 표기, 5칸 체력, 빽판 제거, 스타일 차별화 확인. validation.json은 PNG 디코딩·크기·SHA256·원본 복사 일치 결과. prompts.json에는 실제 초기/보정 프롬프트, sources.json에는 원본 생성 경로를 보관한다. reference.png는 사용자 원본 첨부의 사본이다.

이 결과는 전투 배경과 HUD가 합쳐진 디자인 검토용 PNG이며 분리 UI 에셋은 아니다. 이미지 생성 과정에서 배경과 작은 디테일에 미세한 차이가 있어 픽셀 동일성은 보장하지 않는다. 게임 코드 및 실제 UI 적용은 이번 작업 범위에 포함하지 않았다. .gdignore로 Godot 임포트를 제외했다.
