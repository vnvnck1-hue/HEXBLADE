모델 분석/적용
- 방 바닥은 Terrain.floor_cells가 만든 방 단위 메시다. F01 모듈 GLB를 방마다 한 장씩 늘리는 구조가 아니다.
- F01의 기본 구조는 2×2m/두께0.2m, W01은 2×3×0.25m. 낮은 벽·엄폐·기둥은 기존 MultiMesh를 유지했다.
- 실제 바닥의 2m 줄눈은 방 offset을 유지하고, 붓질은 기존 4m 반복 좌표로 샘플링한다.
- 벽 붓질은 면 방향에 따라 월드 투영한다. 기존 아틀라스 UV의 패널/볼트/프레임/베벨 음영을 분리해 유지한다.
- 바닥 파괴 조각은 실제 바닥 ShaderMaterial 복제로 같은 붓질을 이어받는다.
- BrawlLook 기본 mo.co 재질에서 새 붓질을 직접 사용한다. 기존 채도/밝기 압축이 붓결을 지우던 경로는 새 분기에서 교체했다.
- 기존 메시 파일/UV/판정은 변경하지 않았다. 캐릭터와 외부 서비스 설비 재질은 대상에서 제외했다.
- --bgpaint=old는 같은 모델 배치에서 이전 재질을 비교하는 옵션이다. 기존 --bg=old(배경 모델 제거)와 별개다.
- 정적 평균 캐시는 두 텍스처 경로만 사용한다. 평균을 임포트된 Texture2D.get_image()에서 읽어 PCK 내보내기에도 원본 PNG 파일 경로가 필요하지 않다.

반복 처리
원본 생성 텍스처에 정확한 픽셀 타일링을 가정하지 않는다. hp_sample은 겹치는 반크기 샘플 4개를 smoothstep으로 연결한다.
fract 경계에서도 올바른 미프맵이 선택되도록 textureGrad를 사용한다.
실제 GPU 반복 렌더 1024×1024/4×4의 인접 경계 픽셀 RGB 평균 차이: 0.00139018562105 (0~1 범위).
바닥의 의도적인 줄눈/방 경계와 붓질 반복 경계를 구분해 검증했다.
