# 대화 캐릭터 정리 · 눈 깜빡임

현재 게임 출연진: 사장, 정비사, 청소 파트너. 남주 대화창 포트레이트는 사용자 확정으로 유지.

최종 에셋: `assets/portraits/opening_cast/*_closed.png` 6장. 1254×1254 RGBA, 원본과 같은 위치/실루엣/알파. 눈 부분만 바뀐다. 원본의 헤어·입·몸·소품은 보존했다. 내장 imagegen 6회 편집을 사용하고 생성된 눈 영역만 원본에 합성했다. 최초 원본 참고4장만 그림체 기준으로 사용했다. `prompts.json`에 편집 대상/참고/실제 프롬프트/생성 경로, `masters/`에 생성 결과 복사본, `pack_blinks.cjs`에 눈 영역 제한 합성, `asset_validation.json`에 좌표/픽셀 수/해시.

이미지/움직임 확인:
- `all_open.png` / `all_closed.png`: 게임에서 렌더한 포즈6개.
- `scene_open.png` / `scene_closed.png`: 실제 청소 파트너 소개 씬.
- `blink_preview.gif`: 실제 Godot 포트레이트6개가 각기 깜빡이는7초 미리보기.
- `final_eye_comparison.png`: 눈 부분 확대 비교, 왼쪽 원본/오른쪽 감은 눈.

동작: 포트레이트마다 전용 RNG로2.8~6.2초 간격,0.12초 동안 닫는다. 듣는 동안에도 작동. 표정 교차 전환과 그림자에도 같은 눈 상태를 반영한다. 원본6장 마스크를 재사용하며 눈 프레임이 마스크 캐시를 늘리지 않는다. M 움직임 줄이기에서는 열린 눈으로 고정하고 기존 아이들링도 멎는다. 남주는 기존 정지 포트레이트 유지.

2026-10-11 범위 정정: 구 여성 캐릭터의 **대화 등록과 대본만** 제거했다. 합체 연출에 대한 교체는 사용자의 정정 요청으로 원복했다. 기존 민트 메이드 5포즈·보라 정비사·초록 메이드·조종석 원화 및 마스크/소품을 복구했으며, 대화의 새 세 여성/남주와 눈 깜빡임은 유지한다. 후속 기록: `output/cutin-restored-20261011/`. 아래 기존 검증 자료는 원복 이전 상태의 역사 기록이다.

실행: 로비 → 캐릭터 대화 / 청소 파트너 소개. 대화에서 F1~F5 대본 선택. 코드 연결은 기존 테스트 씬 범위이며 실제 본편 출격/정산 연결은 이번 작업 대상에 포함하지 않았다.
