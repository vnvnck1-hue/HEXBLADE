2026-10-04 · 차분한 HUD 실제 게임 적용

사용자 지시: 선택 시안의 나머지 UI를 실제 게임에 적용하고 필요한 리소스를 제작한다.
보존 지시: 우측 하단 원형 스킬·수치·키 배지와 TRIAD 지원 패널도 현재 그대로 유지한다.

실제 적용
- scripts/presentation/calm_hud.gd: 차분한 남색 카드, 크림색 글자, 녹색 장갑 5칸/실제 수치, 주황 부스터, 에너지 3칸.
- 상단 중앙 실제 방 진행·현재 방 적 수·웨이브·락온 수/남은 시간.
- 우상단 실제 탐색 지도·플레이어/적/방 표시·점수·콤보와 남은 시간.
- 일반 적 HP와 피격 잔상을 읽는 코랄 화면 공간 바. 기존 일반 3D바 중복 숨김, 보스/소품 자체 표시는 유지.
- 적 바는 기존 스킬/TRIAD 패널 영역 위에 그리지 않는다.
- 보스전은 상단 카드가 전용 보스 HP바 아래로 내려간다. 지도 없는 씬은 방 수·빈 지도 프레임을 생략하고 점수만 표시한다.
- STRIKER 기본 적용, H/Shift+H의 다른 기존 프리셋 유지. --hud-art=classic 비교용.

생성 리소스
- Built-in imagegen, 참고 reference.png, 실제 프롬프트 portrait-prompt.txt.
- assets/ui/calm_hud/mecha_bust.png: 1254x1254 투명 메카 초상.
- Godot .import와 함께 보존; 임포트 최대512px, 밉맵, UI 선형 샘플링.
- 패널/게이지/문구/지도/HP바는 Godot의 실제 그리기와 게임 값을 사용한다.
