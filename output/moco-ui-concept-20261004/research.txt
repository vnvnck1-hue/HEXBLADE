이번 결과

사용자 스크린샷을 직접 편집 대상으로 넣고, 실제 mo.co 전투 HUD와 공식 메뉴 이미지를 스타일 참고로 넣었다.
기존 UI 스타일은 교체하고 원본 게임 장면의 구도와 주요 대상 배치는 유지했다.
별도 구성요소 시트, 메뉴 원화, 두 번째 디자인 안, 실제 UI 구현은 만들지 않았다.
ui_concept_draft.png는 같은 디자인의 교정 전 기록이며 추가 선택안이 아니다.

세부 분석

1. 메뉴와 전투 HUD는 밀도가 다르다
관찰: OUTFITS 선택 화면은 짙은 보라색 바탕과 꽉 찬 카드 타일로 항목을 정리한다.
관찰: 전투 화면은 큰 카드보다 투명한 원과 독립적인 아이콘을 사용한다. 장면이 버튼 사이로 보인다.
적용: 전투 버튼 전체를 보라색 박스 안에 넣지 않았다. 임무와 동료 정보만 작은 보라 카드로 묶었다.

2. 색상은 역할을 구분한다
관찰: 보라색은 메뉴와 포털/상황 배너, 민트는 선택·강조, 초록은 체력, 청록은 이동/장비 아이콘에 쓰인다.
관찰: 흰 글자와 흰 아이콘 테두리가 다양한 배경 위에서 전경 정보를 구분한다.
적용: 임무/동료 카드는 보라, 활성 청소는 민트, 체력은 초록으로 분리했다. 공격/이동 아이콘의 사물 색은 다양하게 유지했다.
이 색상 역할 분리는 참고 화면에서의 관찰이며 mo.co의 공식 디자인 토큰 명세를 확보한 것은 아니다.

3. 버튼은 사물 일러스트가 먼저 읽힌다
관찰: 치유 구체, 주사기, 장비, 신발이 큰 색면과 간단한 음영, 두꺼운 흰 윤곽으로 그려진다.
관찰: 버튼 원은 옅고 아이콘이 상대적으로 강하다. 얇은 네온 선만으로 장비를 표현하지 않는다.
적용: 검·총·부츠·부스터·로켓·레이저 에너지 셀을 흰 테두리의 사물 아이콘으로 새로 그렸다.
모코의 치유 도구와 캐릭터는 가져오지 않았다. 우리 게임에 없는 회복 기능이나 가상 조이스틱을 추가하지 않았다.

4. 크기와 묶음으로 우선순위를 만든다
관찰: 주무기 버튼이 크고, 이동/보조 장비가 작은 원으로 주변에 놓인다. 모든 버튼이 같은 크기로 일렬 나열되지 않는다.
적용: 검을 가장 크게, 사격을 다음으로 크게 두고 회피/부스터/레이저/미사일을 주변에 배치했다.
PC용 키캡은 원 바깥 아래에 두어 아이콘을 가리지 않게 했다. RMB는 사격, T는 재장전으로 구분했다.

5. 글자는 읽을 내용만 굵게 남긴다
관찰: 실플레이 임무 본문과 숫자는 굵고 대체로 수직인 산세리프다. 이벤트 리본은 굵은 기울임 제목을 쓰기도 한다.
관찰: 캐릭터 이름/수치에는 어두운 외곽선 또는 그림자가 있어 VFX 위에서도 읽힌다.
적용: ROOMS, ENEMIES, SCORE, 피해와 자원 수치는 짧은 굵은 글자로 정리했다. 기존 작은 안내 문장 줄을 늘리지 않았다.
정확한 모코 폰트 가족명은 확인하지 못했다. 비슷한 굵기·너비·자간의 원화 표현이며 특정 폰트라고 주장하지 않는다.

6. 체력은 월드 대상과 연결된다
관찰: 실제 전투 참고의 체력과 이름은 캐릭터 머리 위에 붙고, 보스/포털 상태는 화면 모서리에 별도로 정리된다.
적용: 상단 왼쪽의 사선 장갑칸을 없애고 메카 머리 위에 4/5 체력을 붙였다. 회피/자원은 작은 보조 표식으로 분리했다.
초안에서 남았던 기존 에너지 3점은 제거해 새 머리 위 에너지 표시와 중복되지 않게 했다.

7. 프레임과 장식은 정보에 종속된다
관찰: 미니맵은 얇은 경로 윤곽과 점으로 구성되고, 임무는 짧은 리본/왼쪽 강조선으로 묶인다.
적용: 미니맵의 장식 프레임을 줄이고 얇은 보라 경로와 민트 플레이어/분홍 적 표시로 교체했다.
바닥과 벽의 실제 사선/핑크 구조물은 UI 장식이 아니므로 원본 장면으로 유지했다.

8. 상태는 장식보다 의미를 우선한다
관찰: 실제 전투 화면의 사용 대기 장비는 아이콘이 어두워지고 흰 잔여시간과 테두리 변화로 구분된다.
적용: 원본의 지원 0/100을 유지해 Q DOCK과 X SHIELD를 회색 비활성으로 표시했다. Z CLEAN만 민트 활성으로 남겼다.
지원 게이지를 가짜로 채우거나 쿨다운/READY/새 치명타 상태를 만들지 않았다.
이 원화의 Q 표기는 현재 프로젝트의 합체 입력을 반영한 것이다. 원본 스크린샷의 G를 최신 입력으로 간주하지 않았다.

최종 원화 읽는 법
- 좌상단: 방 0/9, 적 6의 임무 정보. 기존 기체 상태 패널을 이 자리에서 제거했다.
- 메카 위: 체력 4/5, 주황 보조 막대, 에너지 1/3. 원화의 위치와 크기는 제안이며 런타임 배치가 아니다.
- 우상단: 간단한 미니맵과 점수 0.
- 좌하단: 동행 TRIAD와 지원 0/100, Q 합체/X 보호막 비활성, Z 청소 활성.
- 우하단: 장비 사물 아이콘과 LMB/RMB/T/SPACE/SHIFT/R/L+R 키 표시. 미사일 4는 잔량이며 최대치 4라는 뜻이 아니다.
숫자는 원본 장면 상태를 유지한 컨셉이며 실제 조작/메뉴 기능은 구현하지 않았다.

주요 구도와 대상 배치는 유지했으나 생성 리사이즈·국소 재표현이 있어 배경 픽셀 동일 합성을 보장하지 않는다.
정지 원화 한 장의 스타일과 배치를 확인한 것이다. 실제 화면 크기 대응, 가림, 클릭, 동작, 글자 렌더 검증 결과는 아니다.
prompt.txt와 correction_prompt.txt는 실제 사용 프롬프트다. references.json은 직접 입력과 출처 기록이다.
게임 소스/엔진/기존 원화는 변경하지 않았고 커밋·푸시는 하지 않았다.
