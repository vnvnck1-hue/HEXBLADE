Lancaster 팔 형태·비율 재분석 — 2026-10-06

근거: 사용자가 첨부한 원화(reference.png). 이전 3면도는 팔 길이가 짧다는 사용자 피드백으로 수정 대상.
원화는 원근이 있고 팔꿈치가 굽혀진 자세다. 아래 치수는 실제 설정 치수나 정확한 3D 역산값이 아니라, 원화에서 읽히는 덩어리·관절 연쇄를 펼치기 위한 모델링 비율 제안이다.

1. 오른팔 / 정면 화면 왼쪽 / 집게·스파이크
- 둥근 어깨 관절을 덮는 회색 어깨 장갑과 주황 테두리.
- 어깨 아래로 떨어지는 두꺼운 상완과 검정 관절부가 있으며, 이를 생략하면 팔이 어깨에 붙은 짧은 집게로 변한다.
- 전완은 큰 각진 암회색 장갑 덩어리. 손목 끝에는 분절된 기계식 집게, 전완 아래에는 원뿔형 은색 스파이크.
- 원화의 집게 끝/스파이크는 허리보다 아래, 허벅지 영역까지 내려온다. 어깨부터 그 지점까지 상완과 전완 두 구간이 필요하다.
- 형태감: 넓고 무거운 상자/쐐기 장갑 → 짧은 손목 연결 → 상대적으로 작은 기계 집게. 스파이크는 전완 부속이며 팔 전체를 대신하지 않는다.

2. 왼팔 / 정면 화면 오른쪽 / 기관포
- 어깨 장갑 아래의 상완, 큰 원통 하우징, 굽힌 팔꿈치 주변 연결부, 각진 전완, 좁아지는 총기 연결부와 돌출 총열의 연쇄.
- 큰 원통 드럼의 암회색 외피·주황 띠가 지배적 형태. 원화에서는 드럼이 각진 전완/총기 연결부보다 위쪽·안쪽에 있다. 상완~팔꿈치 부근을 덮는 별도 하우징으로 해석하되, 숨은 실제 관절축과 드럼 용도(장갑/탄통 등)는 원화만으로 확정할 수 없다.
- 원화에서는 총구가 허벅지 아래쪽 높이까지 온다. 총열만 늘려서는 부족하며 상완·전완도 길이와 부피를 확보해야 한다.
- 형태감: 장갑 상완·관절 위 큰 원통 하우징 → 원형 팔꿈치 → 각진 전완/연결부 → 가늘어진 다연장 총열. 집게 팔과 비슷한 관절 길이, 무장 끝까지는 더 긴 실루엣.

3. 이전 시안의 문제
- 어깨와 집게/드럼 사이가 거의 한 장갑 덩어리로 압축되어 상완·팔꿈치·전완 구분이 부족했다.
- 이전 정면의 H(발바닥~기둥 끝) 약600px 대비, 어깨~집게 끝 약150px/어깨~총구 약200px 수준의 화면상 길이. 대략 .25H/.33H로 짧았다(육안 좌표 추정).
- 수정은 몸통을 줄이거나 총열만 늘리지 않고, 두 팔의 상완과 전완을 각각 확보한다.

4. 수정 정면의 작업 비율 (H=발바닥~상단 기둥 끝)
- 어깨 관절 중심 간 약 .60H.
- 어깨~팔꿈치 약 .26H.
- 오른팔 팔꿈치~집게 끝 약 .30H, 어깨~집게 끝 합계 .56H.
- 왼팔 팔꿈치~전완/총기 하우징 끝 약 .23H + 돌출 총열 약 .13H, 어깨~총구 합계 .62H.
- T 포즈 전체 양끝 폭 약1.78H. 생성 후 실제 출력의 비율/관절 구분을 다시 육안 검토한다.
- 굵은 장갑·큰 몸통·짧은 다리를 유지. 사람처럼 가느다란 팔이나 길쭉한 다리로 바꾸지 않는다.

5. 3면도의 기준
- 정면·후면 T 포즈: 어깨·팔꿈치·손목 축이 수평. 정면 왼쪽 집게/오른쪽 기관포, 후면 반대.
- 우측면 T 포즈: 오른팔을 끝에서 보는 단축 투영이라 팔 길이가 화면 폭에 드러나지 않는다. 팔 길이는 정면·후면으로 판단하고 측면은 몸통/장갑 깊이·관절 위치를 판단한다.
- 원화에 없는 후면은 기존 형태를 이어 만든 제안. 정확한 치수는 모델링 단계에서 결정한다.

게임 적용·모델 생성은 이번 요청 범위에 포함되지 않는다. 이전 이미지와 다른 작업자의 파일은 보존.

6. 최종 출력 확인 (1774×887 정면, 표시된 관절 중심의 육안 좌표 추정)
- H≈771px(기둥 상단 y53~발바닥 y824).
- 오른팔: 어깨 x616 → 팔꿈치 x421 → 집게 끝 x195. 상완≈195px(.25H), 팔꿈치~집게≈226px(.29H), 합계≈421px(.55H).
- 왼팔: 어깨 x1158 → 팔꿈치 x1346 → 총구 x1598. 상완≈188px(.24H), 팔꿈치~총구≈252px(.33H), 합계≈440px(.57H).
- 정면 전체 양끝 폭≈1403px=1.82H. 이전 정면의 짧은 어깨~끝 길이보다 두 팔 모두 길이가 확보되었고, 팔꿈치가 드러나 상완/전완이 구분된다.
- 작업 프롬프트의 비율은 목표치이며, 위 값은 실제 최종 정면의 근사 확인값. 두 값을 혼동하지 않는다.
- 후면: 집게 화면 오른쪽/기관포 화면 왼쪽, 같은 수평 T 포즈. 마지막 팔 폭 보정 후 양끝 폭≈1.90H로 정면 대비 약5% 차이가 남는다. 독립 생성 그림 사이 세부 패널·관절 중심도 완전 동일하지 않다. 정확한 모델 비율은 정면을 우선하고, 후면의 폭은 정면 기준으로 맞춰 사용한다.
- 우측면: 몸통 정면이 화면 왼쪽, 집게 팔은 카메라 방향으로 뻗어 단축 투영. 옆모습에서 짧게 보이는 것은 실제 팔 길이를 줄인 것이 아님. 상단/발바닥 높이는 정면·후면과 거의 같은 위치.
- 뒷등판·뒤 종아리 피스톤·뒤꿈치는 원화에 가려진 부분을 보완한 제안.
