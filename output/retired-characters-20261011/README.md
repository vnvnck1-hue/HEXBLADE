# 대화 캐릭터 역사 자료

2026-10-11 사용자 정정: 캐릭터 정리는 대화 씬만 해당한다. 합체 연출에 사용하는 기존 캐릭터는 삭제 대상이 아니다.

`cleaning_owner`는 구 대화 사장 원화 보관본이다. `purple_worker`, `green_maid`, `mint_maid`, 조종석 PNG와 미리보기 도구는 원래 리소스 경로로 복구했고, 이 폴더의 복사본은 원본 보존을 위해 남겼다. 이 폴더 전체는 `.gdignore`로 임포트 제외다. 현재 대화 캐스트는 owner/worker/partner/me이며 합체 캐릭터 설정과 독립적이다.
