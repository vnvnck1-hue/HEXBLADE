UI 스타일 추가 3안
작성: 2026-10-04

01_pop_sticker.png — 팝 스티커: 아이보리 카드, 두꺼운 보라 윤곽, 약간 기울어진 티켓, 장비 스티커 타일. 체력은 기체 머리 위.
02_soft_capsule.png — 소프트 캡슐: 크림/라벤더/민트, 둥근 캡슐과 장비 버튼. 체력/자원은 좌하단, 임무는 상단 중앙.
03_minimal_editorial.png — 미니멀 그래픽: 작은 보라 띠와 프레임 없는 지도, 우하단 가로 아이콘 배열. 체력/자원은 좌상단.

각 최초 생성은 사용자 원본 스크린샷을 직접 편집 입력했다.
이전 UI 원화는 기능·수치·키 정보용 보조 참조이며 그 레이아웃을 유지할 필요 없이 변형했다.
같은 디자인을 교정: 1안 남은 원본 에너지 점/구형 적 HP선 제거, 2·3안 Q/X/Z 명시.
내장 imagegen 사용. 실제 최초 프롬프트는 prompts.txt, 2·3안 추가 지시는 world_overlay_cleanup.txt, 교정은 correction_prompts.txt.
3안 최초 생성에는 Q DOCK/X SHIELD/Z CLEAN 글자를 명시하라는 한 문장을 추가했다(references.json에 전문 기록).

세 안 모두 실제 큐브 적 두 마리 머리 위에 붉은 체력/에너지바가 하나씩 있다.
여기서 적 에너지바는 적의 남은 체력을 나타내는 막대로 해석했다. 별도의 적 에너지 자원 기능을 제안한 것이 아니다.
막대 잔량은 원화용 예시이며 실제 HP 수치를 측정한 결과가 아니다.
통·파트너 드론·UI 아이콘에는 적 체력바를 붙이지 않았다.
지원0/100을 유지해 Q합체/X보호막 비활성, Z청소 활성. 기존 주무장/회피/부스터/미사일/레이저 키 의미 유지.
세 안의 원본 게임 장면 주요 구도와 대상 배치는 유지했다. 생성에 따른 리사이즈·국소 재표현 있음, 픽셀 동일 합성은 아님.
최종 3장과 교정 전 기록은 별도 파일. 최종 3장을 추가 디자인 3안으로 전달한다.
게임 코드/UI 실제 구현·엔진 실행·커밋·푸시 없음. 이전 원화와 다른 작업 파일 보존.
