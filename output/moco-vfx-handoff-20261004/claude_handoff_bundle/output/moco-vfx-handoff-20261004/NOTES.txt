mo.co 무드 VFX 및 배경 전달물
작성: 2026-10-04

먼저 docs/moco-vfx-claude-handoff.md를 읽는다.
형태·색상 PNG와 시간·배치 PNG는 내장 imagegen으로 생성한 컨셉 시트다.
시트에 작은 기체/드론을 그린 것은 크기·배치 설명용이며 모델 교체 요청이 아니다.
시트의 큰 발광과 효과 크기는 도해용이다. 실제 적용은 문서의 크기·수명·투명도 제한부터 시작한다.

정확한 색상은 palette_and_presets.json과 exact_palette.svg를 사용한다.
SVG는 HEX를 그대로 입력한 별도의 벡터 색상표다. 생성 PNG를 편집한 파일이 아니다.
PNG의 색상칩에는 생성된 음영이 있으므로 스포이드 색상을 정답으로 쓰지 않는다.
JSON은 제작 프리셋 명세이며 런타임에서 자동 로드되는 설정 파일이 아니다.
모든 새 수치는 제안값이며 mo.co 공식 수치 또는 실제 게임 검증 결과가 아니다.

CRIT_ACCENT/시트의 CRIT는 노란 색상 역할이다. 실제 치명타 판정이 없으면 CRIT!를 표시하지 않는다.
강공격 표시는 HEAVY!로 분리한다. 예시 피해 26/78을 상수로 쓰지 않는다.
보호막 자체는 적을 기절시키지 않는다. 이전 화면 시안의 STUN!은 실제 상태 이벤트가 있을 때만 적용한다.
지원 행의 500ms는 보호막 유지 상태다. 350ms 연결은 종료되고, 보호막은 현행 10초 및 소모 상태를 따른다.
강타 행의 300ms 착지는 도해다. 기존 SPIN/LAUNCH 0.5초 동작을 유지한다.
현재 합체 입력은 Q이다. 이전 화면 시안의 G 표기를 키 변경 기준으로 사용하지 않는다.

프로젝트 코드와 바닥 텍스처는 적용 위치·현행 값 확인에만 사용했다.
게임 자체를 비교 리서치 기준으로 삼지 않았고, mo.co 관찰과 적용 제안을 문서에서 구분했다.
게임 코드 수정·모델 교체·Godot 실행·커밋·푸시·클로드 메시지 전송은 하지 않았다.
다른 작업자가 수정 중인 파일은 보존했다. 코드 근거의 해시는 code_baseline.json에 남긴다.

ZIP은 프로젝트 상대경로를 보존한다. 해제 후 docs/moco-vfx-claude-handoff.md부터 열면 된다.
현재 전달물과 기존 mo.co 화면 시안·리서치 기록을 포함하며 게임 소스 전체를 포함하지 않는다.
이전 프롬프트/매니페스트의 절대경로는 작성 당시 입력 기록이며 다른 PC의 열기 경로가 아니다.
