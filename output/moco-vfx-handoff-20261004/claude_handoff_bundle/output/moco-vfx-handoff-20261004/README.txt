클로드 전달 묶음 사용법

1. ZIP을 폴더에 해제한다.
2. docs/moco-vfx-claude-handoff.md를 연다.
3. 문서 첫 표의 두 PNG 시트와 exact_palette.svg를 확인한다.
4. palette_and_presets.json의 HEX 및 문서의 수치를 초기 적용안으로 사용한다.
5. 문서 마지막의 요청문을 클로드에게 전달한다.

폴더 구조를 유지하면 문서의 상대 이미지 링크가 연결된다.
게임 프로젝트에 적용할 때는 현재 코드를 다시 확인한다. code_baseline.json은 문서 작성 시점 기록이다.
도해의 숫자·치명타·기절은 실제 게임 이벤트 조건으로 해석한다.
기술 명세는 적용 전 제안이며, 실행 검증은 클로드가 구현한 뒤 진행한다.
