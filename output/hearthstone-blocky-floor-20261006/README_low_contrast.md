# 하스스톤풍 대비 완화

사용자 요청: “하스스톤풍에서 대비를 좀 더 낮춰봐”.

- 결과: [floor_4m_low_contrast.png](floor_4m_low_contrast.png), 1254×1254 불투명 RGB PNG.
- 입력: 직전 [floor_4m_final.png](floor_4m_final.png). 기존 네 판 구성, 큰 색면, 둥근 눌림, 볼트와 모서리 형태를 참고하여 내장 imagegen으로 대비를 완화했다. 생성 편집이므로 입력의 픽셀과 완전히 일치하지는 않는다.
- 실제 요청문: [prompt_low_contrast.txt](prompt_low_contrast.txt).
- [검증](validation_low_contrast.json): 디코딩·규격·불투명·생성 원본 복사 SHA256 일치. 네 판 내부 각 480×480 영역의 sRGB 가중 명도 P95−P05 폭은 약 11.37% 감소했다. 전체 표준편차는 거의 같아, 줄눈·볼트까지 일률적으로 대비를 낮춘 결과는 아니다. HSV 평균 V는 .47485→.48390, S는 .41919→.39137이다.
- 큰 면과 둥근 파임이 더 부드럽게 읽히는 것을 육안 확인했다. 프롬프트의 25–30%는 목표이며 결과의 일률적인 감소율이 아니다.

이전 원본과 세 가지 비교 이미지를 보존했다. 게임 적용·UV/반복 경계 검증·엔진 실행·커밋·푸시는 하지 않았다. 별도 PNG 시안이며, 실제 Substance Painter 프로젝트 파일이나 PBR 채널 세트는 아니다.
