## 레퍼런스 고정

사용자 최신 지시대로 이 대화의 최초 네 첨부만 모든 생성에 직접 사용했다. 직전의 신규 메이드 3종, 기존 사장/정비사 원화, 스타일 검증 결과, 여백이 좁았던 사장 초안은 생성 참고 입력에 넣지 않았다. 기존 외형은 문서에서 필요한 특징만 텍스트로 추출했다. 최초 네 장의 변경 없는 영구 사본은 `docs/character-style-references-20261011/`, 향후 규칙은 [character-art-style.txt](../../docs/character-art-style.txt)에 기록했다.

## 결과와 검증

최종 전신 PNG 4장. 불투명 회보라 배경이며 투명 게임 포트레이트나 표정 세트는 아니다. `style_probe_owner.png`는 최초 네 원본과 얼굴/상반신 그림체를 대조하기 위한 보조 시안이며 새 기준 이미지로 사용하지 않았다. 최초 사장 전신은 머리 위 잘림을 확인하고, 원본 네 장만 다시 참조해 전신 여백을 보완했다.

실제 최종 프롬프트는 `prompts.json`, 검증 시안·재생성 프롬프트와 입력/출력 출처는 `sources.json`, 디코딩 크기·파일 SHA256·원본 복사 일치·육안 검증은 `validation.json`에 있다. 네 전신의 머리·발끝 포함, 손과 직무 소품, 서로 다른 외형/역할, 원본 수준의 외곽선·눈·큰 머리 덩어리·셀 명암을 확인했다. 원본을 편집 없이 복사했으며 정확한 픽셀 단위 그림체 동일성을 주장하지 않는다.

게임 코드·대사·씬·기존 포트레이트 연결은 변경하지 않았다. `.gdignore`로 임포트 제외. 커밋·푸시 없음.
