사용자 재검토 — 실제 적용할 텍스처 이미지 먼저 승인 (2026-10-05)

사용자가 앞선 실제 적용을 “너무 평이하고 표현이 적다”고 평가했다.
앞선 방식은 생성 이미지를 붓결 재료로 사용하고, 셰이더에서 4샘플 혼합/색 구성/절차적 줄눈과 마모로 재구성했다.
이것은 엔진의 필수 제약이 아닌 작업자가 선택한 방식이었다. 다음 방향은 이미지 안에 표현을 완성한 직접 베이스컬러다.

승인용 원본 PNG 3종 (내장 imagegen)
01_floor_albedo.png — 기존 4m/2×2 바닥 텍스처를 편집한 네 판, 명암/볼트/긁힘/모서리 도장 벗겨짐 포함.
02_tall_wall_albedo.png — 실제 W01 UV 아틀라스를 편집한 높은 벽.
03_low_wall_albedo.png — 실제 낮은 벽 블록 UV 아틀라스를 편집한 낮은 벽.
sources/는 실제 게임의 기존 텍스처 원본, prompts.json은 요청한 프롬프트 원문과 생성 경로.
생성 PNG를 바이트 변경 없이 복사했다. 그림을 코드로 덧그리거나 후처리해 재해석하지 않았다.

기술 상태와 승인 범위
본편 재질/셰이더/텍스처 교체 없음. 앞선 적용을 자동으로 되돌리거나 다른 작업을 수정하지 않았다.
현재 PNG의 그림 표현이 승인 대상이다. 이 결과는 사용자가 승인할 때까지 별도 output 폴더에만 보관한다.
생성 도구가 원본 UV 아틀라스의 작은 섬 경계/패딩을 픽셀 단위로 고정한다고 보장하지 않는다.
미리보기에서는 기존 UV로 주요 패널/프레임/낮은 벽 연결을 확인했다. 최종 패딩/볼트 섬 정렬/바닥 반복 이음새 및 게임 조명 검증은 후속 적용 단계다.
UV 정렬과 조명 조절은 표면 배치/렌더 준비이며, 그림을 다시 그리거나 다른 붓결로 대체하는 작업과 구분한다.
현재는 cover/pillar/half/jamb 별도 아틀라스까지 생성하지 않았다. 전체 배경에 적용할 경우 각 원래 UV 배치에 맞는 같은 스타일 텍스처가 추가로 필요하다.
본편 코드 변경/커밋/푸시 없음, 다른 작업 보존.
