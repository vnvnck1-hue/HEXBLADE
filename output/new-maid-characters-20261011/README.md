# 신규 메이드 캐릭터 3종

제작일: 2026-10-11. 사용자 제공 레퍼런스 네 장을 직접 참조하여 내장 image_gen으로 개별 생성했다.

- `01_lavender_tea_maid.png`: 라벤더색 티 메이드. 졸린 표정, 짧은 머리와 옆 번, 달 장식, 찻잔과 달 모양 쿠키.
- `02_lemon_bakery_maid.png`: 레몬색 베이커 메이드. 큰 옆 포니테일, 활발한 표정과 엄지 척, 레몬 타르트와 오븐 장갑.
- `03_plum_magic_maid.png`: 자주색 마술 메이드. 양쪽 버블 포니테일, 청록색 포인트, 카드 장식과 서빙 덮개를 여는 포즈.

공통: 굵은 검정 외곽선, 큰 머리와 신발, 흑백 메이드복, 셀 명암, 회보라 배경의 전신 콘셉트 원화. 배경은 불투명이며 게임에는 미연결이다. 실제 최종 프롬프트는 `prompts.json`, 참조와 생성 출처는 `sources.json`에 기록했다.

검증: 세 장 모두 육안으로 전신 구도, 그림체, 서로 다른 헤어 실루엣/표정/소품을 확인했다. 기술 정보와 SHA256은 `validation.json`에 기록한다. 생성 원본을 수정 없이 복사했다.
