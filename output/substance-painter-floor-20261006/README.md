# Painter 자료를 참고한 청보라 바닥 철판

2026-10-06. 사용자 요청: Substance 3D Painter 자료를 먼저 리서치한 뒤, Painter로 그린 것처럼 바닥 철판을 재작화.

## 최종 시안

`floor_4m.png`: 1254×1254 RGB 불투명 PNG. 현재 청보라 팔레트·네 판·볼트 배치를 기준으로, 도장 코팅과 노출된 회청색 금속을 구분하고 큰 부드러운 명암 덩어리·단순한 모서리 마모·매끈한 볼트 반사를 표현했다. 과거 v2의 대각선 교차 붓 패턴을 그대로 유지하지 않도록 새로 그렸다. 먼저 만든 `draft_diagonal.png`는 대각선 패턴이 많이 남아 최종 시안으로 선택하지 않았고 비교 자료로 보존했다.

**실제 제작 도구는 내장 imagegen이다.** Painter로 제작된 작가 재질과 Adobe의 스타일라이즈드 작업 방법을 참고한 PNG 그림이며 실제 `.spp`나 메시 베이크 결과, 완성 PBR 채널 세트가 아니다. 그림 속 반사/깊이는 PNG 표현이고 실제 인게임 조명 반응을 입증한 결과가 아니다.

최종 프롬프트 `prompt_refine.txt`, 첫 시도 `prompt.txt`, [리서치](research/README.md), 작가 원본 네 장과 URL/해시 `research/images.json`을 보관했다. 공식 문서 확인과 실제 작가 이미지 육안 분석을 먼저 마친 뒤 그림을 제작했다.

현재 기준 평균 HSV V/S 0.49245/0.40404 → 새 시안 0.46769/0.42024. 평균 명도 -2.48%p, 채도 +1.62%p로 팔레트를 가깝게 유지했으나 수치가 동일한 것은 아니다. 원본 출력에 추가 색 보정·리사이즈·재그림 없음. `validation.json`은 원본 SHA 복사 일치·디코딩·정사각·불투명·색 통계·참고 JPEG 네 장의 디코딩 및 해시 일치를 기록한다. `inspect.py`는 읽기 전용 이미지 검사와 보고서 저장용이다.

## 직접 사용 규격과 상태

4m 영역에 네 개의 2m 판을 배치하는 월드XZ 투영용 한 장 시안. 직접 샘플링 시 `(world_xz - offset)/4.0` 좌표를 전제로 한다. 다른 프랍의 원래 UV 아틀라스가 아니다. 현행 붓 혼합 셰이더에 파일만 교체하면 그림이 달라질 수 있다. 픽셀 경계 반복·실제 모델 및 인게임 적용은 이번 단계에서 검증하지 않았다.

사용자 채택 전. 본편 적용·게임 코드 변경·엔진 실행·커밋·푸시 없음. `.gdignore`로 임포트 제외, 기존 시안과 다른 작업 보존.
