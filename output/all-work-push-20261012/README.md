# 전체 작업 통합 커밋·푸시 검증 (2026-10-12)

사용자 요청에 따라 Claude·Codex 작업과 이 경로의 미추적 산출물을 모두 `feature/round-skill-hud`에 포함한다. 기존 Git 제외 규칙은 유지하며, `main` 병합은 하지 않는다.

- 포함: 로비, 대화·출연진 원화·모션, HUD·알림 UI 시안 v2, 텍스처 디오라마, 무한 비행, 방 확대, 지원 게이지, 사체·투사체 프리셋, 문서·검증·최종 이미지·GIF·프롬프트와 `.uid`/`.import`.
- 제외: `.godot/`, `.tools/`, 프레임 덤프·캐시·백업·중복 프리뷰, 재배포 제외 음성 원본 등 기존 `.gitignore` 대상.
- 검증: 고정 Godot 4.7.2 임포트 성공. `tools/run_tests.ps1` 전체57종 최초56종 통과, 무한 비행 재화 이동1항목 실패. `stream_mode_check` 단독 재검사 통과, 최종57종 모두 통과.
- 최초 간헐 실패는 별도 수정하지 않았으며 두 실행 로그를 모두 보관한다. 이번 작업에서는 게임 코드 내용을 바꾸지 않았다.

`import.log`, `all-tests.log`, `stream-retry.log`가 이번 통합 검증 원본이다. 각 작업별 과거 미커밋 표기는 당시 기록이며 통합 커밋 범위는 AGENTS.md 최신 기록을 따른다.
